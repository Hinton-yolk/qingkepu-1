# 参考分析 · Ordinary Folk《Equilibrium》（2024）

用户 2026-11-19 指定为 AI 系列的**主体参考**（原话见 `episodes/ai/要求清单.md`「画风」）。
用途：给 AI 系列定「高级风格化 2.5D 科学动画」的画面语言。只学语言，不照搬造型和画面；参考片里没有具体数字可引用。

## 素材与可信度
- 来源：项目页 https://www.ordinaryfolk.co/project/equilibrium （2026-11-19 能打开）。
- 拿到的东西：26 张 styleframe（800 px 宽）、一段 8.1 秒的 Fine Cut 循环（720×720，30 fps）、四段分镜头片段（S05_06、S07、S08_09、Comp_1，共约 9.5 秒）。项目页上**没有完整成片**（播放按钮链接为空），所以没法看全片节奏，也没有声音。
- 配图（缩小存档，原文件不进仓库）：`参考分析_OrdinaryFolk/styleframes_26.jpg`、`成片8秒_每0.2秒.jpg`、`分镜头片段.jpg`。
- 项目页自述：起点是「两个基本形状」；「2D 关键帧和转场」与「有触感的 3D」结合；主题是「相反的力」。
- 〔测〕= 用 `tools/frame_stats.py` 或 ffmpeg 测的；〔看〕= 看帧得出的判断。

## 1. 造型〔看〕
- 只用几种基本体：圆环 / 卷曲的带子、球、圆片、方块、有厚度的方框（像相框一层套一层）、圆柱。
- 复杂感来自**重复和组合**：圆片叠成花、方框一层层往里套、圆柱斜着排成一列、方块排成格阵。不来自单个物体的细节。
- 构图大多居中、对称或沿一条轴排开，主体只占画面中间 1/3–1/2，四周大量留白。
- 没有描边、没有角色、没有表情。

## 2. 材质（「不廉价」的关键）〔看〕
- **糖果塑料**：高饱和、带清漆高光，边缘有一圈亮的菲涅耳反光。
- **半透明玻璃 / 果冻**：能透过它看到后面的物体并带颜色，有轻微磨砂（模糊的折射），内部偶尔有细小的闪粉颗粒。
- **渐变材质**：同一个物体从一种颜色渐变到另一种（绿 → 黄、粉 → 橙），像彩色玻璃。
- **2D 图案贴在 3D 面上**：棋盘格、像素格、条纹贴在方块或方框的面上。这是「2D 设计和 3D 材料融合」最直接的一种做法。
- 光：柔和的大面积棚灯，没有硬阴影；物体之间有轻微的接触阴影和互相映色。

## 3. 颜色〔测 + 看〕
- 背景是**一整片粉彩色**（天蓝、薄荷绿、粉、奶黄），有很缓的渐变，没有地面线、没有环境。
- 一个镜头里只有 2–3 个颜色家族：一个背景色 + 主体的一组邻近色 + 一个点睛色（例如蓝底上绿色的环，中间一个蓝球）。
- 〔测〕Fine Cut 六个时间点：平均亮度 0.68–0.77，平均色度 0.27–0.44。四张 styleframe：亮度 0.53–0.77，色度 0.30–0.66。
  对照：我们旧深靛画风的底色亮度约 0.1。这是一个**明亮的**画风。

## 4. 空间层次〔看〕
- 浅景深：前景的大圆片、后景的球都是虚的，焦点只在中间一层。
- 前中后三层，常用半透明的东西做前景，透过它看主体。
- 「简单物体也有空间感」靠三件事：透视下的厚度（方框都有侧面）、透明物体的叠压、景深。

## 5. 运动〔看 + 测〕
- 〔测〕8.1 秒的 Fine Cut 用 ffmpeg 场景检测（阈值 0.3）**一次切换都测不出**：全程是一个连续的形变镜头，换场景靠变形，不靠剪切。
- 〔看〕手法：
  1. 带子展开 / 卷起，一圈圈变成一串圆环；
  2. 球穿过环（一个东西贯穿全程）；
  3. 一组物体旋转散开，再聚拢成新的形状（四片 → 十几片 → 花）；
  4. 相机推进穿过前景的圆片，进到下一层；
  5. 方框一层套一层地往里推（隧道）。
- 节奏：每个形状大约 1–2 秒变成下一个，但动作是连续的，没有停顿，也没有甩镜。
- 运动曲线：缓入缓出，落位时有轻微回弹，没有线性运动。

## 6. 对 AI 系列的翻译（建议，待样张验证）
| Equilibrium 的语言 | AI 系列里的对应 |
|---|---|
| 球穿过一串圆环 | 新生成的那个字（一颗发光的球）穿过模型的一层层 |
| 方块格阵、棋盘格面 | 参数表 = 粉 / 蓝两色的糖果方块格阵（保留旧符号表的粉正蓝负） |
| 带子展开、分叉 | 一句话是一条带子，在「去」后面分成两条 |
| 一层套一层的方框 | 模型的层、显卡的层级（第二季） |
| 粉彩底色、每段换一个底色 | 每个环节换一个底色，帮观众分段 |
| 2D 图案贴在 3D 面上 | 字块上的汉字、芯片表面的版图 |

**和 Ordinary Folk 不同的地方**（科普要求）：
- Ordinary Folk 是品牌片，只有形状；我们要讲清楚因果，所以每个画面要有字幕和少量小字，字放在 2D 层上，不进 3D。
- 科技产品（手机、显卡、芯片）要做成**有实体质感的产品模型**（用户要求），不能只是一个抽象方块。它们和抽象形状同一套材质和灯光，看起来属于同一个世界。
- 节奏按用户规定（每 3–8 秒一个知识推进、关键画面停够），不照搬作品集节奏（见 `CLAUDE.md` 3D 镜头语法第 14 条）。
