# 「如果……」系列：导演原则（已暂停，存档）

2026-11-06 决定暂停「如果」系列（见 `DECISIONS.md` 第 4 条），以下原则原样保留，做特别篇时使用。
做特别篇时，仓库 `CLAUDE.md` 里的「开头 2 秒规则」优先于下面的「开头两句」。数据显示「如果」的情景式开头 2 秒跳出偏高（地球停转 46.2%）。

---

- 一句话定义：不是「告诉你一个科学事实」，而是「修改一个现实参数，然后陪你看世界一步步失控」。
  「为什么」系列满足「原来如此」；「如果」系列是一场有科学规则约束的短篇科幻实验：
  先让人觉得很爽 → 再觉得越来越不对劲 → 最后发现真正的结果和一开始想的完全不一样。
- 四问只用来找核心规则和反转，叙事按下面的 6 段式。
- 情绪曲线：好奇 → 惊艳 → 原来如此 → 不安/奇怪 → 越来越大 → 反转 → 余味。
  不是「问题 → 原理1 → 原理2 → 原理3 → 总结」（那是课程）。
- 6 段式（固定）：
  1. 一秒就懂的疯狂假设：听懂 ≤ 1 秒、脑子里立刻有画面；不解释背景，不用术语
     （「如果你的眼睛突然能看见 Wi-Fi？」可以；「如果人类能感知 2.4 GHz 电磁辐射」就死了）。
  2. 先满足第一想象（wish fulfillment）：给观众点进来想看的画面，不急着纠正。
  3. 转折句：「但有一个问题。」/「但事情开始变奇怪了。」/「不过，真正的世界不会这么整齐。」
     从漂亮的想象进入科学推演。
  4. 推演 + 尺度升级：约每 6 秒（5–8 秒）世界发生一次新变化——是因果升级，不是镜头变化
     （路由器 → 房间 → 一栋楼 → 整条街 → 整个城市）。
  5. 真正的反转：结果和开头想的完全不一样，并且重新解释整条片子
     （你以为在讲「如果我们能看见 Wi-Fi」，其实问题是「什么样的眼睛才有资格看见 Wi-Fi」）。
  6. 余味：不收死，留一个画面；黑场 →「下一个如果，你想看什么？」
- 每集只保留一个核心科学规则，其他知识都为它服务
  （看见 Wi-Fi：波长很长；地球停转：惯性不会跟着停；空气密度翻倍：阻力 ∝ 密度；光速慢十倍：信息不能比光快）。
- 先讲故事，再讲知识：知识是剧情道具，不念公式
  （不说「λ = c/f」，而是「你以为 Wi-Fi 的波很小？」→ 手里出现一把 12 cm 的尺子 →「这会带来一个很麻烦的问题」）。
- 标志动作（每集固定）：现实里一个很普通的画面 →「如果……」→ 顿一下
  → 啪：一个物理变量被改掉（参数读数：转速 1x → 0x、c → 0.1c、g → 0、身高 170 cm → 1 cm），世界切换。
- 开头两句（每集固定）：第一帧就是标题；先把观众放进情景里，再点题。
  ① 一句话描述当下的情景（例：「想象黄昏时分，你正在阳台上品着刚刚做好的手冲。」）
  ② 点题（例：「如果此刻，地球突然停止自转，会发生什么呢？」）
  ② 说完顿一下（约半拍），就直接改参数、世界开始变——不再念「好，让我们把现实修改一下」，
  那句会让节奏掉下来。一镜到底时，观众跟着字幕和镜头走，我们负责引导。
  改参数用一个快速的读数变化（如身高 170 cm → 1 cm 跟着镜头滚动），而不是停下来等的面板。
  两句用同一种惬意、放松的声音（同一个语气标签，如 [relaxed]），音高和响度保持一致；
  不要换成好奇、兴奋之类的语气——会变声、一惊一乍。配完用音高/响度对比检查。
- 节奏与动感（从「陀螺仪」那条学来的，取长补短，不照搬；「如果」系列保留旁白和情绪曲线）：
  - 时长：目标 55–65 秒，上限 75 秒；超过 60 秒的每 10 秒都要换来一个新的「哦」。
  - 一镜到底：尺度升级用连续的镜头运动串起来（推进、拉远、穿过），不在场景之间硬切；
    上一镜的结束画面就是下一镜的开始画面。
  - 每一镜都有一个「心跳」：一个和核心规则有关、一直在动的东西（地球在转、海在晃、波在推），
    动本身就在讲道理；正片里不留超过 0.5 秒的静止。
  - 大块面的运动优先（镜头推拉、大物体位移、大色块）；细线条的小变化在手机上等于没动。
  - 字也在动：一屏一句，逐字或逐词出现，换句时旧字退场。
  - 首尾相接：最后一个画面回到第一个画面（同一构图），但意义已经变了；然后才接「下一个如果」。

## 原「Render contract」与「Look」（供用 render.mjs 流程的项目参考）
- Every film is a pure function of time: `window.seek(t)` paints frame t.
- No CSS transitions, no setTimeout, no requestAnimationFrame in render mode,
  no state carried between frames. Seeded noise only (mulberry32), never Math.random.
- Render with `node render.mjs`, encode H.264 yuv420p, CRF 16.
- Banned defaults: centered title on gradient, everything fading in,
  corner labels and frame borders, glow on UI chrome, generic particle bursts.
- One display face, one UI face. One accent color unless the brief says otherwise.
- Every 2 to 4 seconds something new must happen on screen.
- Score and SFX are synthesized in code unless a track is supplied.
  Place hits on the measured beat grid (beats.json). Loudness -14 LUFS.
