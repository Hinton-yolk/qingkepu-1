# FACTS — 如果……会怎样 01 · 如果你的眼睛突然能看见 Wi-Fi

核心规则（全片只有这一条）：**Wi-Fi 的波很长，约 12 厘米。**

| 片中说法 / 画面 | 依据 |
|---|---|
| 2.4 GHz Wi-Fi 一整条波约 12.5 cm（画面上波纹按真实间距画，尺子量 12.5 cm） | λ = c / f = 3×10⁸ m/s ÷ 2.4×10⁹ Hz = 0.125 m |
| 「你的手机，也在回应它」 | Wi-Fi 是双向通信：手机同样发射信号给路由器 |
| 「墙会削弱它，你的身体会挡住它，冰箱会把它弹回来」 | 2.4 GHz 穿墙会衰减；人体含水，吸收并反射；金属反射电磁波（冰箱外壳、微波炉门网孔远小于 12 cm，起屏蔽作用：https://www.straightdope.com/21343269/what-keeps-microwave-radiation-from-leaking-out-the-oven-door ） |
| 「几路波撞在一起，乱成一张网；手机挪几厘米，信号都可能变」，画面上强、弱两点相隔几厘米 | 多径传播造成的小尺度衰落，强弱交替的尺度约为半个波长（约 6 cm）。画面上的「网」是路由器与墙、冰箱镜像源的相干叠加，示意 |
| 「连蓝牙耳机都在发光」 | 蓝牙工作在 2.4 GHz ISM 频段，与 2.4 GHz Wi-Fi 同一频段 |
| 「整座城市，泡在一片从不熄灭的光雾里」/「电磁海洋」 | 比喻 |
| 「你的瞳孔只有几毫米」，画面上 3 mm | 人眼瞳孔直径约 2–8 mm |
| 「刚才那些清楚的圆圈，你一个也看不见」 | 口径远小于波长时无法分辨方向和形状：衍射极限角 ≈ 1.22 λ / D，D = 3 mm 时远大于 1 弧度，成不了像 |
| 「眼睛得有几百米宽」，画面上 ≈ 500 m | 按人眼约 1 角分（2.9×10⁻⁴ rad）的清晰度估算：D ≈ 1.22 × 0.125 m ÷ 2.9×10⁻⁴ ≈ 520 m。屏幕上写明「按人眼的清晰度估算」 |
| 「中国天眼，口径五百米」；屏幕小字「收得到 2.4 GHz」 | FAST 口径 500 m（有效照明口径 300 m）；FAST 的接收机覆盖约 70 MHz–3 GHz（含超宽带接收机），2.4 GHz 在范围内，对它来说是干扰 |
| 「方圆五公里内，禁止带手机」 | 《贵州省 500 米口径球面射电望远镜电磁波宁静区保护办法》：以台址为圆心、半径 5 km 为核心区，禁止擅自携带手机等无线电发射设备；游客参观前须寄存手机（https://www.thepaper.cn/newsDetail_forward_1541691 ） |
| 「可它最怕的，恰恰就是手机和 Wi-Fi」 | 射电望远镜对人为无线电干扰极敏感；画面上手机在它眼里像一颗颗小太阳是比喻 |
| 画面：一栋楼按层亮起、街上的窗、城市的光 | 示意，不对应真实设备数量 |
