# 「如果……」03 · 如果你突然缩小到一厘米 — 脚本 v1（待确认）

## 拆题（四问只用来找核心规则和反转）

| 问 | 答案（一个机制） | 演示画面 | 「哦」 |
|---|---|---|---|
| 1 为什么不？人为什么是现在这么大？ | 身体的一切（骨头、体温、皮肤）都是为这个大小的物理长成的 | 开头的书桌：你、热茶、一只沿桌沿爬的蚂蚁 | — |
| 2 不，意味着什么？ | 不同大小，「谁说了算」不一样：大的东西重量说了算，小的东西表面说了算 | 你的身体轮廓，皮肤一圈亮起；两个数字：表面 ÷2.9 万、体重 ÷490 万 | 哦！缩小不是等比缩小，表面「缩得慢」 |
| 3 如果缩到 1 厘米，会怎样？（必须演示） | 先爽：摔不坏、力气大。再不对劲：水裹住你、雨滴比你重、几分钟失温、一天吃掉比自己还重的东西 | 一镜到底跟着你：桌面 → 跳下 → 地板 → 窗边的水和雨 → 风 | 哦！超能力和致命伤是同一件事 |
| 4 缩了，又意味着什么？ | 大小就是物理：蚂蚁不是缩小的人，是为那个大小长成的；人缩不成蚂蚁，蚂蚁也长不成人 | 镜头拉回开头的书桌，蚂蚁绕开一滴水 | 哦！原来每种生物的大小都不是随便的 |

**核心科学规则（只有这一条）：东西越小，表面越占上风。** 摔不坏（阻力按面积）、力气大（肌肉按截面）、挂水（按面积）、冷得快（散热按面积）、饿得快（为了补热），全部从这一条推出来。

**一镜到底的镜头路线：** 书桌（正常大小）→ 啪，你缩小，镜头同步推进，书桌变成平原 → 回形针 → 桌沿，跳下，镜头跟着往下 → 地板，窗台溅下的水 → 雨 → 窗缝的风 → 一只蚂蚁走过来 → 镜头一路拉回，回到第 0 帧的构图。全片不硬切。

**每一镜的「心跳」：** 茶的热气和窗上的雨丝 → 缩小时的推镜 → 回形针被你一上一下地举 → 下落时身边流过的气流 → 水膜在你身上颤 → 一颗颗砸下来的雨滴 → 热量从皮肤往外流（体温色从橙变蓝）→ 一粒米越吃越小、旁边的日历在翻 → 蚂蚁的六条腿 → 拉回时整张书桌。

**情绪曲线：** 好奇（缩小？）→ 惊艳（半粒米重、力大无穷、从桌上跳下来）→ 原来如此（表面占上风）→ 不安（水、雨）→ 越来越大（冷、饿）→ 反转（超能力就是致命伤）→ 余味（蚂蚁绕开一滴水）
