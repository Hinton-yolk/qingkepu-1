# 如果 · 会怎样 01 ——「白模投影」三个方向（风格帧）

**Style:** Projection on White Model（白模投影，lemo-opuscar `styles/white-model`）。STYLE.md 全部不变量照守：真实地点的真实楼体（PLATEAU，CC BY 4.0），白模不变、数据是投上去的光，一层一个手势，暗房 + 底座。
**Format:** 9:16 竖屏 1080×1920（抖音/小红书），本轮只出静帧。
**Brief (from the user):** 不用 OSM，用海外开放数据；三个方向各用一个地点，构图和叙事都不同。

## 这个题材里，"数据"是什么

白模上投的唯一一层数据 = **Wi-Fi 的光**：每栋楼里估算的路由器数量（由同一批楼体的楼高、占地面积、用途算出，屏上标「估算」），以及由这些路由器算出的信号场。颜色只用一族：琥珀橙（与系列"信号橙"同义：橙 = Wi-Fi，绝不做装饰）。

## 三个候选结构（= 给用户挑的三个方向）

| | A · 一栋楼，万家灯火 | B · 一片街区，涟漪漫过屋顶 | C · 一座城，泡在电磁波里 |
|---|---|---|---|
| 地点 | 东京 高岛平团地（板桥区，1970 年代板楼群，最像国内小区） | 东京 高圆寺一带（杉并区，几千栋低层住宅） | 东京 新宿西口（超高层群） |
| 结构 | 单栋的故事由邻居讲：一栋楼逐层逐户点亮，再带出整片小区 | 一个问题一层层回答：熄灯 → 一盏灯 → 几千盏 → 只剩没有灯的"洞" | 从地面到天际线：一个上涨的"水位"把整座城淹没 |
| 原生动作 | The pick-out（单独点亮一栋）+ 逐户亮起 | Lights out, lamp on + The hole（公园、寺院、铁路是暗的） | The rising level（光的水位爬满所有立面） |
| 构图 | 低机位贴着屋顶，一栋 14 层板楼占画面高度 1/3 以上，浅景深，楼后邻居虚化 | 起重机俯视（约 60°），整片街区铺满竖屏，涟漪从每栋房子扩散、互相叠加 | 侧面低角度对着黑色天空，超高层剪影，琥珀光从地面往上漫 |
| 读数（左侧三分之一） | 这一栋 ≈ N 户 = N 台路由器（估算） | 这 1 km 网格 ≈ N 台路由器（估算） | 光的"水位"＝每栋楼估算路由器数换算的高度 |
| 对应成片段落 | 「整栋楼一闪一闪，像万家灯火」 | 「墙挡不住它」「真实世界更乱」 | 「整座城市，都泡在看不见的电磁波里」 |

**选择：** 三个都做成同一套引擎的静帧，由用户挑一个方向再做成片。三个方向构图不同（低机位单栋 / 俯视街区 / 侧面天际线），不是同一构图换颜色。

## 规则冲突与处理

- STYLE.md 要求左上角身份标签；用户全局规则禁止角标与画框 → 身份信息（地点、比例、数据源）并入左侧读数块的来源行。
- STYLE.md 的字体角色有三种；用户规则只允许一个展示字体 + 一个界面字体 → 数字用 Inter Tight 200，其余标签与读数用 Noto Sans Mono CJK SC。

## 事实与数据

见 `FACTS.md`：楼体与高度来自 PLATEAU（国土交通省，CC BY 4.0），片中署名「出典：国土交通省 PLATEAU」；户数与路由器数为估算，方法写在 FACTS.md。
