# TREATMENT — 如果眼睛能看见 Wi-Fi（「如果……会怎样」01）· 白模投影 · 高岛平团地

**Logline.** 一扇窗在黑暗里亮起，然后整栋楼的窗都烧起来：每户一台路由器、每秒喊十次「我在这儿」。信号溢出墙外，在楼下一圈圈扩散；隔壁、再隔壁也亮了，最后整片团地六千多台同时亮着。灯一开，什么都没有；灯一关，这里是另一种万家灯火。

- 竖屏 1080×1920，24 fps，46.0 s；抖音 / 小红书。
- 模型：PLATEAU 实测高度 + 屋顶轮廓，1:1000，半径 230 m，134 栋。数字全部来自 `data/A/stats.json`（见 FACTS.md）。
- 配音：Fish Audio「科普」（用户指定），9 句；字幕中文单行。
- 一个强调色：橙 #ff6a1a（Wi-Fi）及其高光 #ffd2a8；字体：Inter Tight 200（数字）+ Noto Sans Mono CJK SC（文字）。

## 结构（一镜到底，转场只用灯光变化）

## 声音设计（全部代码合成，节拍 120 BPM，命中点都在 beats.json 的网格上）

| 行 | 时间 | 声音 |
|---|---|---|
| 房间 | 全片 | 房间底噪、投影机风扇（灯亮时升高） |
| 第一扇窗 | 0.0 | 一声玻璃音（G5） |
| 蔓延 | 0.5–3.5 | 每批窗点亮一个短促玻璃/马林巴音，越来越密，落在 3.5 的低音和弓奏颤音琴和弦 |
| 脉冲 | 4.5–14.5 | 马林巴八分音符脉冲（信标的节奏），低音提琴与大提琴垫底，Am–F–C–G |
| 计数 | 10–12、15–16.5 | 上行马林巴音阶，落数处一声钟琴 |
| 信标 | 14.5–18.5 | 脉冲变十六分音符；17.5 「我在这儿」一声明亮的玻璃铃 + 其余音乐短暂收住 |
| 出墙 | 20.5–24.5 | 每个光环一次带通噪声「呼」；低音下行 |
| 邻楼 | 25.0、26.0 | 各一声玻璃音 + 软的低铜管 |
| 扩散 | 28–30 | 空气上升音 + 马林巴越来越密 → 30.0 定音鼓、大鼓、锣、低铜管（全片最响） |
| 亮灯 | 33.5 | 继电器咔哒，音乐收掉，只剩风扇 |
| 打灯 | 36.0 | 继电器 + 灯泡点亮（电弧 + 闷响），第一声是转折：温暖的低铜管 + 弓奏颤音琴大三和弦（C） |
| 万家灯火 | 38.5–46 | 稀疏的玻璃音随机闪烁（像窗），40 片尾卡一声管钟，风扇收尾 |

混音：人声比音乐高约 10 dB；30.0 和 36.0 两个设计好的冲击最响；整片 −14 LUFS，真峰值 ≤ −1.2 dBTP。

## 规则说明

- 不加角落身份标签（用户规则禁止角标）：地点、比例、数据来源写进读数的来源行和片尾卡。
- 光环的环距放大约 150 倍（真实 2.4 GHz 波长 12.5 cm），读数 03 和片尾卡都写了「示意」。
- 窗的闪烁每扇窗相位随机、亮度起伏小，整体亮度稳定，不做大面积同步频闪。
