## 数据来源

- **建筑几何与高度**：国土交通省 PLATEAU 3D 都市模型（东京都 23 区，2023 年度），CityGML `bldg` 图层。
  - 用到的三次网格：A `53395542` `53395543`；B `53394541` `53394542`；C `53394525` `53394535`。
  - 取 `lod0RoofEdge`（屋顶轮廓）＋ `measuredHeight`（实测高度）＋ `storeysAboveGround`（地上层数）＋ `usage`（用途代码）。
  - 许可：PLATEAU 数据以 CC BY 4.0 兼容的条款开放。画面署名：「数据：国土交通省 PLATEAU（CC BY 4.0）」。
  - 获取方式：PLATEAU 数据目录 API → CityGML 压缩包，HTTP Range 只取所需网格的 `udx/bldg/*.gml`（`tools_fetch.py`）。
- **没有使用 OpenStreetMap**（按要求）。

## 估算方法（全部是估算，画面上都标了「估算」）

路由器 / 无线接入点数量按用途代码估：

| 用途代码 | 含义 | 估算 |
|---|---|---|
| 411 | 独栋住宅 | 1 户 = 1 台 |
| 412 / 414 | 共同住宅（含底商） | 板楼（最小外接矩形宽 ≤ 16 m）：沿长边每 6.5 m 一户 × 层数；其他：总楼面积 ÷ 60 m² |
| 413 | 店铺兼用住宅 | 2 台 |
| 401 / 402 / 403 | 办公 / 商业 / 酒店 | 总楼面积 ÷ 150 m²，一个接入点 |
| 其他（含 461 未知） | 公共、仓库等 | 总楼面积 ÷ 400 m² |

- 层数：PLATEAU 的 `storeysAboveGround = 9999` 表示「未知」，此时用 实测高度 ÷ 3.2 m 估层数。
- 总楼面积 = 屋顶轮廓面积 × 层数（忽略退台，偏高估）。
- 「每户一台路由器」是假设：现实中有的户没有、有的户有两台（加中继），不同户可能共享。

## 示意（不是物理）

- Wi-Fi 2.4 GHz 的波长约 **12.5 cm**；画面上地面的环距是 **24 m**（B）/ **18 m**（A 的外溢环，以 16 m/s 向外走），是放大的示意，B 的来源行写了「环距放大示意」。
- B 的场：只有最大的约 40 个楼栋画出环纹，其余只铺一层底光；叠加是非相干的亮度相加，没有算墙体衰减和反射。
- C 的「信号淹到的高度」是一条随时间上升的光面，只是比喻「整座城市泡在电磁波里」，不代表某个高度的场强。
- A 的窗格亮灭是随机种子（哈希）决定的，表示「每户一台」，不对应真实户的在线状态。

## 待核（进入正片前）

- 板楼 6.5 m 开间：高岛平团地的标准户型开间实测值待对照 UR 公开资料复核。
- 办公 150 m² / 接入点：企业 AP 密度常见 100–250 m²，取中间值；若进入正片，旁白应说「估计上万台」而不是精确数字。
