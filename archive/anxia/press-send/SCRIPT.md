**核心机制（只讲一个）：你的消息只在两头「飞」几百米，中间几千公里都是一束在玻璃丝里跑的光。**

**一镜到底的路线：** 你的手机屏幕（第 0 帧）→ 拇指按下，镜头钻进发送键 → 消息变成一团电磁波飞出手机，镜头拉到整个街区 → 跟着它飞上楼顶基站 → 一头扎进地下管道 → 穿进一根光缆、一根玻璃丝，里面是一闪一闪的光 → 镜头一路拉远到全国夜景地图，这束光从北京冲到广州 → 推进广州的一座机房 → 再飞出最后几百米，钻进朋友的手机：「叮」→ 拉远，全国光缆一起亮起 → 回到你的手机，朋友回了「还没睡」（和第 0 帧同一构图）。

**每一镜的「心跳」：** 那团一直在往前跑的光（消息），全片不停。飞行时是一圈圈电磁波，在光纤里是一闪一闪的光脉冲，在地图上是一道划过国土的亮线。

**情绪曲线：** 好奇（这句话去哪了？）→ 惊奇（钻进地下）→ 原来如此（玻璃丝里的光、百分之一秒）→ 越来越大（全国 7000 多万公里）→ 反转（「无线」几乎全是线）→ 原来还可以这样（难的只是最开始那几百米）→ 余味（大地替你送过去）
