**核心机制（只讲一个）：它不用听，它在猜——你的停留、你身边人的搜索，早就把答案递给了它；猜错的你记不住，猜中的那次你记一辈子。**

**一镜到底的路线：** 饭桌（第 0 帧：你和朋友，桌上倒扣的手机，纸剪的对话气泡「最近想买个空气炸锅」）→ 饭还没吃完，你拿起手机，空气炸锅推过来 → 顿半拍，镜头钻进手机底部的麦克风孔 → 纸做的麦克风在「睡觉」，演示偷听的代价，检测报告盖章「未发现」→ 镜头退出来，升到饭桌上方 → 三条线索依次亮起：你的 6 秒、朋友的搜索、墙上的路由器把两部手机系在一起 → 镜头冲进你的信息流：几百张卡片刷过，只有猜中的那张被钉住 → 拉回饭桌：对话气泡原来是这三样拼成的 → 设置里拨掉「个性化广告」→ 回到饭桌，和第 0 帧同一构图。

**每一镜的「心跳」：** 对话气泡里的字一直在晃；麦克风的呼吸；电量条和温度计；飞行的珠子；路由器的纸波纹；哗哗刷过的卡片。

**情绪曲线：** 熟悉（人人都遇到过）→ 怀疑（它在偷听？）→ 意外（其实没在听）→ 好奇（那它怎么知道的？）→ 原来如此（朋友搜了、你停了、你只记得猜中的）→ 反转（是你身边的一切先开了口）→ 原来还可以这样（关掉个性化广告）→ 余味（回到饭桌）

**纸艺画面：** 沿用上一集的纸艺拼贴：夜色深蓝底、米色纸条字幕、牛皮纸签；唯一的金色是「你的信号」。朋友的珠子用米白，商家和广告用别的纸色。

## 需要你拍板的三件事

1. **标题：** 片头用「你刚说完」，结尾贴回来变成「你刚说完 / 它早就猜到了」，和上一集「你上划之前 / 就是你自己」是同一个套路。发布标题和封面用更好搜的「手机在偷听你吗？」。
2. **「同一个 Wi-Fi」这句的分寸：** 这是三条线索里证据最弱的一条。同一个路由器后面的设备对外共用一个 IP，广告行业确实拿 IP 当「一户人家」来投放，也有学术研究观察到广告按同一网络里别的设备的流量来投；但国内哪个 App 具体怎么用，没有公开。所以片中只说「可能就是一伙的」。如果你想更稳，可以改成「你们互相关注、存着对方的电话」——这条有法院案例（抖音「可能认识的人」案）和微信视频号「朋友赞过」可以撑，但画面没那么直观。
3. **分寸和结尾办法：** 片中只说「没发现」「它不用听」，不说「绝对没有」，不点名任何 App。美国那家吹自己能「偷听」、结果被美国联邦贸易委员会查实根本没在听的广告公司，放在置顶评论里。关掉个性化广告时明说「广告不会变少」。
