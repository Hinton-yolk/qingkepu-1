# FACTS · 「你按下去之后」· 你刚说完（手机在偷听你吗？）— v3

只说公开的检测、研究、监管文件和平台自己的说明；不点名任何 App 偷听或没偷听，不说「绝对没有」。


**v3 变化：** 片中不再出现检测实验室结论、耗电约 27%、状态栏小圆点，也不放进置顶评论（下表相关几行保留作背景资料，标「v3 不用」）。新增两句：

**背景资料（v2）：**

| 片中说法 | 依据 | 来源 |
|---|---|---|
| （v3 不用）「要偷听，麦克风就得一直开着」「那样，手机会发烫，耗电快将近三成」 | 中国电子技术标准化研究院网安中心测评实验室的实验：「一旦手机被『偷听』，手机耗能会异常增加，出现掉电过快、发热发烫、CPU和内存占用高等现象。通常情况下，如果手机处于『偷听』状态下，其耗电速度会比正常情况快27%左右。」**「将近三成」= 约 27%** | 中华网 2024-12-05（何延哲，该实验室副主任）；新华网 2026-08-10 转载「保密观」：「持续后台录音会致使手机耗电速度较正常加快约27%，并伴随明显的发热和卡顿」 |
| （v3 不用）（备用，片中未说）后台录音会被系统切断 | 「如果App进行『偷听』，超过1分钟会被操作系统切断」「麦克风权限只能被当前位于前台或最后使用的App占用」 | 同上（中华网 2024-12-05；新华网 2026-08-10「后台一分钟切断机制」） |
| （v3 不用）「屏幕角上还会亮起一个小圆点」 | iOS 14 起，App 使用麦克风时状态栏亮橙色圆点（用摄像头时亮绿色）；Android 12 起，用摄像头或麦克风时右上角亮绿色指示，可点开看是哪个 App。**国产安卓系统的样式各家略有不同**，片中只画「小圆点」 | Apple 支持文档「iPhone 状态栏中的橙色和绿色指示器」；Android 开发者文档「Privacy indicators」；新华网 2026-08-10「状态栏的亮点提示实时显示麦克风调用状态」 |
| （v3 不用）「国内的检测实验室专门测过：没发现哪个应用，真把你的声音传走」 | 「通过实验检测并未发现哪款App存在真正意义上的将语音信息上传之后的偷听行为。」「根据实验结果可以判断，App几乎不存在偷听的可能性。」**说法是「没发现」，不是「不可能」** | 中华网 2024-12-05（引央视新闻此前报道及何延哲的说法）；新华网 2026-08-10：「『技术上可行』不等于『现实中普遍发生』」 |
| （v3 不用）（置顶评论用）国外的研究也一样 | 美国东北大学等 2018 年分析 17,260 个安卓应用（Google Play 及国内应用商店），没发现应用偷偷开麦克风把录音传出去；但发现个别应用的第三方组件会录屏、截屏传给第三方 | Pan, Ren, Lindorfer, Wilson, Choffnes, *Panoptispy*, PETS 2018 |
| （v3 不用）（置顶评论用）有人吹过能偷听，结果是假的 | 美国一家广告公司 Cox Media Group 宣传「Active Listening」，声称能听人们对着设备说的话来投广告。美国联邦贸易委员会（FTC）2026-05-21 公布和解：按其起诉书，这项服务「根本没有偷听消费者的对话，也没有使用任何语音数据」，实际是加价转卖从数据经纪商那里买来的邮件名单；该公司需支付 88 万美元（三家共 93 万）。**和解不代表认罪，是 FTC 的指控** | FTC 新闻稿 2026-05-21（ftc.gov/node/332281）；Gizmodo 2026-05-22 |
| 「它根本不用听」 | 法院和检测方的说法：平台「根据用户的浏览偏好、使用记录等进行收集和标记，形成用户画像，并据此进行广告投放」；「发生广告个性化推荐结果并不意味着App实施了监听」 | 北京互联网法院 2021 年判决（见中华网 2024-12-05 引述）；新华网 2026-08-10：「App根据用户平时使用习惯进行分析，形成多维用户画像，并据此进行个性化推荐」 |
| 「它根本不用听，它有别的线索」 | 见上一行：法院、检测方都说广告推荐来自浏览偏好、使用记录等形成的画像。微信团队 2020 年回应「监听聊天推广告」的传言：不会监测聊天记录，广告标签针对的是用户群体，广告主选的人群范围很广，广告和聊天内容相似属于正常的概率事件 | 微信「谣言过滤器」2020-06（澎湃转载）；中华网 2024-12-05；新华网 2026-08-10 |
| 「三天前，你在一条空气炸锅视频上，停了六秒」 | **示意情景**：停留是公开说明里列出的行为信号（见上一集 FACTS：抖音安全与信任中心「看完优于没看完」）。「6 秒」「三天前」是编的例子 | — |
| 「刚才饭桌上，你朋友顺手搜了一句：空气炸锅哪款好？」 | **示意情景**：搜索是最直接的兴趣信号；主流广告平台的「行为」定向可按搜索等行为选人（行为天数 7–365 天） | TikTok for Business「兴趣与行为定向」；巨量引擎营销 API「行为天数」参数 |
| 「你们连着同一个 Wi-Fi，坐在同一张桌边——在系统眼里，可能就是一伙的」 | **证据最弱的一条，片中用「可能」**。①同一个路由器后面的设备对外共用一个公网 IP，广告行业把 IP 当作「一户人家」的半固定标识来投放（IP targeting）；②2015 年一项移动广告实证研究观察到，有些广告几乎只出现在同一网络里的设备上，推测是依据同一网络里别的流量来投的（作者也说具体方法不清楚）；③国内有判决认定 App 曾在未获同意的情况下收集位置、社交关系等用来推荐「可能认识的人」（北京互联网法院，抖音案，2020）。**国内哪个 App 是否、如何用同一网络来投广告，没有公开** | Book & Wallach, *An Empirical Study of Mobile Ad Targeting*, arXiv:1502.06577 (2015)；AdExchanger「The marketer's guide to IP addresses in connected TV」；中新网 2020-07-30 报道北京互联网法院「可能认识的人」案判决 |
| 「再加上一天刷几百条，沾边的总会冒出来；你只记住了猜中的那一次」 | 两个心理现象：说出口之后才开始注意这类内容，以为它突然变多了——「频率错觉」（Zwicky, 2005，牛津英语词典收录）；以及只记得应验的、忘了没应验的（确认偏误）。微信团队也把「广告恰好和聊天内容相似」解释为概率巧合。**「几百条」是概括说法；画面里「今天已刷 312 条」是示意数字** | Arnold Zwicky, Language Log, 2005；微信「谣言过滤器」2020-06 |
| 「你以为它听见了你说的话；其实，是你和你身边的人，先替你开了口」 | **比喻**，概括上面三条线索 | — |
| 「去设置里，关掉『个性化广告』——法律规定，必须给你这个开关」 | 《个人信息保护法》第二十四条：「通过自动化决策方式向个人进行信息推送、商业营销，应当同时提供不针对其个人特征的选项，或者向个人提供便捷的拒绝方式。」《互联网信息服务算法推荐管理规定》（2022-03-01 施行）第十七条：「应当向用户提供不针对其个人特征的选项，或者向用户提供便捷的关闭算法推荐服务的选项。」**「必须给你这个开关」是概括说法：法律要求二选一（不针对个人特征的选项，或便捷的拒绝方式）** | 《中华人民共和国个人信息保护法》（2021）；国家网信办等《互联网信息服务算法推荐管理规定》 |
| 「广告不会变少，但它就不能再照着你来猜了」 | 微信关闭个性化广告页面的说明：关闭后看到的广告数量不会减少，但不再展示个性化广告，广告相关度可能降低；淘宝负责人也表示数量不变 | 钛媒体、红星资本局等对各平台关闭页面的报道（2023）；以各 App 当前版本的说明为准 |
