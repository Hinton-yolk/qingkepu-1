# 「你按下去之后」· 你把验证码念出去之后 — 脚本 v1（待确认）

这一集按新规矩做：
- **第 0 帧就是具体的问题**，画面里只有一个主角：你的手机和那条验证码短信。
- **第 4–7 秒反转**：「你以为……」整屏刷橙红，「其实……」打叉。
- **全片围着同一部手机转**：第二部手机从侧面滑进来，不换场景。
- **大字就是内容**：一屏一句，静音也能看懂。
- **时长 40–50 秒**；浅米色纸底、平面剪纸、一个强调色（橙红）。
- 两个版本：**旁白版**（约 47 秒，大字和旁白同步，不再另加小字幕）和**大字 + 音乐版**（约 38 秒，没有旁白）。两版画面相同，只是大字措辞和节奏不同。

## 拆题四问

| 问 | 答案（一个机制） | 演示画面 | 「哦」 |
|---|---|---|---|
| 1 你以为 | 验证码只是一串随机数字，念出去也没什么 | 六个数字从短信里飘出来；整屏刷橙红，数字乱跳 | — |
| 2 其实 | 每个验证码背后都绑着一件具体的事：有人在某台手机上发起的那一笔操作 | 一个大叉划掉「随机」；数字底下垂下一根线，拴着一张单子「转账 ¥5,000」 | 哦！验证码不是随机的，是为某件事发的 |
| 3 演示（必须演示） | 别人在另一台手机上点「转账」→ 系统认准账户是你的，把验证码发到你手机 → 他打电话「我是客服，给你退款，报一下验证码」→ 你一念，他一输 → 系统当成你本人确认 | 一部灰色手机从右边滑进来，手指点「转账」；验证码落进你的手机；电话气泡；数字从你这边飞到他那边，输入框填满，盖章「本人确认 ✓」，钱从你的手机里被拽走 | 哦！我念出去的那一下，就是替他按了确认 |
| 4 又意味着什么 | 验证码不是密码，是一张「同意书」：谁拿到它，谁就能替你按下确认。收到先看短信说的是什么事，不是你刚发起的就别念；也别给陌生人开屏幕共享 | 六个数字合成一张纸「同意书」，下面签着你的名字；短信里的「转账」两个字被圈出来；屏幕共享的画面里，数字被对面看得一清二楚 | 原来还可以这样：先看清是什么事 |

**核心机制（只讲一个）：验证码 = 你对某一笔具体操作的「同意」，谁输入它，谁就替你按了确认。**

**一镜到底：** 你的手机居中（第 0 帧）→ 数字从短信里飘出 → 整屏刷橙红（你以为）→ 打叉、刷回米色（其实），数字下面拴出一张「转账」单 → 镜头微微拉开，灰色手机从右边滑进来 → 电话气泡 → 数字飞过去、输入、盖章、钱被拽走 → 数字合成「同意书」→ 推回你的手机，短信里的用途被圈出 → 屏幕共享的小插曲 → 回到第 0 帧同一构图，数字落回短信里。

**每一镜的「心跳」：** 那六个橙红色的数字一直在画面里（飘、跳、飞、合成、落回），全片的视觉主线。

**情绪曲线：** 不以为然（就是串数字）→ 意外（它绑着一笔转账）→ 紧张（电话响了）→ 原来如此（念出去 = 替他按确认）→ 原来还可以这样（先看清是什么事；别开屏幕共享）→ 回扣标题

## 开头：三个备选

| | 画面 | 为什么停得住 |
|---|---|---|
| **A（推荐）** | 第 0 帧是浅底大字问题 + 你的手机居中，一条验证码短信，数字很大；第 1 秒起数字从屏幕里飘出来；第 4 秒整屏刷橙红「你以为」，第 6 秒打叉「其实」 | 每个人都收过这条短信，一眼就认出来；问题具体；7 秒内反转 |
