**核心机制（只讲一个）：你还没划，下一条已经被挑好、下载好了；挑它的依据，是你刚才停留的每一秒。**

**一镜到底的路线：** 床上，你手里的手机（第 0 帧）→ 镜头穿过屏幕，看到后面排着的两三张卡片（已下载）→ 跟着你的「停留信号」从手机飞出去，飞过城市，进入机房 → 机房里一整面视频墙（海量）→ 一个漏斗把它收成一小批 → 每张卡片上跳出「看完 / 点赞 / 评论 / 分享」几个概率条 → 分数最高的几张飞回你的手机，插进队列 → 你一划，下一条秒开 → 镜头退回床上，和第 0 帧同一构图，只是屏幕里换成了刚才被挑出来的那一条。

**每一镜的「心跳」：** 屏幕上一直在走的进度条和「停留秒数」读数；飞回机房的那个信号；漏斗里不停流下的视频卡片；跳动的概率条。

**情绪曲线：** 放松（睡前刷视频）→ 惊讶（下一条已经在了）→ 好奇（谁挑的？）→ 原来如此（是你自己）→ 越来越大（每刷一会儿就跑一遍）→ 反转（视频也在刷你）→ 原来还可以这样（别盯着看，点「不感兴趣」）→ 余味（挑它的就是你自己）

## 需要你拍板的两件事

1. **标题：** 用「你上划之前」作主标题。它和系列模板「你按下……之后」反过来，正好说明这一集讲的是你划之前就已经发生的事。也可以统一成「你上划之后」，但那样就丢了「它早就在了」这个钩子。
2. **分寸：** 这一集讲的是平台自己公开过的通用原理（预加载、召回、排序、预估点赞/看完的概率、「不感兴趣」是负反馈），**不碰**任何没公开的权重和参数，也不下「算法在操控你」这类结论。「视频也在刷你」是比喻。
