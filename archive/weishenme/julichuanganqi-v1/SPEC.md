# SPEC — EP.04 距离传感器 v1

GOAL:   看完的人能复述：屏幕不是被脸碰黑的；听筒旁边一盏看不见的灯一直往外照，脸一靠近光就弹回来，旁边的"眼"看到了，
        多过一条线就关屏；太阳光不跟着闪，被减掉；关屏是为了不让脸碰到挂断。
TIME:   59.75 s，120 BPM；第一次黑屏 2.0、打叉 8.0、名词 36.0、还差一步 38.0、闭环黑屏 50.0 在小节线上。
