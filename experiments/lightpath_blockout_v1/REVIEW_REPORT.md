## 2. 画面约定
- Workbench 灰盒：物体纯色、棚拍基础光、黑色轮廓线、轻微腔体阴影和投影。没有景深、运动模糊、字幕、标签、UI、旁白。
- 硬件中性灰；PCB 暗绿；阻焊下的走线是浅一点的绿（**不画成铜色**，免得和琥珀色的电信号混）。
- 电信号：克制的琥珀色。光信号：克制的青色（红外光本来看不见，青色是示意）。
- **同一个 8 位数据包 `1 0 1 1 0 0 1 0`** 贯穿全片：在走线上是琥珀色的四段短条，在波导和光纤里是青色的四段短条，回到电路板上又是琥珀色。观众不需要读懂比特，只看到「同一个图样换了一种载体」。
- 每一段信号指示都画在真实的物理路径上（走线、键合线、片上馈线、波导、光纤纤芯），不在空中飞，不是发光小球。
- 每一拍里信号都按恒定速度走；各镜头的速度不同（每镜相当于不同的慢放倍率，真实传播是纳秒级）。同一个镜头内，同一个比特在电和光里**时长相同、长度不同**。S03 里光段的短条比电段短，对应「硅波导里的群速比 PCB 上的电信号慢」，这一点只对硅波导成立；S03 里模块内光纤那一小段沿用了波导的速度，S04 光缆里的速度也只是镜头节奏，**都不代表真实光纤里的速度**（真实光纤里约 2×10⁸ m/s，比 PCB 上快）。

## 3. 空间布局（一个连续的世界）
- 两个开放式四柱机柜并排，前面朝 +Y（相机所在的通道）。A 在 x = +32，B 在 x = −32，所以**从机柜正面看 A 在左、B 在右**，S04 和 S06 的远景里数据从画面左边走到右边（顺着阅读方向）。两侧还有四个远景机柜。
- 两台**同型号**的 2U 服务器装在各自机柜的最上层，顶盖拿掉（维护状态）。板上：后部是主机 CPU 和内存，中间是两颗 GPU（GPU A / GPU B 是靠 +X 的那颗，另一颗是同板的邻居加速器），前面是 NIC，最前面板边是三个 OSFP 笼子，入口和机箱 I/O 面板平齐略伸出。
- 光模块从机箱外插入笼子，前脸朝外，MPO 插头插在前脸上（按 11-14 决定，装配方向在灰模阶段就核对过）。
- 光纤：A 模块前脸 → 向前 → 下弯进顶层服务器下面的 1U 理线槽 → 沿槽横穿到 B 机柜 → 上弯 → B 模块前脸。全长约 100 cm，弯曲半径约 3.5 cm。
- A 板上数据向 +Y 走（GPU → NIC → 笼子），B 板上向 −Y 走（笼子 → NIC → GPU）。相机在电路段总是跟在信号后面，所以信号在画面里一直「往前、往画面上方」走。


## 4. 逐镜头说明（全局帧 / 局部帧 F001–F150）

### S01 DEPARTURE · 全局 1–150 · 00:00–00:05
- **主事件**：GPU A 硅片从「计算中」的浅灰回到深灰（约 F030–F048，计算结束）；F052 起，封装前沿、故事那对走线的起点出现一小块琥珀色（高速接口准备发送），轻微呼吸；F100 数据包出发，四段琥珀色短条沿差分对向 NIC 走，约 F143 头部进入 NIC。
- **相机**：F001 三分之四高位俯视 GPU A 封装（看得到旁边的另一颗加速器、供电电感、板上元件）→ F030–105 斜向推近通信电路 → F106–135 压低到走线起点后方 → F136–150 落在走线上，走线指向画面上方的 NIC。
- **结尾构图**：走线从画面下方伸向上方的 NIC 封装，方向就是下一镜的前进方向。

### S02 THE ELECTRICAL PATH · 全局 151–300 · 00:05–00:10
- **主事件**：同一个数据包沿差分对前进，经过 NIC A（NIC 硅片在数据经过时微微偏琥珀色，表示 SerDes 在重新驱动这些比特），出 NIC 后走过每条线上的 AC 耦合电容，约 F144 头部进入笼子后部的连接器。
- **相机**：F001 贴着 PCB（离板约 1.2 cm），差分对在前景 → F025–100 沿走线向前跟拍，越过 NIC 时稍微抬高 → F101–130 前方露出三个 OSFP 笼子（中间那个是本链路的）→ F131–150 减速，停在笼子后部、走线进连接器的地方。
- **视差**：前景走线、电容、过孔和远处的笼子、机箱面板分层移动。

### S03 ELECTRICAL → OPTICAL · 全局 301–450 · 00:10–00:15
- **剖视**：这一镜里隐藏三件东西：A 笼子顶板、A 模块顶盖、机箱面板在这个笼子上方的一小段（`CHASSIS_A_face_top_lane`）。其它镜头里它们都在。
- **主事件（因果链）**：
  1. 琥珀色数据包沿模块内的差分走线进入驱动器（驱动器硅片在数据经过时偏琥珀色）；
  2. 从驱动器经键合线、片上 RF 馈线到调制器电极，电极按比特变色（灰 = 0，琥珀 = 1），约 F040–F104；
  3. 激光器从第一帧起就一直向波导送出**不变的**暗青色光载波，经分束器进入两臂；
  4. 合束后的输出波导里出现明亮的青色短条，节奏和电极的亮灭一一对应，同一个 `1 0 1 1 0 0 1 0`；
  5. 青色短条进入光纤阵列，沿模块内的光纤走向模块前脸的 MPO 插座。
  - 画面上不出现「电子变成光子」：电只出现在金属上，光只出现在波导和光纤里，两者唯一的接触点是电极旁的那一段臂。
- **相机**：F001 从模块后方高处同时框住驱动器、激光器、调制器和出光波导 → F041–105 向右横移并小幅环绕，看出芯片、键合线、光纤阵列的高度差 → F106–130 推近合束器和耦合区 → F131–150 停在通向光纤的出光路径上（光纤朝画面上方，指向模块前脸）。

### S04 THE OPTICAL PATH · 全局 451–600 · 00:15–00:20
- **主事件**：青色数据包从 A 模块前脸的 MPO 插头出来，在光缆纤芯里走完整条路线（A 前脸 → 下弯进理线槽 → 横穿到 B 机柜 → 上弯 → B 前脸），约 F125 头部到达 B。光缆外皮半透明，光只在纤芯里，不在空气中。
- **相机**：F001 在 A 模块前上方，看插头和离开的光缆 → F031–110 拉高、退到机柜前方，沿光缆方向越过两台机柜（尺度从厘米级跳到米级，看得到开放式机柜、下层服务器、理线槽、远处的机柜）→ F111–135 沿理线槽向 B 靠近 → F136–150 落在 B 模块的 MPO 插头上，光缆从画面下方进入插头。
- 相机全程在机柜前方的空中，没有穿过任何设备（第 6 节的检查）。

### S05 OPTICAL RECEPTION · 全局 601–750 · 00:20–00:25
- **剖视**：隐藏 B 笼子顶板、B 模块顶盖、B 面板对应的一小段。
- **主事件**：青色数据包沿 B 模块里的接收光纤 → 光纤阵列 → 输入波导到锗探测器；探测器被光照到时变成青色（F045 起，节奏和到达的光一致）；同时从探测器的输出走线开始出现琥珀色短条，经键合线进 TIA（TIA 硅片偏琥珀色），再沿模块走线流向金手指和主机连接器。
- **和 S03 的呼应**：同一型号的模块、同样的高位剖视，但相机从模块前方往后看（S03 从后往前看）；S03 是「琥珀电极 → 青色输出」，S05 是「青色输入 → 琥珀输出」。
- **相机**：F001 框住进来的光纤、光纤阵列、探测器和旁边的 TIA → F036–095 慢推并小幅横移到探测器 → F096–125 横移露出琥珀色信号离开探测器、进 TIA → F126–150 停在流向连接器的电走线上。

### S06 ARRIVAL · 全局 751–900 · 00:25–00:30
- **主事件**：琥珀色数据包从 B 笼子连接器出来，沿差分对 → NIC B（硅片微微偏琥珀）→ 差分对 → 约 F095 到 GPU B 封装前沿；F110 起 GPU B 封装前沿留着一块柔和的琥珀色（已到达），GPU B 硅片变成「工作中」的浅灰。F108 起光缆纤芯慢慢亮出一条连续的青色（这条光链路是连通的）。
- **相机**：F001 在 B 笼子后方，沿走线看向 NIC B → F036–100 跟着走线到 GPU B → F101–135 升高、后退 → F136–150 停在两台机柜的高位正面全景：左边是 A 服务器（较远），右边是 B 服务器（较近、较大，GPU B 在右侧板上），中间偏下是两只模块和连通它们的光缆：从 A 模块前脸下到理线槽、向右走到 B 模块前脸。
- **和 S01 的呼应**：S01 从 GPU A 出发，S06 落在 GPU B，并把 GPU A 放回同一个画面里，交代「两端是被这条光链路连起来的」。

## 6. 自检结果（任务书第 8 节）
1. **每镜一个主事件**：是（见第 4 节）。
2. **有意义的 3D 运动**：是。每镜的相机都有平移（推、跟、横移、升降），不是原地转。S03 / S05 的横移让芯片、键合线、光纤阵列之间的高度差显出来。
3. **主体全程可读**：大体是。不足见第 8 节（S02 越过 NIC 的约 0.5 秒、S04 开头、S06 结尾 GPU B 偏小）。
4. **穿模 / 不连续运动**：
   - 脚本逐帧检查 900 帧：相机位置是否落在任何可见方块物体里面或 0.2 mm 以内——**没有**（`build_scene.py -- check`）。曲线物体（走线、光缆、键合线）没有纳入这项自动检查，靠看接触表和关键帧。
   - 相机全部是 Bezier 关键帧，没有跳变；镜头前后各多一个关键帧，第一帧已经在动，最后一帧还在缓慢落定。
   - `tools/motion_check.py`：总片和六个单镜头都 PASS（静止帧 0%，最长静止 0 秒）。
5. **转场保持信号方向和物体关系**：是（第 5 节）。
6. **每镜第一帧可以当照片级改图的底**：S01、S02、S03、S05、S06 是；S04 第一帧偏弱（第 8 节）。
7. **开头、升级、技术转换、结尾**：S01 出发 → S02 电的路（升级为跟拍）→ S03 电控光（技术高潮）→ S04 尺度跃升到机房 → S05 光变回电（反向呼应）→ S06 到达 + 全景收束。

## 8. 已知问题（如实列出）
1. **S06 结尾 GPU B 不够「大」**。为了把 GPU B、两只模块、光缆和 GPU A 放进同一个竖屏画面，结尾是两台机柜的高位全景。两端的模块和整条光缆都在画面里，B 服务器比 A 近、比 A 大，但 GPU B 只占右侧一小块，B 板的右边缘被画面切掉一点，画面上方约三分之一是背景。根本原因：两台服务器左右并排、数据路径沿前后方向，在 9:16 里很难同时「GPU B 很大」又「看得到整条链路」。可选的改法（请导演定）：
   - A. 保留现在的全景，在 GPT 照片阶段用光线 / 景深把视线引到 GPU B；
   - B. 结尾改成 GPU B 特写 + 背景里虚化的光缆，不交代 GPU A；
   - C. 把两台服务器改成同一机柜上下相邻、抽出在维护位，竖屏里上下排列。
2. **S04 第一帧偏弱**：从上方看，光缆先向前再向下的弯折像一个「钩子」，背景是 190 cm 以下的地面，没有机柜语境。可以改成更低的机位，从侧面看插头和下垂的光缆。
3. **S04 远景的光缆偏细**：已把外皮改成深灰半透明、加粗到直径 4.4 mm，远景里能看出一条深色线和里面的青色短条，但在手机尺寸上仍然细。照片阶段可以加强。
4. **S02 越过 NIC 的约 0.5 秒（局部 F025–F040）**：相机贴得低，NIC 封装占满下半个画面，硅片的琥珀色偏重。
5. **S01 F060–F090**：相机从 GPU 封装边上压过，封装加强框占了画面下部一大块灰色。
6. **审核提出、已改**：第一版里 A 在右、B 在左，远景里数据从右往左走，和阅读方向相反；已把两台机柜对调重渲（第 3 节）。
7. **剖视只存在于 S03 / S05**：笼子顶板、模块顶盖和面板的一小段只在这两镜隐藏；如果后期把 S02 结尾和 S03 开头做成连续镜头，需要在镜头里交代「剖开」。
8. **S05 结尾**看的是模块走线流向笼子连接器，琥珀色短条在画面里偏小。
9. **整体偏暗、偏灰**（Workbench 灰盒）：这是为了给照片阶段留余地，不代表最终色调。

## 9. 刻意的简化（行家会注意到的地方）
- **点对点链路**：GPU A → NIC → 模块 → 光纤 → 模块 → NIC → GPU B，中间没有交换机。这是任务书要求的讲故事抽象，不表示真实集群里 GPU 之间不经交换机。
- **GPU 到 NIC 直接走板上差分线**：真实的 8 卡服务器里 GPU 在 HGX 一类的基板上，NIC 多在单独的 PCIe 卡或夹层卡上，中间经过 PCIe 交换芯片；这里压缩成同一块板上的一段走线。
- **差分对两根线画成同样的琥珀短条**：真实差分信号两根线上的电压极性相反。
- **只画了一个通道**：800G 模块是 8 × 100G，板上和模块里实际有 8 对发送、8 对接收；画面只让其中一对 / 一路发亮。
- **MPO 光缆只画了一根纤芯在发光**：真实 MPO 跳线里有 8 或 16 根光纤，这里不区分。
- **服务器没有顶盖，GPU、NIC 没有散热器**：为了看得见封装。真实运行时都有。
- **线性直驱模块（类似 LPO），没有 DSP**：现在很多 800G 可插拔模块在连接器和驱动器之间有一颗 DSP。省掉它是为了让「驱动器 → 调制器」的因果一眼看清。
- **开关键控**：画面用「亮 / 暗」两级表示 1 / 0。真实 800G 模块多用 PAM4（四个电平）；而且「0」也不是完全没光，只是比「1」暗（有限的消光比）。
- **亮度不代表功率**：载波是暗青、调制后的「1」是亮青，只是为了区分「未调制」和「调制后」；真实情况下调制器输出的光功率不会比输入大。
- **单臂驱动的马赫-曾德尔调制器**：信号电极只画在一条臂旁边；真实的硅光行波调制器常用差分推挽和 GSG 电极，电极直接做在臂的 PN 结上。
- **激光器画成芯片上的一个小块**：真实方案有片上键合的激光器，也有外置激光源经光纤送进来。
- **尺寸放大**：波导画成约 0.25 mm 粗（真实约 0.5 µm 宽，放大约 500 倍）；硅光芯片 17 × 18 mm 偏大；模块内光纤间距、光纤阵列都放大了。差分走线 0.7 mm 宽也偏宽。
- **模块外形**：按 OSFP 量级做（约 100 × 22.6 × 13 mm），**待核**；真实 OSFP 顶面有集成散热鳍片，这里没做。
- **时间**：每镜相当于不同的慢放倍率（真实信号在纳秒内走完这些距离）；镜内速度恒定。
- **光的颜色**：青色是示意，真实是看不见的红外光（数据中心常用 1310 nm 或 850 nm 一带）。
- **模块 A 只画 TX 通道在工作，模块 B 只画 RX 通道在工作**：真实模块双向同时工作，激光器也一直开着。为了不让画面里出现两股方向相反的光，另一方向的通道保持暗。
