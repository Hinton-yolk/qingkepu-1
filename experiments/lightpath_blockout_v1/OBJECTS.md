# 物体身份表 · PROJECT LIGHTPATH Blockout V1.0

`lightpath_blockout.blend` 里的集合（Collection）和真实硬件的对应关系。单位 1 BU = 1 cm。
A、B 两台服务器、两只光模块是**同一个型号**，几何完全一样，只是位置不同（A 在 x = +32，B 在 x = −32；从机柜正面看 A 在左、B 在右）。
「不是精确工程尺寸」：下面的尺寸是为了比例看着合理，凡是凭记忆的都标了 **待核**。

| 物体 | 表示什么 | 颜色 |
|---|---|---|

| `SIG_E_A_launch_PHY` / `SIG_E_B_arrival_PHY` | GPU 封装边上的高速接口区：出发前的预备 / 到达后的状态 | 琥珀 |
| `MODULATOR_electrode_signal`（变色） | 电极上加了「1」的电压 | 灰 → 琥珀 |
| `SIG_O_TX_carrier_*`、`SIG_O_TX_laser_emitting_facet` | 激光器不变的光载波（未调制） | 暗青 |
| `SIG_O_TX_out_*`、`SIG_O_fiber_*`、`SIG_O_RX_in_*` | 调制后的光：同一个 8 位图样 | 青 |
| `PHOTODETECTOR_Ge_PD`（变色） | 探测器正被光照到 | 灰 → 青 |
| `SIG_O_fiber_link_core` | 片尾：这条光链路连通（S06 后段慢慢显出） | 青 |
| NIC / 驱动器 / TIA 硅片（变色） | 数据正经过这颗芯片 | 深灰 → 偏琥珀（弱） |

| GPU B 硅片 | 到达后变成「工作中」的浅灰 | 中性灰 |

## 相机
`CAMERAS` 集合：`CAM_S01_departure` … `CAM_S06_arrival`，每台相机有一个注视目标空物体 `CAM_*_target`（Track To 约束）。
关键帧是 Bezier（Auto Clamped），可以直接在 Blender 里改。每台相机在镜头前后各多一个关键帧（局部 −10 和 162 帧），让第一帧已经在动、最后一帧还在慢慢落定，不是死停。
主场景 `LIGHTPATH_master` 用时间轴标记切换相机；另有 6 个镜头场景 `SHOT_S0x_*`，共用同一套集合，帧范围就是该镜头的全局帧，可以单独渲染。
