# Seedance PoC 02 · 动态摄影机 + 独立物体运动 Blockout

验证：在 Blender 里同时控制两条独立的运动——摄影机绕固定笼子走约 60° 的弧线，光模块沿笼子轴线直线插入——并让它们在一个连续镜头里形成清楚的三维空间关系。
独立目录，不改 PoC 01。本机 CPU，Workbench 灰盒渲染，费用 $0，没有调用 Seedance。

## 检查（正式出片前）
- **相机确实沿弧线移动**：相对固定的笼口，方位角从 43.5° 转到 -16.5°（共 60.0°），仰角 26.9° → 14.8°，距离 21.4 → 9.3。相机位置实际走了约 20.4 个单位，不是原地摇镜。
- **空间视差**：挡板（前景）和散热器（后景）在画面上的相对横向位置错开了约 1.28 个画面宽。
- **模块沿固定轴线插入**：只改 y，x、z 和朝向全程不变。
- **两条运动没有互相掩盖**：插入段里，模块相对笼口在画面上走了 0.67，笼口自己因为相机移动只走了 0.28。
- **构图**：每个时间点都用投影算了模块和笼口离画面边缘的距离，全程不出框（最小 0.046 个画面宽）。每 0.25 秒一帧看完整段确认过。
- **视觉落点**：结尾在右前方低机位，和开头的左前高机位明显不同；模块前端、笼口、相邻空口和散热器都能辨认。
- `tools/motion_check.py`：静止帧 4%，最长静止 0.20 秒，**通过**。
- 规格（ffprobe）：720×1280，30/1 fps，180 帧，6.000 秒，无音轨。

制作过程中修过的问题：
1. 第一版 66° 侧面起拍，模块在竖屏里横着放不下，出框；
2. 注视点按时间漂移，模块还没动镜头就先走了，模块出框，改成跟随装配段的中点；
3. 一块竖直的背景板被侧光照亮，像一根柱子，去掉了；
4. 挡板太高太亮，挡住了笼子，降低并改成深色；
5. 起初相对注视点转了 60°，但相对固定笼口只有约 49°，放宽两端角度后才到 60°。

## 导演自评

**这次镜头想做的事**：让观众「绕着一次装配走半圈」。开头在左前方高处看清全局：两个口、一根待插的模块、后面的板子。插入时镜头一边绕一边降，模块在世界里笔直地往里走，参照物是那块不动的挡板。最后镜头停在另一侧的低机位，像蹲下来看一个刚刚完成的连接。

**相比 PoC 01 新增的视觉价值**
- **立体感**：PoC 01 的视角只变了约 6°，基本是一个推镜。这次转了 60°，模块和笼子从「斜侧面」转到「正面略偏另一侧」，观众看到了物体的三维形状，而不只是越来越大。
- **视差层次**：前景挡板、中景笼子和元件、后景散热器，三层以不同速度错开，空间纵深是「算出来的」，不靠景深和光效。
- **运动更好读**：插入有了一个固定参照面（挡板）。镜头怎么转，模块「穿过挡板上的口」这件事都看得清。
- **科学修正**：插入方向改对了（从机箱外插，接口朝外），还带出了「双口网卡」的上下文。

**自评打分（1–10）**
| 项目 | 分数 | 说明 |
|---|---|---|
| 弧线运动的可辨性 | 8 | 视差明显，方向变化清楚 |
| 插入动作的可辨性 | 7 | 前半段很好读；约 4.1 秒相机越过插入轴线时，模块的运动几乎正对镜头，只剩「前端靠近挡板」这个线索 |
| 两条运动的分离 | 8 | 模块自身位移是笼口画面位移的两倍多 |
| 开头构图 | 6 | 高机位侧看，上方和右下有大块空暗区，主体偏小；为了让整根模块不出框做了让步 |
| 结尾落点 | 8 | 和开头反差明显，前端、笼口、邻口都清楚 |
| 科学合理性 | 7 | 方向对了；但挡板做矮了（示意），真实挡板会挡住大部分板子 |

**可以再改的**：开头可以再近一点，让模块的一部分出画、只保留前端和笼口，构图会更紧。代价是第一帧看不到整根模块，和任务书「同时看到插槽、模块和 PCB」有冲突，所以这版没改。

## 可能给 Seedance 复现带来的困难
1. **把相机运动和物体运动搅在一起**：视频模型常把「镜头绕着转」理解成「物体在转」，或者让模块「粘」在镜头上跟着走。这次两条运动同时进行，是最大的风险。
2. **约 4.1 秒越过插入轴线**：这时模块几乎正对镜头运动，只能靠大小和前端与挡板的距离判断。模型可能把它读成「模块停了」或「变大了」。
3. **复合运动被简化**：60° 环绕 + 下降 + 推近同时发生，模型可能退化成平摇或变焦，丢掉真正的位移视差。
4. **挡板高度和参考图冲突**：Blockout 里的挡板是故意做矮的。如果参考图里是完整的 PCIe 挡板，模型可能做出高挡板，把笼子和板子挡住，或者两者折中出奇怪的结构。写 Prompt 时要说清楚，取舍先由你定。
5. **遮挡关系要连续**：模块穿过挡板开口那一刻，开口、笼口和模块要始终对齐。生成模型容易在环绕中让开口漂移，或让模块从板外穿过去。
6. **相邻的空口**：模型可能自作主张给它也插一个模块。
7. **模块悬空**：没有手，模块从空中滑进去，模型可能补一只手，或者让它掉下来。
