# 信号层单独导出：可行性试验（V1.1 任务 4B）

## 场景怎么分的
`lightpath_blockout_v1.1.blend` 的集合：
- `LIGHTPATH/HARDWARE`：全部硬件和环境。**硬件本身不再有任何颜色动画**（V1.0 里 NIC、驱动器、TIA、电极、探测器是给硬件本身变色，V1.1 改成在它们上面盖一层薄的「状态层」物体）。硬件上剩下的动画只有剖视用的显隐（S03 / S05 隐藏一只模块和笼子的顶盖、侧壁，以及面板上的一小段）。
- `LIGHTPATH/SIGNALS_ELECTRICAL`：琥珀色数据包（走线、键合线、片上馈线上的短条）、芯片「正在处理」的状态层（NIC、驱动器、TIA、电极）、GPU 封装边上的出发 / 到达标记、GPU 硅片上的 4 × 4 计算小块。
- `LIGHTPATH/SIGNALS_OPTICAL`：激光载波、调制后的光短条（波导、模块内光纤、光缆）、探测器受光的状态层。
- `LIGHTPATH/CAMERAS`：6 台相机和注视目标。
信号的时序和 V1.0 一样，同一个 `1 0 1 1 0 0 1 0`；只有 S01 / S02 / S06 的出发和到达时刻按导演意见提前了（见修订报告）。

## 怎么导出只有信号的透明层
Workbench 不支持「遮挡但不显示」（holdout），已试过，硬件照样渲出来。所以用两次很简单的渲染代替：
1. `sig_color`：硬件全部涂成不透明黑色（半透明的光缆外皮保留透明度），平光、无描边、黑背景。得到「信号颜色 × 覆盖率」，被硬件挡住的部分自然是黑的，遮挡是对的。
2. `sig_cov`：同上，但所有信号物体涂成白色，得到每个像素的覆盖率，也就是 alpha。
3. 两张在线性光下相除，得到普通（非预乘）透明度的 RGBA PNG（`sig_overlay_demo.py`）。

另渲一张 `plate`（排除两个信号集合，只有硬件），当作 LTX 出来的画面的替身。

命令（全局帧 341–380 = S03 局部 F041–F080）：
```bash
blender -b --factory-startup --python-exit-code 1 --python build_scene_v11.py -- sig_color 341 380
```
```bash
blender -b --factory-startup --python-exit-code 1 --python build_scene_v11.py -- sig_cov 341 380
```
```bash
blender -b --factory-startup --python-exit-code 1 --python build_scene_v11.py -- plate 341 380
```
```bash
python3 sig_overlay_demo.py 341 380 S03
```
每种 40 帧，本机 CPU 一共约 3 分钟。

## 结果（`deliver_v1.1/signal_overlay_demo/`）
- `rgba/S03_F041…F080_signals_rgba.png`：40 张透明信号层。
- `S03_overlay_demo_4panel.mp4` 和中间一帧 `…_mid.jpg`，四个画面并排：硬件底片 | 信号层（棋盘格上）| 底片 + 信号 | 几何漂移后的底片 + 信号。
- `metrics.txt`：
  - 底片 + 信号层，和正常渲染相比，平均每像素差 3.5 / 255。这个差来自信号层用的是平光颜色，正常渲染里信号有棚拍光和黑色描边，不是位置误差。
  - 把底片放大 1.5 %、平移 6 / 4 像素，模拟 LTX 的几何漂移，平均差变成 5.8 / 255。肉眼上电极的琥珀色已经离开电极、波导的青色离开波导（中间帧第 4 格）。

## 结论和限制
- **可行**：只要 LTX 出来的画面和灰模的几何一致，信号层可以直接盖回去，时序完全由 Blender 决定，不靠 LTX 画。整片 900 帧照这个办法多渲两遍，本机大约 40 分钟，零费用。
- **限制 1：对位。** LTX 的画面不会和灰模逐像素对齐。我们的信号都很细（走线 0.7 mm、波导放大后也只有几个像素宽），几个像素的漂移就会让信号离开它的物理路径，正好违反「信号必须沿物理路径走」。
  - 补救：在 LTX 输出上做二维跟踪或光流，把信号层按跟踪结果变形；或者只在相机慢、结构简单的镜头用叠加。
  - 最稳的做法是让 LTX 自己生成「不带信号的」画面，信号只靠后期叠加；但前提是对位够准。
- **限制 2：遮挡。** 信号层的遮挡是灰模的遮挡。LTX 如果把某个零件画大了、挪了，前景就会和信号层打架。
- **限制 3：光照。** 信号层是平的颜色，不受 LTX 画面的光影影响。合成时需要另加一点辉光 / 色彩匹配，这一步不做在灰模里。
- **限制 4：半透明光缆外皮。** 光缆里的青光在信号层里已经被外皮压暗。LTX 如果把外皮画成不透明，叠上去的光会显得「浮在外面」，这时应该改为把光画在可见的纤芯 / 剖面上。
- 建议的最小下一步：拿 LTX 首测那个镜头的输出，先量一下它和灰模差几个像素，再决定用不用叠加。
