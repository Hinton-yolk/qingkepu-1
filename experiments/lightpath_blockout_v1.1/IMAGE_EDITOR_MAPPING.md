# 给 GPT Image 的物体对照（V1.1 每镜第一帧）

用法：把 `deliver_v1.1/reference_frames/S0x_F001_first.png` 交给 GPT Image 改成照片级画面时，附上对应这一节。
所有镜头都必须保留：相机视角、物体位置、主要轮廓和前后遮挡关系。不要加字、标签、箭头、光晕，不要改构图。
颜色约定：琥珀色短条 = 电信号示意（走线上），青色 = 光信号示意（看不见的红外光，只在波导 / 光纤芯里）。改图时可以保留为克制的示意色，也可以先去掉，之后用信号层（见 `SIGNAL_OVERLAY.md`）合成回去。
