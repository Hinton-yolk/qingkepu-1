# Seedance PoC 01 · 3D Blockout：光模块插入网卡模块笼子

验证的工作流：Claude 做导演规划 → Blender 做极简动态 Blockout → Seedance 根据 Blockout 和文字提示生成写实镜头。
本目录只做第二步。独立实验，不改 T5/T6 和正式电影工程。没有调用 Seedance，没有用付费 GPU，费用 $0。

**当前是 v2**（按 11-14 审阅意见局部修正）。v1 在提交 a7f34f6，可以从 git 历史取回。

## 交付物
| 文件 | 内容 |
|---|---|
| `scene.blend` | Blender 5.2.3 工程：四组物体、相机、注视点空物体、180 帧动画，渲染设置为 Workbench |
| `blockout.mp4` | 6 秒动态预演：720×1280，30 fps，180 帧，H.264，静音 |
| `contact_sheet.png` | 六张关键画面：0 / 1.2 / 1.7 / 2.7 / 4.0 / 6.0 秒。标签只在接触表上，视频里没有 |

| `build_scene.py` | 生成场景的脚本，scene.blend 和视频都由它产生 |

## v2 改了什么（对应审阅的三项）
1. **运动主体完整可见**：注视点跟着「模块外露段的中点」走，相机距离随外露段一起缩短。每 0.25 秒一帧看完整段，模块近端和笼子入口每一帧都在画面内，离边缘都有余量。
2. **主体运动和相机运动分开**：
   - 1.2–1.7 秒相机相对稳定：平均速度 0.61 cm/s，模块 2.16 cm/s，这 0.5 秒里模块进去了 1.08；
   - 模块改成梯形速度（约 0.3 秒加速），所以在稳定段里就能看清它在动；
   - 1.7 秒后相机才开始跟随和靠近。
3. **最终插入位置**：笼子加长到 6.0，模块到位后只露出前端 1.4（全长的约 19%）。4.0 秒停稳以后保持静止，相机再推向前端面。

另外两处小改：起始距离拉近约 18%，主体在竖屏里大一些；PCB 加长，画面里不再露出板边。

## 怎么重做
在本目录运行：
```bash
blender -b --factory-startup --python-exit-code 1 --python build_scene.py -- anim
```
```bash
ffmpeg -y -framerate 30 -i out/frames/f%04d.png -c:v libx264 -pix_fmt yuv420p -crf 18 -an -r 30 blockout.mp4
```
- 只看关键帧：`-- stills 1,37,52,82,121,180`。
- 本机 4 核 CPU，Workbench 软件渲染，180 帧约 1 分 45 秒。

## 画面风格
Workbench 灰盒：物体纯色、棚拍式基础光照、黑色物体轮廓线、轻微腔体阴影和投影。没有景深、运动模糊、字幕、标签、箭头和 HUD。

## 检查结果
- 规格（ffprobe）：720×1280，30/1 fps，180 帧，6.000 秒，无音轨。
- 各阶段数据（从 scene.blend 逐帧读出）：
  - 0–1.2 秒模块静止；
  - 1.2–4.0 秒模块平移 6.8，不旋转、不缩放；
  - 4.0 秒后模块速度为 0，只有相机在动；
  - 各段速度见 `camera_motion.md`。
- 构图：按每 0.25 秒一帧看完整段。主体和入口全程在画面内，没有穿模，单镜头。
- `tools/motion_check.py`：
  - 最长静止 0.47 秒，通过（≤ 0.6）；
  - 静止帧总占比 31%，**不通过**（门槛 < 15%）；
  - 开头约 1.1 秒的窗口静止超过 30%，**不通过**。
  - 原因：这次按审阅要求在 1.2–1.7 秒让相机稳定下来；画面又是大块纯色，模块沿自己长轴滑动时，单色表面几乎不产生像素变化。这个检查是为正式短片定的，这里只作参考。为了凑指标去缩短稳定段或加纹理，会违背审阅要求，所以没有做。
