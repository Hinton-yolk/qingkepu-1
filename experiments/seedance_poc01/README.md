# Seedance PoC 01 · 3D Blockout：光模块插入网卡模块笼子

验证的工作流：Claude 做导演规划 → Blender 做极简动态 Blockout → Seedance 根据 Blockout 和文字提示生成写实镜头。
本目录只做第二步。独立实验，不改 T5/T6 和正式电影工程。没有调用 Seedance，没有用付费 GPU，费用 $0。

## 交付物
| 文件 | 内容 |
|---|---|
| `scene.blend` | Blender 5.2.3 工程：四组物体、相机、注视点空物体、180 帧动画，渲染设置为 Workbench |
| `blockout.mp4` | 6 秒动态预演：720×1280，30 fps，180 帧，H.264，静音 |
| `contact_sheet.png` | 0 / 1.2 / 2.7 / 4.2 / 6.0 秒五张关键画面，左上角是时间标记（只在接触表上有，视频里没有） |
| `camera_motion.md` | 相机路径、机位关键点、速度曲线 |
| `object_motion.md` | 各物体的尺寸、位置关系和运动 |
| `build_scene.py` | 生成场景的脚本，scene.blend 和视频都由它产生 |

## 怎么重做
在本目录运行：
```bash
blender -b --factory-startup --python-exit-code 1 --python build_scene.py -- anim
```
```bash
ffmpeg -y -framerate 30 -i out/frames/f%04d.png -c:v libx264 -pix_fmt yuv420p -crf 18 -an -r 30 blockout.mp4
```
- 只看关键帧：`-- stills 1,37,82,127,180`。
- 本机 4 核 CPU，Workbench 软件渲染，180 帧约 2 分钟。

## 画面风格
Workbench 灰盒：物体纯色、棚拍式基础光照、黑色物体轮廓线、轻微腔体阴影和投影。没有景深、运动模糊、字幕、标签、箭头和 HUD。

## 检查结果
- 规格（ffprobe）：h264，720×1280，30/1 fps，180 帧，6.000 秒，无音轨。
- 构图：按每 0.25 秒一帧看完整段。模块前端全程在画面内；笼子入口在每一帧都能看到。
- `tools/motion_check.py`：最长静止 0.47 秒，通过（≤ 0.6）；任意 5 秒窗口的静止都不到 30%，通过；静止帧总占比 16%，**不通过**（门槛 < 15%）。
  - 原因：画面是大块纯色。模块沿自己长轴滑动时，单色表面几乎不产生像素变化；开头的相机前移又按任务书要求做得很「轻微」。
  - 这个检查是为正式短片定的，这里只作参考。为了凑指标去给灰盒加纹理或加快开头，会违背任务书，所以没有做。
- 中间改过的几轮：
  1. 第一版长轴斜着朝画面右下伸出，模块被切掉，改成插入方向大致上下走向；
  2. 开头和结尾太接近静止，加大开头推进、结尾留余速；
  3. 中段前端碰到右边缘，镜头改 25 mm，中段改为向插入轴线一侧平移。

## 和仓库规则的出入
- 仓库规则是 mp4 不进仓库（`.gitignore` 也排除）。任务书要求把 `blockout.mp4` 交在本目录里，文件也只有约 0.6 MB，所以这一个文件用 `git add -f` 提交了。以后的大文件仍按原规则不进仓库。
- 这是交给 Seedance 的参考预演，不是给观众看的视频。所以没有走「审核写通过」「观众」这两个节点，也没有按「开头 2 秒规则」做开头。
