# 主页背景图

编辑风插画：研究者的书桌，暖色自然光，上半部是空的墙面，留给品牌字。代码画成，不用 AI 生图。

## 文件
| 文件 | 用途 |
|---|---|
| `exports/douyin@2x.png`（2250×1266） | 抖音主页背景，上传用这张，`douyin.png` 是 1125×633 原尺寸 |
| `exports/xhs-5x4@2x.png`（2000×1600） | 小红书背景（按 1000×800 的说法） |
| `exports/xhs-3x2@2x.png`（2484×1656） | 小红书背景（按 1242×828 的说法） |

两个平台的尺寸都来自第三方网站，没有找到官方说明（2026-11-08 查）。抖音默认只露出上面约 400 像素高（仅单一来源）。
小红书先试 5:4，上传后在手机上看，被裁得厉害再换 3:2。

## 画面
- 左：墨绿台灯；摊开的笔记本，手绘棱镜色散光路、六角晶格（纤锌矿俯视）、能带、外延层截面，不出现文字；铅笔和削下的木屑
- 中：玻璃棱镜，在桌上投出一道淡淡的光谱；一块从晶圆上裂下来的扇形碎片，带虹彩和芯片网格
- 右：咖啡杯，一摞没有书名的书
- 配色：奶白、浅橡木、墨绿、暖石墨色，少量琥珀色

## 修改
`scene.html` 按 `?w=&h=` 生成画面，所有尺寸以画面高度的 1% 为单位，左边的物件贴左边、右边的物件贴右边，换比例也能自动排好。
改完运行：

```bash
node assets/brand/profile-bg/render.mjs
```
