# 头像

手绘编辑风插画头像，代码画成，不用 AI 生图，也没有把照片上传到任何第三方。
参照用户的三张自拍：往上抓的黑色短发、两侧推短，平直偏粗的眉毛，单眼皮，招风耳，饱满的嘴唇，圆润的下颌；
深蓝圆领毛衣，领口露出浅蓝衬衫领。配色和主页背景图一致（墨绿底，铅笔描边和排线，纸张颗粒）。

| 文件 | 说明 |
|---|---|
| `exports/avatar.png` | 1080×1080，不戴眼镜 |
| `exports/avatar-glasses.png` | 1080×1080，戴灰色半透明方框眼镜 |
| `exports/preview-round.png` | 两版裁成圆形后的大图和信息流小图效果 |

自拍原图不进仓库。修改 `avatar.html` 后运行 `node assets/brand/avatar/render.mjs`。
