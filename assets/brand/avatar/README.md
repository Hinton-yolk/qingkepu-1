# 头像（「一语道破」）

手绘漫画风头像，代码画成，没有把照片上传到任何第三方（用户 2026-11-08 选择不上传）。
风格：日系漫画与杂志人物插画结合，干净的轮廓线，两色调的赛璐璐硬边阴影，少量纸张纹理。

## 人物还原（相似度优先）
以帆船照片为主，树下自拍补充耳朵、眉毛和发型，博物馆自拍补充正面五官比例：
- 短而微微立起的黑发，发际线比较平，两侧很短
- 鹅蛋脸，颧骨略宽，下巴圆润
- 平直、偏低的眉毛；单眼皮，上眼睑偏厚的细长眼
- 鼻梁直而长，鼻头圆，鼻翼偏宽
- 嘴唇饱满（下唇更厚），只有很轻的笑意
- 明显的招风耳，颜色偏红
- 深蓝圆领针织衫加浅蓝衬衫领；不戴眼镜
