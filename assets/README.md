# 「芯片与光」素材库

选题会反复出现同一批东西。每样东西做一次、做精，之后每集直接引用，画面统一、准确，也省时间（`DECISIONS.md` 第 15 条）。

## 规则
- **准确第一**：结构、比例、层序按真实器件画。用户是半导体材料博士，有疑问就问，不要凭印象画。每个素材在自己的 `NOTES.md` 写明参考来源和刻意简化了什么。
- **一个素材一个目录**：`assets/<英文短名>/`，里面放源码（可以被各系列的渲染流程直接引用的 JS / SVG / three.js 模块）、预览图、`NOTES.md`。
- **适配两个系列的画风**：素材只管几何和结构，颜色、描边、质感由调用它的系列决定（用参数传入），不要把某个系列的配色写死。
- **纯函数**：动画素材按时间 `t` 给出画面，不依赖随机数和帧间状态，方便任何流程逐帧渲染。
- 第一次用到某样东西时再建，不要一次性全做；做完在下面的清单里打勾。

## 清单（按预计使用频率排序）
- [ ] wafer：晶圆（整片 → 局部 die 放大）
- [ ] epi-stack：外延层截面（衬底 / 缓冲层 / 有源层，可标注厚度）
- [ ] gan-lattice：氮化镓纤锌矿晶格
- [ ] waveguide：硅光波导（截面 + 光在其中传播）
- [ ] laser：半导体激光器（发光示意）
- [ ] photodetector：光电探测器
- [ ] optical-module：光模块（外观 → 拆解）
- [ ] gpu-package：GPU 封装（芯片、HBM、基板）
- [ ] cpo：共封装光学（光引擎靠近交换芯片）
- [ ] signal-wave：电信号波形（干净方波 → 衰减拖尾，用于光互连）
- [ ] fiber-rack：机柜里的光纤（光互连开头的实物画面）
