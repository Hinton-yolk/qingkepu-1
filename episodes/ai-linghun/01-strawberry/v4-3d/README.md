## 做法
- **真 3D，但不用 Blender**：three.js 在无头 Chromium 里逐帧渲染（WebGL / SwiftShader，约 0.3 秒一帧，31 秒约 3 分钟）。和 v3 一样由 `timeline.js` 驱动，标题、深度计、字幕、标签仍是 2D 叠在上面（标签按 3D 位置投影）。
  选它而不选 Blender：样片要快速来回改，云端没有 Blender、也没有 RunPod 凭据；用户 2026-11-21 说渲染方式「不限制你的发挥」（Blender / RunPod 都可以）。看法定了以后，终版要更好的质感（真实景深、全局光照）可以再搬到 Blender / RunPod。
- 运行：`npm install`（three@0.187.0），然后 `node render.mjs`（全片）、`--sheet`、`--stills=…`、`--strip=a,b`。需要 http，所以 render.mjs 自带一个本地静态服务器（根目录是 `01-strawberry/`）。
