## 样张 5 · 暖光桌面工业设计（用户 2026-11-21 发来参考图：「这个风格的你可以做么」）
`s5-studio.html`。照参考图的元素来做：米白哑光方块和多层叠板、黑炭色底座加拉丝铝面板和螺丝、磨砂玻璃立板、珊瑚色点缀、黑色线缆和接头、发暖光的导光管；低角度暖色斜阳、高机位 3/4 俯视；上下边移轴模糊，四周压暗。
画面内容：单词托盘 → 分词器（带玻璃屏）→ 三个黑底座上的积木 str / aw / berry，各自的小玻璃屏显示编号。
做法：three.js（PCF 软阴影 + GTAO 环境光遮蔽 + 各向异性拉丝铝），云端约几秒一帧。参考图那种真实的全局光照、更软的长阴影和光管的焦散，要用 Blender（Cycles）才能到位。
参考图不进仓库，并排对比见 `out/s5-vs-reference.jpg`（本地）。
