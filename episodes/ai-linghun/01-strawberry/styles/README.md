# EP.01 风格样张（2026-11-21）

用户：「3、4、1 各渲一张样张对比」「2也做一张」。四张画的是同一时刻：strawberry 刚被切成 str / aw / berry，下方是「AI 看到的（示意）」编号 #496 #675 #15717（GPT-4 分词器实测，见 `../FACTS.md` #1、#19、#20）。
四种风格的积木都用同一组颜色：蓝 / 橙 / 粉。红色不当积木色，留给「r / 错」（审核 v4 时提的意见）。

| 文件 | 风格 | 做法 | 切的工具 | 编号怎么出现 |
|---|---|---|---|---|
| `s3-pixel.html` | 3 像素游戏 | Canvas2D：画面 270×480 放大 4 倍，文字 540×960 去抗锯齿；PICO-8 16 色 | 像素剑 + 刀光 | 物品栏格子 |
| `s4-glass.html` | 4 亚克力 / 磨砂玻璃 | three.js 透射材质，深石板蓝影棚 | 光刃 | 积木里面发光，字母刻在表面 |
| `s1-paper.html` | 1 剪纸 | Canvas2D：纸纹、毛边、层间投影、胶带 | 剪刀 | 卡片背面的橡皮章 |
| `s2-clay.html` | 2 黏土 | three.js：起伏变形 + 指纹凹凸、opentype 挤出的黏土字母（仓库里的 Noto Sans SC 900） | 切泥线 | 黏土名牌 |

出图：`npm install`（opentype.js），需要 `../v4-3d/node_modules`（three）；`node shoot.mjs [名字…]` → `out/<名字>.png` 和 `out/compare.jpg`。对比图另存一份在 `compare.jpg`。
都只是静帧，没做动画；选定风格后按 v4 的做法（timeline.js 驱动、逐帧渲染）做前 31 秒。
