# EP01 · Full Motion Draft V02（内容逻辑与动画因果精修）

《AI 为什么一个字一个字往外蹦？》：约 68.3 秒，540×960 渲染、1080×1920 合成，原生 30 fps，无配音（只有原创合成音乐和音效）。本机 CPU 渲染，没用付费 GPU。

## 怎么做的（工程）
- 场景：`shot_v02.py`（由 V01 的 `shot_full.py` 改来）。
  - 第一到第四幕的场景时间和 V01 完全一样，没改动的段直接复用 V01 的帧。
  - 改动的段重新渲染：第一幕（新的手机输入），第五、六幕（重做）。
- 帧表：`assemble_v02.py` 把成片时间映射到场景时间，第二、四幕的模型处理压紧到约 1.4 倍速（平滑变速，不跳帧）。每帧注明来源（V01 原帧或 V02 新渲）。
- 提示层和音效：`post.py v02`。提示的时间按场景时间写，跟着变速一起压紧。
- 手机界面贴图：`make_ui_v2.py` 生成 `ui_phone_v2.png`。

# 看某几个时刻的构图（场景时间）：

## 修改报告
1. **开场**：
   - 手机上用户输入改为「续写这句话：周末我想……」。
   - AI 的回答里「周末我想」作为给定的开头一下出现，后面「去海边看日落」逐个生成。
   - token 说明缩成一行短标签，放在回答下面，不压画面。
2. **模型处理压紧**：第二幕（每个字变成一串数 → 回看前文 → 候选）和第四幕（「去」那串数进模型）约 1.4 倍速，突出「候选形成」。没有新增模型层的知识点。
3. **P0 逐步生成 → 推测解码的转场**：
   - 逐步生成三轮，每一轮标明「大模型第几轮 → 哪个字」，以及「要等上一个字写定」。
   - 结束后镜头保持同一个稳定景别：海 / 边 / 看从「看」开始依次沿来路收回候选区，柱子缩回。
   - 已写定的「周末我想去」依次亮一下，标注「起点：周末我想去」。
   - 标题「回到同一个起点，换一种办法。」
   - 然后装置从右边滑进来，镜头升高后退到主景别（不再沿托盘横移）。
4. **P0 集中评估（本轮新增动画的重点）**：
   - 小模型推出草稿「海边吃饭」，标「草稿：还不算数」。
   - 已写定的前缀沿一根连线进入验证通道左端（一颗光珠，一次）。
   - 同一时刻，4 个位置的连线一起长出来：每个位置只连到它前面的内容（前缀 + 它前面的草稿），这就是各位置的因果约束。
   - 同一道光同时经过 4 个位置，4 块结果灯一起亮。这是一轮处理，不是扫描仪逐个跑 4 遍；音效也是 4 个音同时响的一个和弦。
   - 接着按顺序对照：海、边接受，吃未接受，饭跟着作废。屏幕注明「接受与否按两个模型的概率规则（示意），不看意思通不通」（「海边吃饭」本身也说得通）。
5. **P0 验证段镜头**：
   - 重新布局：验证通道就在正式输出的正前方，4 个验证位置正对正式输出接下来的 4 个空位。
   - 一个固定的主景别同时装下草稿、验证区、正式输出和大模型输出口，镜头在接受、撤回、补充的全过程中不动。
   - 「海」「边」从通道径直往后进空位。
   - 「吃饭」沿草稿轨退回小模型。
   - 「看」从通道右后方的大模型输出口出来，沿独立弧线落进空位，和「吃」的路线不相交。
6. **对比**：结果「周末我想去海边看」出来后，屏幕上两行对照：
   - 「一步一步：大模型 3 轮 → 海 边 看」
   - 「先猜再验：大模型 1 轮 → 海 边 看」
   - 小字：「另加小模型猜草稿；条件合适时，整体更快」。

   没有加速度数字、倍数和显存带宽。
7. **镜头**：
   - 去掉第五幕开头沿托盘的横向追踪。
   - 验证装置在第五幕之前不在场景里，不再长期占据背景。
   - 结尾飞回手机的弧线压到托盘和手机之间，不再朝镜头飞。
   - 验证光的亮度降低（V01 过曝）。
8. **结尾**：手机上用户的输入同样是「续写这句话：周末我想……」，最后两句改为「每一步，都建立在前一步之上。」「但可以先猜几步，再一起验收。」

## 主要对象的身份与连续性
- **周末我想**：手机回答里的同一批字块，升起落到托盘，一直留到第六幕飞回手机。
- **去**：候选 → 分叉 → 正式输出 → 第四幕的起点 → 第五幕的「同一个起点」→ 飞回手机。
- **海 边 看（第四幕）**：示意的逐步生成，三轮后沿来路收回候选区。它们和第五幕的草稿不是同一批物体：第五幕是一次新的对照实验。
- **海 边 吃 饭（第五幕）**：小模型推出的同一批草稿。海、边经验证进入正式输出；吃、饭退回小模型。
- **看（第五幕）**：从大模型输出口出来的新字块，和「吃」不是同一个物体。
- **验证装置**：第五幕开始时整套从右边滑进来，之后一直在主景别里。

## 尚未解决的内容与镜头问题
- **主景别**：左边的「周末我」被裁在画外，只看得到「想去」和后面的空位。要整行都进画面，就得把镜头拉远，验证通道里的字会变小。这次优先让验证区够大。
- **第二、四幕**（约 9–16 秒、26–31 秒）：约 1.4 倍速。仍有几秒主体偏小或镜头贴近闸门（14–15 秒、28–30 秒）。这两段沿用 V01 的镜头，这一轮没有重渲。
- **第四幕和第五幕的「海 / 边 / 看」**：不是同一批物体。第五幕是一次新的对照实验，这一点只靠「回到同一个起点」标题和「起点：周末我想去」标签说明，没有更强的视觉记号。
- **接受规则**：只写了「按两个模型的概率规则（示意）」，没有演示具体比较（例如两个概率条并排）。要演示的话要再加约 3 秒。
- **「看」的来源**：标为「这一位用大模型自己的结果」。严格说，它是在「吃」被拒绝后，从修正过的分布里重新抽出来的，这一层没有展开。
- **验证装置进场**：从右边滑进来，是为了不长期占据背景，但这是一个新的出场动作，请确认能不能接受。
- **全部接受时**：大模型还会多给一个字，片中没有讲。
- **音乐**：仍是合成占位。第五幕的集中评估用 4 个音同时响的一个和弦来对应「同一轮」。
