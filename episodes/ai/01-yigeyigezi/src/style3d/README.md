# 新画风样张 · 风格化 2.5D 科学动画（2026-11-19，待用户定）

用户 2026-11-19 定的方向：Ordinary Folk 式的精致动态图形语言 + 有实体质感的科技产品建模；不卡通，也不追求照片级（原话见 `episodes/ai/要求清单.md`「画风」）。参考分析见 `research/参考分析_OrdinaryFolk_Equilibrium.md`。

同样三个镜头（和 11-18 的 A–G 样张对照）：
1. 开头：手机里 AI 正在逐字回复，「去」字块从屏幕里浮出来，下一个位置是黄色「?」玻璃块。
2. 模型一层层：五层参数板（粉正蓝负的糖果方块），新字是一颗黄色发光球，从中间的洞往上穿；穿过的层变暖色，穿过的路径留下圆环。
3. 分叉：句子是一条半透明的渐变玻璃带，在「去」后面一分为二，上面一条接「海边看日落」，下面一条接「睡个懒觉」。

## 做法
- 3D：Blender 5.2 Cycles（本机 CPU），`scene.py`，一个镜头一个函数段。
- 2D：大字问题、字幕、小字、手机屏幕贴图由 `overlay.py` 叠加（字留在 2D 层，保证手机上可读）。
- 出图：`bash render_all.sh <输出目录> [分辨率比例] [采样数]`。1080×1920、64 采样，本机每张约 1 分钟。样张 v1 缩略图：`样张_v1_三镜头.jpg`。
- 材质对照 Equilibrium：糖果塑料（清漆 + 次表面）、半透明渐变玻璃、缎面金属（手机）；整片粉彩底色（每个环节换一个底色），柔和大面积棚灯，浅景深。
- 符号表的颜色分工照旧：粉正蓝负 = 参数，黄 = 当前 / 答案。

## 做整片时要定的
- 画风本身（用户看样张定）。
- 渲染：75 秒约 2250 帧，本机 CPU 每帧约 1 分钟，整片约 40 小时，太慢。两个办法：RunPod GPU 精渲（按 11-18 的规矩先报预算）；或者把同一套材质搬到 three.js（WebGL，本机能渲，质感会弱一些）。等样张定了再做一个 3 秒的运动测试来比较。
