## 做法
- 3D：Blender 5.2 Cycles（本机 CPU），`scene.py`，一个镜头一个函数段。
- 2D：大字问题、字幕、小字、标签条、手机屏幕贴图、细颗粒由 `overlay.py` 叠加（字留在 2D 层，保证手机上可读）。标签条的位置由 `scene.py` 把 3D 锚点投影到屏幕（`*_anchors.json`），自动跟着物体走。
- 出图：`bash render_all.sh <输出目录> [分辨率比例] [采样数]`。1080×1920、64 采样，本机每张约 1 分钟。样张 v1 缩略图：`样张_v1_三镜头.jpg`。
- 材质对照 Equilibrium：糖果塑料（清漆 + 次表面）、半透明渐变玻璃、缎面金属（手机）；整片粉彩底色（每个环节换一个底色），柔和大面积棚灯，浅景深。
- 符号表的颜色分工照旧：粉正蓝负 = 参数，黄 = 当前 / 答案。

## 运动测试 v1（2026-11-19）：镜头 ② → ③ 转场，3 秒
- 源码 `motion.py`（每帧按时间摆好物体，时间的纯函数）+ `motion_overlay.py`（字幕、小字、标签条、颗粒）；出片 `bash build_motion.sh <工作目录>`。
- 一个连续镜头：0–0.6 秒黄球继续往上穿层（走过的层变暖）→ 0.6–1.4 秒沿出口细管跑到「?」→ 1.3–2.4 秒相机从正面长焦摆到左前方广角、模型升走、底色淡紫变桃色 → 1.5–2.6 秒玻璃带长出来并在球的位置分叉、分叉上的字块依次弹出 → 2.6–3 秒落定，相机仍在慢漂。字幕在换章节时先淡出再淡入。
- 渲染：648×1152、32 采样，90 帧本机 19 分钟，放大到 1080×1920。无声。
- `tools/motion_check.py`：静止帧 0%，最长静止 0 秒 → PASS。缩略图：`运动测试_v1_每0.2秒.jpg`。
- 自查问题：1.4–2.2 秒同时发生的事太多（模型升走、相机摆、底色变、玻璃带长、字幕换）；结尾分叉在画面里偏小，分叉上的字手机上偏小。

## 草稿 v3（2026-11-19）：按用户确认的 v3 字幕，34 拍
- 源码：`film3d.py`（3D：每拍一个函数，时间从 `script.md` 的「逐句字幕 v3」表读，和字幕同步）+ `film_overlay.py`（2D：字幕、小字直接从同一张表读）。
- 接触表：`草稿v3_接触表_34拍.jpg`（每格标起止秒；★ = 最难懂的两环）；每拍小图 `草稿v3_每拍/`。本系列无配音，只用字幕。每拍只取一帧代表画面，草稿画质（0.4 倍分辨率、24 采样）。
- 色度：34 拍全量实测平均 0.32、最低 0.25（拍 16）；亮度平均 0.70、最低 0.63（用户 11-19「色度可以适当提升」；样张 v3 时 0.14–0.15）。
- 安全区：每拍渲染前自动取景（`autofit`）：把所有物体和标签锚点收进 x 7%–86%、y 12%–63%（无小字的拍到 69%），右边缘 ≤ x 929；手机拍和片尾手动。
- **转场计划**（用户 11-19「节奏有点太快」）：草稿是静帧，转场在终版里做：每次换章节（换底色）用约 1.5–2 秒的连续转场，一次只发生一两件事（先相机，再形变），带一个东西过去（黄球、字块那一排）；章节内一个版式撑住，在画面里一步步加东西（Kurzgesagt 讲解段的做法，见 `research/参考分析_Kurzgesagt_BUCK.md` 5.1）。每拍时长先按字幕表，终版按音乐细调。
- **流程**：节点 ② 审核 / 监督 → 接触表交用户确认内容 → 再做动画和音乐 → 自检循环、动效检查 → **报 RunPod 预算、用户批准后**才渲终版（11-19 估算：约 3210 帧，L40S / 4090 约 7–9 秒一帧，预算 $7–10）。
