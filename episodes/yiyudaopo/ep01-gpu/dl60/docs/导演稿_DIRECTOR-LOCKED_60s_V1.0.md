## 1. Visual identity

B. One motif: the computation tile — simple rounded rectangular calculation unit; illustrative calculation task, NOT transistor / GPU core / shader / token / packet. Geometry, corner radius, edge, motion language consistent throughout.
C. Color: hardware cold-neutral metallic; graphics restrained amber; AI cool off-white; both keep identity before entering one coordinated visualization; background dark graphite, not pure black everywhere. No oversaturation / neon / sci-fi.
D. One Chinese type family; legible at 360×640; no tiny numeric grids; no competing text blocks; central safe region (avoid bottom caption area, right platform controls). Text supports motion.

## 3. Mandatory transition continuity (most important)
Five transitions: GPU → game viewport; game computation → AI numerical environment; single AI operation → multiple; game & AI patterns → shared revelation; abstract computation → physical GPU. For each: identify the surviving element; preserve screen-space continuity where appropriate; preserve or deliberately animate velocity direction; avoid abrupt scale jumps, unexplained camera resets, crossfading unrelated full-screen pictures, black separators. Use motion / shape continuity, occlusion or justified match cut. Major boundaries within ±3 frames of prescribed timing unless a concrete technical problem.

## 4. Camera discipline
Not "move constantly". Three behaviors: Approach, Follow, Reveal; each move has one of these purposes. No random orbiting, fast spinning, whip pans to hide discontinuities, constant zoom in/out. Smooth acceleration/deceleration, timing reflects the action's meaning (not generic ease-in/out everywhere). Allow stillness when a result or revelation needs to register.

## 5. Prohibited
Reassembling Pilot V03 / Full Assembly V01 scenes; six slide-like compositions with transitions added after; black background as default; moving labels replacing storytelling; rows of tiny numbers; fake lasers / glowing tunnels / sci-fi particles; GPU-core count as performance comparison; HBM, multi-GPU interconnect, data-center networking explanations; voiceover; TTS as timing tool; storyboard document instead of the video; mathematical correctness alone as visual quality.
