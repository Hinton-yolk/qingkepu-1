# 观众（Codex）反馈 · Pilot v01

Codex 看的是逐秒截图接触表 + 字幕时间表，听不到声音。原文如下，未改动。是否采纳由用户决定。

**一句话感受：题目能让我停一下，但中间越来越像数学课；看完能懂大意，正常刷视频可能在第 21 秒就走了。**

以下只根据截图和字幕判断，我听不到声音，不能评价实际配音和连续动画的节奏。

1. **前 3 秒：会停，但还没到非看不可。**

   “AI 又不打游戏，为什么还要用显卡？”是我能理解、也有点好奇的问题。聊天界面也熟悉。

   但 0–3 秒主要在等问题打出来，画面吸引力一般。**2 秒时我会留下，5 秒时就开始等你赶紧解释。**“黑洞是什么”本身没有增加多少好奇。

2. **最可能划走：第 21 秒。**

   15 秒看到游戏画面变成三角网格，我还能跟，觉得“原来游戏画面是这样”。

   到 19–23 秒出现朝向、光源方向、两排小数，再对应相乘，我会想：**“我要先学会算这个，才能知道 AI 为什么用显卡？”**这时问题的答案还没到，学习负担已经上来了。

   第二个危险点是 49–54 秒：刚看懂简单算式，又铺开满屏数字，有点累。

3. **看完后，我能说出的答案：**

   **AI 要做大量同一种乘加计算，显卡擅长把这些计算一大批同时做，所以用它算得快。**

4. **两段有没有看懂？**

   **2×4＋3×5＝23：看懂了，而且稍微讲得太慢。**  
   42–47 秒逐个算出 8、15、23，不难。真正没跟上的是后面：为什么把数字“排整齐”就叫矩阵乘法？那些行和右边的输出怎么对应？我接受了字幕的说法，但没有自己看明白。

   还有一个疑问一直留着：**这些数字算完，怎么就变成“黑洞”的回答了？**不需要全讲，但现在会觉得从文字跳到算术有点突然。

   **CPU / GPU：懂结论，图里的细节没看懂。**  
   我看懂的是：CPU 各个核心可以做不同的事，GPU 有很多计算格子，一起处理同类计算。  
   “控制”“缓存”“分支”这些词，我只是读过去。图让我记住“GPU 格子更多”，但“一条指令带一大批数据”具体怎么发生，印象不够强。

5. **具体看不清或容易误会的地方：**

   - **19–23 秒：**数字和标签偏小，还要同时看三角形、箭头、字幕，不知道先盯哪儿。“朝向”为什么会变成三个数，我不懂。
   - **24–32 秒：**下面数字表太密。我能看懂岛，但没法把某个数字和岛上的某一块对应起来。
   - **36–38 秒：**词下面的数字暗、小。我看出“文字变成一串数”，具体数值基本不会读。
   - **49–54 秒：**数字越铺越多后，我放弃辨认。只能感受到计算量大，理解不了每一行怎样出结果。
   - **55–57 秒：**“几十亿～上千亿次”能看到，下面滚动数字和估算说明看不清。大数字挺震撼，但我不会记住。
   - **68–80 秒：**CPU 格子里面的字太小。到上下对比时，GPU 的格子明显更多，我容易直接理解成“核心多，所以更快”，忽略你想讲的工作方式。
   - **85–88 秒：**解释文字和底部字幕挤得近，87 秒尤其有重叠感。
   - **90 秒：**突然出现 `D＝A×B＋C`，我刚觉得自己懂了，又冒出一道新题。这里我不会再尝试理解公式。

   这些是接触表里的可读性感受，原视频全屏可能好一些；连续动画到底快不快，仅凭逐秒截图不能确定。

6. **会不会互动，以及最想改的三件事：**

   **如果看完，会考虑点赞；不会收藏，暂时不会关注。**大意记住就够了，没有明显需要回来查的内容。结尾“数字怎么及时送到”有一点吸引力，但还不足以让我马上追下一条。

   我最想评论的是：**“所以 AI 聊天主要在服务器上算，我自己电脑的显卡不用好也行？”**

   最想改的三件事，按顺序：

   1. **早点让我知道答案方向。**前面先让我看到“很多块同时算”的效果，再解释里面怎么乘加。我不想先算完亮度才知道它和标题有什么关系。
   2. **简单算式快一点，关键连接慢一点。**2×4 那段可以缩短；把时间留给“一行怎么算出一个结果、多行怎么同时出结果”，这才是我没跟上的地方。
   3. **放大主要演示，减少密密麻麻的小字。**尤其 CPU / GPU 对比，直接让我看到一批相同任务怎么被处理，比让我读格子里的标签有效。
