## 任务书
- T1 只交开头 80–100 秒；9:16、1080×1920、30fps、普通话、干净的中文字幕；不做后 3 分钟。【任】
- T2 写实硬件镜头 + 克制的 2D 编辑式动态图形；不要多余特效、通用 AI 科技感、重复发光粒子、科幻隧道、随机高速飞行。【任】
- T3 3D 用 Blender，优先 RunPod + Cycles；2D 数学用 Remotion，精确可控；不为每段都走 LTX。【任】【补】
- T4 A：问「黑洞是什么？」→ 回答出现 → 从人机交互到数据中心 → GPU 微距；专业灯光、物理尺度感。【任】
- T5 B：游戏画面 → 抽象计算；先演示一个图形计算，再演示很多类似运算同时处理；原图和计算联系明显；**不要画成每个像素完全独立、没有共享和依赖**。【任】
- T6 C：切 token → 数字 → 2×4+3×5=23（两次乘法分开，再相加）→ 扩展到大量乘加 → 矩阵；注明示意；留视觉停顿。【任】
- T7 D：B 和 C 的视觉对应、共同并行结构；CPU/GPU 设计差异；**不暗示 CPU 单核 / 不能并行、GPU 什么都更快；不用工人比喻**；结论：不是因为会画游戏，而是数学结构适合 GPU。【任】
- T8 E：回到写实加速器；矩阵计算硬件；引出「只有速度够吗」；结尾暗示内存和数据输送。【任】
- T9 旁白以 V2.1 为准（未找到，现用重建稿 v01-R2，待确认）；临时 TTS 不算终版。【任】

## CLAUDE.md 通用规则（本集适用的）
- G4–G7 开头 2 秒规则 + 开头检查 5 问（第一帧实物 + 大字问题；第一句 ≤ 2 秒、反直觉；前 10 秒无「上一篇 / 这一篇」；15 秒内有会动的机制演示；大字问题不是行业名词）。
- G3 FACTS.md 每条有来源；示意 / 估算写明。
- G10–G12 声音：终版配音 Fish Audio「科普」声线；音乐代码合成、分段换调、揭晓前停半拍、音效卡动作；-14 LUFS，音乐在人声下约 12 dB。
- G13 内容关卡（拆题四问 + 逐句脚本 + 开头备选 → 接触表 + 配音 → 才重渲染）。本轮任务书要求直接出片，已补交 `docs/拆题与开头备选.md`。
- G14 自检循环：接触表亲眼看、1–10 打分、motion_check 必须 PASS。
- G15 先只出一个视频；确认后才做封面、小红书版、publish.md。
- G16 四个角色：审核写「通过」才交；监督查清单；观众（Codex）看片反馈（需要用户登录 Codex）。
- G18 字幕和角注避开平台底部界面（监督估计 y > ~1540 有风险）。

## 3D 镜头语法（只管 DC / MACRO / CHIP）
- 跟着一个东西走；推镜回答问题；转场带一个东西过去；简化加注「示意」；不让人以为芯片是搭出来的；色度 / 亮度门槛是建议值（任务书要中性底，2D 段不适用）。
