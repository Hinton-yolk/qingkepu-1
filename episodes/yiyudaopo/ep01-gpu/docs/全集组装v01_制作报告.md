## 开头的三处修正
1. 去掉「芯片 → 机房 → 芯片」的快切，开头只留芯片一个镜头（机房镜头挪到结尾 H 段的大场面去用）。
2. AI 计算的数字：输入标「由问题变来」，参数标「模型里学到的数」，加角注「示意数字：真实的输入和参数都是小数，而且多得多」。
3. D 段 GPU 铺满那段：两处停顿共缩短约 1.2 秒（导演说约 2–3 秒「如果剪辑需要」；画面上有新信息在流动，没有再砍）。

**三处修正之外，锁定段还有这些改动（请导演知道）：**
- 删掉了 E2「可是，数据如果送得不够快，计算单元就只能等着」——这一条超出了导演允许的三处修正，理由见下一节。
- E1 后的停顿 0.4 → 0.3 秒，E4 后的停顿 1.6 → 0.7 秒：E 段不再是结尾，问题直接接 F 段的回答。
- 代码上跟着修正 1 和删 E2 的连带改动：B 段开头的芯片方框改为从 A 段的芯片微距接过来（`SeqB.tsx` 的 `r0` 跟 `MACRO_BACK`），因为中间的机房镜头去掉了；E 段原来配 E2 的「在等数据…」画面关掉了（`SeqE.tsx` 的 `waiting = 0`），「等数据」改由 F 段完整演示。
- 修正 3 只缩了约 1.2 秒，没到导演说的 2–3 秒，原因见上。

## 旁白相对导演建议稿的改动（需要导演知道）
- E 段去掉「可是，数据如果送得不够快，计算单元就只能等着」（Pilot v03 的 E2），这个意思由 F 段完整讲。
- F 段去掉开头三句「刚才我们说……可这些计算，还有一个前提。需要的数据，得及时送到。」——紧接在 E 段「数据又是怎么及时送到芯片上的？」之后会重复。F 段从「AI 模型有大量参数……」开始。
- G、H 段照导演建议稿，一字未改。

## 层级：GPU → 板卡 → 服务器 → 多台服务器 → 机柜
- G 段的 SERVER 镜头是一个连续拉远：从一块 GPU 的封装（芯片 + 两侧 HBM）→ 它所在的模组（板卡）→ 底板上的 8 块模组 → 整台服务器。**板卡这一级镜头经过了，但没有单独加标签**，屏幕字只有「一台服务器里的 8 块加速器」。要补的话，可以在拉远经过模组时加一个「一块加速器板卡」的标签（不需要重渲）。
- H 段：「一台服务器（8 块 GPU）」外框缩进机柜镜头里的服务器 →「柜顶交换机」→「机柜与机柜之间」。
