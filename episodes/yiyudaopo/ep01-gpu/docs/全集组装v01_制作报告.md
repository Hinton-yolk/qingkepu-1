## 结构
| 段 | 时间 | 讲什么 |
|---|---|---|
| A–E | 0:00–1:07 | Pilot v03（锁定）：为什么是 GPU → 游戏和 AI 都是大量可以同时算的计算 → CPU / GPU → 矩阵单元 →「算得快还不够。数据又是怎么及时送到芯片上的？」 |
| F | 1:07–1:36 | 显存放参数和中间数据 → 计算单元要不断读 → 送得慢就等 → 比的还有显存容量和带宽 → HBM 紧挨着芯片、接口很宽 |

| H | 2:02–2:43 | 多块一起就要交换数据，传得慢就等 → 服务器 → 机柜 → 一排排机柜 → 回到开头的问题 → 计算 · 存储 · 通信 → 下一集：GPU 之间怎么「说话」 |

## 开头的三处修正
1. 去掉「芯片 → 机房 → 芯片」的快切，开头只留芯片一个镜头（机房镜头挪到结尾 H 段的大场面去用）。
2. AI 计算的数字：输入标「由问题变来」，参数标「模型里学到的数」，加角注「示意数字：真实的输入和参数都是小数，而且多得多」。
3. D 段 GPU 铺满那段：两处停顿共缩短约 1.2 秒（导演说约 2–3 秒「如果剪辑需要」；画面上有新信息在流动，没有再砍）。

## 旁白相对导演建议稿的改动（需要导演知道）
- E 段去掉「可是，数据如果送得不够快，计算单元就只能等着」（Pilot v03 的 E2），这个意思由 F 段完整讲。
- F 段去掉开头三句「刚才我们说……可这些计算，还有一个前提。需要的数据，得及时送到。」——紧接在 E 段「数据又是怎么及时送到芯片上的？」之后会重复。F 段从「AI 模型有大量参数……」开始。
- G、H 段照导演建议稿，一字未改。
