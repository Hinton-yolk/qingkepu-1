## 拆题四问（标题：AI 又不打游戏，为什么还要用显卡？）
1. **为什么不？**（直觉：显卡是画游戏的，AI 用它很奇怪）
   → 机制：画游戏画面，本质是给成千上万块三角形各算一次「朝向 × 光源方向，再相加」——同一个公式、同一束光、不同的数，可以成批同时算。GPU 就是为这种活儿造的。（B 段，演示：真正着色那块三角形的三对数相乘再相加）
2. **不，意味着什么？**（AI 不画图，那它在算什么）
   → 机制：文字切段 → 换成一长串数字 → 模型做得最多的是乘了再加；2×4 + 3×5 = 23；几千对一排，很多排就是矩阵乘法。（C 段）
3. **如果是，会怎样？**（把两边放在一起）
   → 演示：两道算式的「形状」一样——成对相乘、再相加；同一步里一大批、彼此不用等。CPU 把面积给了控制和缓存，GPU 把更多面积给了运算单元，一条指令喂一大批数据。（D 段）
   → 「哦！原来是这样」：**GPU 擅长 AI，不是因为它会画游戏，而是 AI 的很多计算，正好长成了 GPU 擅长的样子。**
4. **是了，又意味着什么？**
   → 「哦！原来还可以这样」：既然 AI 的核心是矩阵乘法，后来的 AI 芯片干脆专门做了算矩阵的单元；可算得再快，数字得及时送到——引出显存和数据搬运（E 段，接全片后半）。

结尾回扣：D7–D8 把标题反过来说了一遍（「不是因为它会画游戏」）。
