# SPEC — EP.02 降噪耳机 v5（v4 + 反馈：「如果」、抵消不干净、内侧麦克风的作用演示出来、闭环里真的变安静、小提示高亮）

GOAL:    看完的人能复述：降噪不是把耳朵堵得更严，而是往耳朵里加一个反过来的声音；外面的麦克风先听到噪音，芯片把它反过来，
         扬声器放出去，一推一拉正好抵消，空气不动，鼓膜也就不动；反得慢一点就抵消不掉；耳朵里的麦克风再检查还剩多少。
OUTPUT:  单文件 canvas 页面，`window.seek(t)` 画第 t 秒；1080 × 1920，30 fps；`node render.mjs` 出帧，H.264 yuv420p CRF 16。
TIME:    59.75 s × 30 fps = 1793 帧；120 BPM，30 小节；打叉 8.0、名词 36.0、还差一步 38.0、安静 50.0 都在小节线上。
MOTION:  每一秒都在动：开场第 0 帧起缓推；误区、耳道、第二个麦克风、闭环的停留段都有缓推或漂移；耳道里的波 1.5 Hz、线更粗、空气点更多；
         亮场景里轰鸣画成从地铁一圈圈扩散出去的声波（每拍一圈，按下降噪后照样在外面扩散——只有耳道里安静）。
PACING:  每个变化之前先停住"之前"的状态 ≥ 1.5 s；关键画面落定后 ≥ 2 s；推进 ≥ 2 s；同一时刻最多一句字幕 + 1–2 个短标签。

空间：一张耳朵的剖面图（正面切开：耳廓、耳道、鼓膜、一点中耳和耳蜗），耳机塞在耳道口；外面左边是地铁。
      一台相机：整体 → 耳机 → 外壳上的麦克风 → 顺着信号到芯片、扬声器 → 钻进耳道（暗场）→ 分屏 → 拉回整体。
