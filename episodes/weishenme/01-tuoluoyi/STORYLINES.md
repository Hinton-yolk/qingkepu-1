# EP.01 为什么手机知道你横过来了？—— 三条故事线

系列：「你每天都在用，但你不知道它怎么工作」
平台：抖音 / 小红书，9:16，≤45 s，静音也能看懂（大字 + 画面讲完），配乐与音效代码合成。

## A. 一镜潜入（推荐，已制作）

- **装置 / 形式**：物体本身就是解释（The object is the explanation）× 一路放大的长镜头（Powers of Ten 式对数推进，带滚转）。
- **观众看到 / 感到**：手机一横、画面一转——这是每个人都熟悉的那一下。镜头穿进屏幕、找到一颗比米粒还小的芯片、掀开盖子，掉进一个会振动的硅做的机械世界；看懂科里奥利力后，再一路拉回手机，那一下"画面转过来"重新发生一次，这次你知道它为什么转。
- **前两秒**：第 0 帧就有大字问题 + 正在转动的手机；0.75 s 手机横过来但画面还是竖的，1.0 s 画面"咔"地转正。
- **节拍**：钩子 → 透视找芯片 → 比一粒米还小 → 掀盖 → 会动的机械 → 静默 → 陀螺仪(砸字) → 误区翻转(旋转陀螺✕) → 振动 → 一转就被推一下 → 推得越狠转得越快 → 但还不够 → 搭档加速度计认"下" → 拉回手机 → 画面转正(最大的一下) → 一句话结论 → 系列片尾。
- **画面**：日常世界是浅灰底 + 墨黑 + 信号橙；芯片内部是扫描电镜(SEM)式灰阶硅结构，橙色只给"被感知的东西"（力、重力、信号、答案）。
- **声音**：120 BPM 原创电子流行，F–G–Em–Am（王道进行），3 音动机 mi-sol-la 贯穿；进芯片前 0.5 s 全静，砸字是全片最响的一下；振动段的琶音随质量块左右声像摆动。

## B. 大字辩论（未制作）

- **装置 / 形式**：字来推论证 × 卡点硬切。整片是巨大的动态字和纯色色块，每拍换一次版式，只用象形小图（手机、陀螺、箭头）。
- **前两秒**：满屏"它怎么知道？"四个字随手机图标一起旋转 90°。
- **节拍**：问题 → 你以为是陀螺(✕) → 其实是振动的硅 → 科里奥利 → 加速度计 → 答案。
- **取舍**：最快、最省，但缺少"看到真东西"的惊奇感，容易像 PPT。

## C. 转椅实验（未制作，最大胆）

- **装置 / 形式**：一个角色替你做实验 × 匹配剪辑。一个人坐在转椅上来回推小球，转椅一转，小球的路径被"推歪"；匹配剪辑到芯片里同样被推歪的硅质量块。
- **前两秒**：转椅上的人手机一横、屏幕翻转，他自己也跟着椅子转起来。
- **取舍**：类比最直观，但需要可信的人物表演（代码画人风险高），45 s 内装不下加速度计这一段。

**推荐 A**：它让观众真正"看到"手机里面那块会动的硅，惊奇感最强，而且结尾能把开头那一下原样重演——这次观众知道原因。
