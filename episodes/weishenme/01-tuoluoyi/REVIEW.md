# REVIEW — EP.01 v4（为什么系列 · 微型侦探故事）

v4（40.0 s，1200 帧）在 v3 的连续空间上按第四轮反馈重排叙事；v3 存档在 `archive/v3/`。

| 反馈 | v4 的处理 |
|---|---|
| 转场太硬 | 不用 animate 的形状变形；所有转场都是同一空间里的连续运动：扫描线揭开、螺旋推进、掀盖、暗场浸入、分屏滑开、拉出。去掉开场问题退场后 0.35 s 的空拍（问题留到 4.0 s，和橙色铺底无缝交接） |
| 现象开场，名词不做入口 | 去掉 4.0 s 的「陀螺仪」砸字；名词在 24.0 s 作为答案出现：「这块会"偏"的硅，就叫陀螺仪。」+ 小字「名叫"陀螺"，却一圈都不转」回扣误区 |
| 错误直觉 → 打叉 | 「你是不是以为里面藏了个小陀螺？」→ 5.5–6.0 只剩小陀螺嗡嗡声 → 6.0 打叉（最响之一）→「其实里面什么都不转。」 |
| 钻进去 | 手机 → 扫出主板 → 芯片（米粒对照）→ 掀盖 → 暗场 → 质量块，一台相机连续推进；推进途中抛出「它自己不转，怎么知道你在转？」 |
| 只讲一个机制 | 同一个质量块：振动 → 手机转 → 侧偏 → 转得越快偏得越多 |
| 原来还差这一步 | 「但只知道"转了"，够吗？」→ 分屏：陀螺仪「我在转」｜加速度计「下面在哪」 |
| 回到开头闭环 | 拉出到竖着的手机，手机再横一次：两个传感器在转动的那一刻开口说话，气泡缩回手机，画面转正：「所以，你一横手机，它就知道了。」 |
| 每 5–7 s 一个新认知问题 | 8 个问题：0 / 4.25 / 8 / 12.25 / 18 / 20.75 / 26 / 30.75 s；每个都在下一个之前被画面回答；每个问题同一个上行四度声音记号 |

# REVIEW — EP.01 v3

v3（36.0 s，1080 帧）在 v2 基础上只改了两处，按第二轮反馈：

| 反馈 | v3 的处理 |
|---|---|
| MEMS 段要确保"侧向偏移"足够明显，宁愿慢 | 这一段从 8 s 拉到 10 s；驱动降到 1 Hz（每拍摆一次）；镜头推近到质量块（偏移在屏上约 60–100 px）；加入"没被推时的位置"虚线方框，错位部分涂橙；白色横箭头（摆）+ 橙色竖箭头（推）+ 直角符号；往右摆被推向上、往左摆被推向下，每拍交替；慢转 30°/秒 → 快转 75°/秒，偏移明显变大。去掉了没有解释的"电容高亮"和"转了 90°"读数，只留一个视觉动作 |
| 金句让传感器开口说话 | 分屏改为对话气泡：陀螺仪 告诉手机：「我在转」；加速度计 告诉手机：「下面在哪」 |

测量（v3 成片）：−14.1 LUFS，真峰 −1.7 dBTP；120 BPM，命中最大误差 0.15 帧；无黑帧；整片帧与单独渲染逐字节一致。
自检：钩子 8、可读 8、运动 8、变化 8、品牌 8、声画 8、结构 9、知识高潮清晰度 9。

# REVIEW — EP.01 v2

成片：`out/ep01-gyroscope.mp4`（1080×1920，30 fps，1020 帧，34.0 s，H.264 yuv420p CRF 16 + AAC，10 MB）
上一版：`archive/v1/ep01-gyroscope-v1.mp4`（42 s）

## 按反馈改了什么

| 反馈 | v2 的处理 |
|---|---|
| 12–13 s 振动戛然而止、突然变成传统陀螺，转场生硬 | 误区提前到 4–8 s，紧接开头的问题：点名"陀螺仪"，在**同一台手机里**扫出一个在转的小陀螺 →「你以为里面藏了个小陀螺？」→ 啪，打叉 →「其实它根本不转。」橙色底 + 打叉保留 |
| 最大的问题是重复（A→B→A→C→B→A） | 镜头只往前走：手机 → 小陀螺（错的）→ 真主板 → 芯片 → 一个质量块 → 分屏 → 拉回手机。删掉第二次橙色场景、"芯片里藏着会动的机械"、单独的加速度计段、"下跑到了侧边"等重复解释 |
| 只保留一个视觉动作：质量块左右振动 → 手机一转 → 侧向偏移 | 同一个质量块完成三拍：「它本来只在左右振动」（虚线=原来的轨道）→「手机一转，它就会向侧面"偏"」（轨迹离开虚线、绕成环）→「偏多少，就能算出你转得多快」（快转时环更大、读数 67°/秒、最后"转了 90°"） |
| 不要让专业名词做主字幕 | "科里奥利"只出现在小字「这叫科里奥利效应」 |
| 陀螺仪 + 加速度计压成清楚的结尾：分屏 → 合并 | 22 s 分屏：左 陀螺仪 / 感觉"转"，右 加速度计 / 找到"下"；然后右半屏滑走、左半屏一路拉出到手机 →「于是手机知道：你把它横过来了。」画面在同一拍转正 |
| 动得多 ≠ 推进得快，要一个连续空间 | 全片一个世界坐标系、一台相机，相似变换对数螺旋插值：推进、滚转、拉出都在同一空间里连续发生；每个运动都推进理解（扫描 = 揭开，推进 = 进入，偏移 = 原理，分屏 = 分工，拉出 = 结果） |

时长从 42 s 降到 34 s。

- R1 → R2：小陀螺那段手机推得太近，两端被裁掉，看起来像一条横带而不像手机（推近从 1.5× 改到 1.2×）；侧向偏移太小（偏移幅度 20 → 28 µm，梳齿间距相应加大，避免穿模）；12.5 s 黑底小芯片（压暗推迟到推进开始后）。
- R2 → R3：分屏右半边下方露出了第二个陀螺仪结构、左半边露出封装（两边都裁到内容带）；"这叫科里奥利效应"压在硅条上（换位置）；偏移轨迹加粗加长。

## 测过的

- 响度：整合 −14.1 LUFS，真峰 −1.8 dBTP（成片实测）。
- 节拍：`npx hyperframes beats` 实测成片 120 BPM，网格偏移 5 ms；画面命中点最大误差 0.15 帧（`beats.json`）。
- 名字前 3.5–4.0 s 真静音；最响两下在 4.0（名字）和 28.0（揭晓）；21.5–22.0 鼓组退出。
- 无黑帧；整片渲染出来的帧和单独渲染的同一帧逐字节一致。

- 4.0 s 名字砸出时，扫描线同时在揭开小陀螺，信息同时到达，第一次看可能先看字。
