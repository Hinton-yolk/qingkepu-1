## 白话版（v3）

手机往板子上一放，就开始充电了。没插线，电是怎么进手机的？

它们之间，没有一根线连着。那电怎么过去？

两边各藏着一圈铜线。板子这圈里，电流一直在来回跑，每秒来回十几万到几十万次。电流一来回，周围的磁也跟着翻。磁穿过外壳，穿过手机这一圈，手机这圈里的电，也跟着动起来了。

电没有走过去，过去的是磁。手机再把这股来回跑的电理顺，充进电池。

那为什么一定要放正？磁都挤在线圈正上方。放歪一点，穿过手机这圈的磁就少了，板子得更使劲，还容易发烫。所以有的手机和充电器，各有一圈磁铁，一贴就对正。

板子怎么知道上面是手机？它先问一声，手机就用这圈线回话；钥匙不会回话，板子就不送电。充电时，手机还在说吗？还在说：多一点、少一点。

所以没插线，靠的是磁。
小提示：充得慢、发烫？摘掉厚壳和金属指环，再放正一点。

## 拆题四问
1. **为什么不（插线也能充）？** 电荷没有穿过间隙：板子线圈里的交流电产生交变磁场，磁场穿过外壳，在手机线圈里感应出电流。两边之间没有任何导电接触。
2. **不，意味着什么？** 隔着外壳也能充，但磁集中在线圈正上方：放歪了，穿过手机线圈的磁通变少（耦合变差），板子要加大驱动去补，效率下降、发热（所以有磁吸对正）。
3. **如果放上去的不是手机，会怎样？（必须演示）** 板子先「问一声」（ping），手机通过改变自己的负载「回话」，板子从自己线圈上读出来；钥匙不会回话，板子就不送电。**演示**：左手机、右钥匙并排，同一次「问」，先亮左边（有回话），再亮右边（没回话）。
4. **是了，又意味着什么？** 无线充电是两边一直在「对话」的过程（控制误差包：多一点 / 少一点），不是板子一味地往外放电；放歪、隔着厚壳和金属会变慢、发烫。

- 原来是这样：电没走过去，过去的是磁。
- 原来还可以这样：充电板和手机，一直在用这圈线「说话」。
- 结尾回扣标题：开头问「没插线，电怎么进手机」，结尾「所以没插线，靠的是[磁]」（同一个放手机的动作）。

### 六段式对照
1. 现象：0–2.75（手机放上充电板）
2. 意外的事实（代替错误猜测）：2.75–4.75（没有一根线连着）
3. 钻进去：4.75–8.75（外壳变透 → 两圈线圈）
4. 一个机制：8.75–24.75（电流来回 → 磁跟着翻 → 穿过手机线圈 → 手机线圈里电动起来；电没走过去，过去的是磁；理顺充进电池）
5. 原来还差这一步：24.75–47.5（要放正：磁都挤在正上方 → 放歪少了、板子使劲发烫 → 磁吸；板子怎么知道是手机：问一声、回话、钥匙不回、一直在说）
6. 回到开头：47.5–54.25（同一个放手机的动作 → 闭环句 → 小提示）
