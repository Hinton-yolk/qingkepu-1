选题：用户 11-27「准备做无线充电这个题目」。新一季第一集：画风换成「半透明玻璃实物」，字幕版式、配乐也换（见 `notes.md`）。

## 白话版（v1）

手机往板子上一放，就开始充电了。没插线，电是怎么进手机的？

其实，板子和手机根本没碰到。两边各藏着一圈铜线。

板子这圈铜线里，电流一直在来回换方向，每秒十几万次。电流一变，它周围就有了一阵阵变化的磁。这股磁穿过玻璃，钻进手机里的那圈铜线，手机这圈里，电也就跟着动起来了。

电没有走过去，是磁把它带过去的。手机再把这股来回的电理顺，充进电池。

那为什么一定要放正？磁一离开线圈就散得很快，放歪一点，手机接到的就少一大截。所以有的手机背后有一圈磁铁，一贴就对正。

放一把钥匙上去，它为什么不充？板子会先问一声，手机就用同一圈线回话。没有回话，板子就不送电。充着的时候，手机也一直在说：多一点、少一点。

所以，手机往上一放，它们就接上了。
小提示：充得慢、发烫？摘掉金属指环扣，再放正一点。

## 拆题四问
1. **为什么不（插线也能充）？** 电不是「走」过去的：板子线圈里的交流电产生变化的磁场，磁场穿过外壳，在手机线圈里感应出电流。两边从头到尾没碰到。
2. **不，意味着什么？** 隔着东西也能充，但要靠得近、对得正：磁一离开线圈就散开，放歪、隔太厚就接得少（所以有磁吸对正）。
3. **如果放上去的不是手机，会怎样？（必须演示）** 板子先「问一声」（短促的探测），钥匙不会回话，板子就不送电；手机会用同一对线圈「回话」，还一直告诉板子「多一点 / 少一点」。**演示**：手机和钥匙各放一次，一个有回话的脉冲、一个没有。
4. **是了，又意味着什么？** 无线充电是两边一直在「对话」的过程，不是板子一味地往外放电；金属挡在中间会发烫、会被拒绝，所以摘掉金属指环扣、放正。

- 原来是这样：电没走过去，是磁把它带过去的。
- 原来还可以这样：充电板和手机，一直在用这圈线「说话」。
- 结尾回扣标题：开头问「没插线，电怎么进手机」，结尾「手机往上一放，它们就[接上]了」（同一个放手机的动作）。

## 错误猜测 + 打叉
建议**不用**这一拍，直接给意外的事实「板子和手机，其实[没碰到]」。
备选（如果用户想要）：「你是不是以为，/ 下面有[触点]碰着？」+ ✕ →「中间隔着[两层壳]」。拿不准观众是不是真会这么想（违反「错误猜测必须是观众真会有的想法」的风险），所以不推荐。

### 六段式对照
1. 现象：0–2.75（手机放上充电板）
2. 意外的事实（代替错误猜测）：2.75–4.75（其实没碰到）
3. 钻进去：4.75–8.0（玻璃外壳淡下去 → 两圈线圈）
4. 一个机制：8.0–23.25（电流来回 → 变化的磁 → 穿过去 → 手机线圈里有电；电没走过去，是磁带过去的）
5. 原来还差这一步：23.25–44.75（要放正：磁散得快 → 磁吸；不是手机就不充：板子问、手机答、一直在说）
6. 回到开头：44.75–51.75（同一个放手机的动作 → 闭环句 → 小提示）
