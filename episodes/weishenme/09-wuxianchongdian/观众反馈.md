# EP.09 无线充电 · 观众（Codex）反馈

## 看草稿 v1（2026-11-27；逐秒抽帧 3 张 + 字幕时间表，听不到配乐）

### 1. 第一印象

手机一放就亮，磨砂半透明的画面挺好看，但我最没想到的是，充电板还要等手机「回话」。

### 2. 会不会看完

**我大概会看到 53 秒的小提示，54 秒进片尾就划。** 会点个赞，小提示值得顺手收藏，转发倒没什么冲动。

- **2 秒，不划。** 0 秒第一眼那个白块有点像耳机盒，闪电亮起来，再配上「电怎么进手机的」，我就知道在讲什么了，也想听答案。
- **5 秒，有点想划。** 开头已经问过电怎么进手机了，这里又问「怎么过去」，我会觉得还在铺垫。4–5 秒已经露出铜圈，6 秒看到上下各有一圈，我就有兴趣接着看。
- **15 秒，不划，但有点跟丢。** 蓝线一下子铺满剖面，我不知道该盯蓝线还是上面那圈铜线。字幕刚好问「手机这圈会怎样」，我会再等两秒看答案。
- **21–24 秒是我最可能提前划走的地方。** 18 秒我已经觉得听到了答案，接下来「把电理顺」又来了个新概念，画面里只有个小黑块被框起来。反而 37 秒钥匙一出现，我会立刻想看它和手机有什么区别。

### 3. 看懂了什么 / 没看懂什么

- **6–20 秒**：看懂了手机和充电板里各有一圈铜线，下面那圈先动，后来上面那圈也亮了。**11–15 秒的「磁跟着翻」没看懂**，我看见了蓝色弧线，但说不出什么在翻。「过去的是磁」也让我一瞬间以为是有个东西从下面跑上去了。
- **22–24 秒**：明白手机还要处理一下才能给电池充电，但「理顺」前后有什么区别，我只在小字里看到「交流 → 直流」，没从图上看出来。
- **29–36 秒**：看懂了放歪容易热，右边底下那团橙光很好认。但「穿过手机这圈的磁少了」主要是字幕告诉我的，两边的蓝线看起来都挺多。35 秒又冒出一圈磁铁，我一时没接上它跟刚才的「放正」有什么关系。
- **37–47 秒**：手机有回话、钥匙没回话，这段一眼就懂，也是我最喜欢的地方。46–47 秒的「多一点／少一点」我猜是在说充电的劲儿，但气泡小，我第一眼只顾着看上面的问题。

### 4. 想评论什么

- 「所以磁吸那一圈主要是帮忙对准的吗？我一直以为就是靠那圈磁铁充的。」
- 「我充一会儿就烫，挪一下又能充，原来位置差一点也有影响啊。」

### 5. 建议（按重要程度）

1. **影响理解｜11–18 秒。** 这一段我最想看清三步：下面那圈先亮、蓝线穿过上面那圈、上面那圈再亮。蓝线可以少几根，把穿过手机那圈的几根画清楚。「下面的磁一变，手机这圈的电也跟着动」比「过去的是磁」更贴合我刚看到的画面。
2. **影响理解｜29–36 秒。** 放正和放歪并排时，我想直接看到穿过上面那圈的蓝线哪里少了。接着让两圈磁铁一吸、手机就回到正中，我就能顺着看懂磁吸在这里帮了什么忙。
3. **影响观感｜3–6 秒。** 4 秒既然已经露出铜圈，可以直接接「两边各藏着一圈铜线」。我已经记住开头的问题，这时更想看手机里面有什么。
4. **可有可无｜22–24 秒。** 如果想保留「理顺」这一步，可以在黑块旁边用一个小图画出「来回的箭头进去、朝一个方向的箭头出来」，我扫一眼就能跟上。

## 看草稿 v1.1（2026-11-27）

### 1. 第一印象

磨砂外壳透出两圈铜线挺抓眼，放正和放歪这次看得出差别，但讲到手机那圈电也动起来时，我的眼睛还是先被蓝线抢走了。

### 2. 会不会看完

- **2 秒，会留。** 手一松开就看到橙色闪电，配上「没插线，电怎么进手机的？」我马上知道在讲无线充电。
- **5 秒，有一点想划。** 开头已经问过电怎么进去，中间又说一次没线，到 5 秒还是在问电怎么过去。6–8 秒看到手机和充电板分开、露出两圈铜线，我才觉得开始有答案了。
- **15 秒，会再等两秒。** 我想看手机那圈到底会发生什么，但这也是最容易掉队的地方。14–16 秒蓝线占了大半个示意图，我扫一眼分不清该看上面还是下面。
- **我大概会看到 53 秒的小提示，54 秒进片尾就划。** 手机和钥匙的对比让我重新来劲。我会为这段点个赞，也可能把最后的排查提示转给老抱怨无线充发烫的人。提示够短，我看一遍就能记住，倒不太会专门收藏。

### 3. 看懂了什么 / 没看懂什么

| 时间 | 我第一遍看到的 |
|---|---|
| **11–18 秒** | **前半段懂了，关键一步还得靠字幕。** 11–13 秒蓝线比较淡，我能看到它们是从下面那圈周围出现的。14–15 秒蓝线一下变得很显眼，两圈都被罩住。16–17 秒我读懂了「手机那圈的电也动了」，但第一眼没从画面里找到上面那圈和刚才有什么不同。到 19 秒蓝线淡下去，上圈的橙色才好找。 |
| **22–24 秒** | **看出「理顺」有画出来了。** 23 秒的小波浪变成直线，旁边还框了一个小黑块。到 24 秒下面的橙色块也被框出来，我能猜到是手机里先经过一个零件，再进电池。卡住的是波浪、黑块和电池分在三处，我得来回找，才把它们串成一步。 |
| **29–36 秒** | **这次能看懂放正和放歪的差别。** 29 秒靠标签认左右，31 秒配上蓝线和小电池图标，我能看出右边接到的少。33 秒右边底座泛橙，我读成「放歪这边更容易热」。35–36 秒也看得出多了一圈磁铁，但我还想看它怎么把原本偏开的两圈拉回正中。 |
| **37–47 秒** | 手机和钥匙并排是我最喜欢的一段。两边都有「问」，只有手机那边有「回话」，我不用看懂波形也跟得上。46–47 秒的「多一点」「少一点」让我看懂手机充着的时候还在跟板子沟通。 |

### 4. 我真会发的评论

- 「原来手机一边充电一边还在跟充电板说‘少一点’啊😂」
- 「我那个带指环的壳一放上去就容易热，今晚摘了试试。」

### 5. 建议，按重要程度排

1. **影响理解｜先改 14–17 秒。** 讲完蓝线穿过手机外壳后，把蓝线压淡一点，留一拍只让上面那圈的橙色变化最显眼。我想在读到「也跟着动起来了」的同时，自己就能找到是哪一圈动了。
2. **影响理解｜把 23–24 秒的三个东西连起来。** 波浪、小黑块、直线可以沿同一路径排，直线再接到电池。现在每个符号单看都能认出来，顺序要靠我自己拼。
3. **影响观感｜让两圈铜线更早露出来。** 如果 5 秒问「怎么过去」时两层已经开始拉开，我就能一边看画面给的新信息，一边等答案。
4. **可有可无｜给 35–36 秒磁吸一个短动作。** 让偏开一点的手机吸回正中，我会更容易把那圈磁铁和前面的「放正」联系起来。29–33 秒的对比已经够我看懂。
