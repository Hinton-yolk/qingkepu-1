# EP.09 无线充电 · 观众（Codex）反馈

## 看草稿 v1（2026-11-27；逐秒抽帧 3 张 + 字幕时间表，听不到配乐）

### 1. 第一印象

手机一放就亮，磨砂半透明的画面挺好看，但我最没想到的是，充电板还要等手机「回话」。

### 2. 会不会看完

**我大概会看到 53 秒的小提示，54 秒进片尾就划。** 会点个赞，小提示值得顺手收藏，转发倒没什么冲动。

- **2 秒，不划。** 0 秒第一眼那个白块有点像耳机盒，闪电亮起来，再配上「电怎么进手机的」，我就知道在讲什么了，也想听答案。
- **5 秒，有点想划。** 开头已经问过电怎么进手机了，这里又问「怎么过去」，我会觉得还在铺垫。4–5 秒已经露出铜圈，6 秒看到上下各有一圈，我就有兴趣接着看。
- **15 秒，不划，但有点跟丢。** 蓝线一下子铺满剖面，我不知道该盯蓝线还是上面那圈铜线。字幕刚好问「手机这圈会怎样」，我会再等两秒看答案。
- **21–24 秒是我最可能提前划走的地方。** 18 秒我已经觉得听到了答案，接下来「把电理顺」又来了个新概念，画面里只有个小黑块被框起来。反而 37 秒钥匙一出现，我会立刻想看它和手机有什么区别。

### 3. 看懂了什么 / 没看懂什么

- **6–20 秒**：看懂了手机和充电板里各有一圈铜线，下面那圈先动，后来上面那圈也亮了。**11–15 秒的「磁跟着翻」没看懂**，我看见了蓝色弧线，但说不出什么在翻。「过去的是磁」也让我一瞬间以为是有个东西从下面跑上去了。
- **22–24 秒**：明白手机还要处理一下才能给电池充电，但「理顺」前后有什么区别，我只在小字里看到「交流 → 直流」，没从图上看出来。
- **29–36 秒**：看懂了放歪容易热，右边底下那团橙光很好认。但「穿过手机这圈的磁少了」主要是字幕告诉我的，两边的蓝线看起来都挺多。35 秒又冒出一圈磁铁，我一时没接上它跟刚才的「放正」有什么关系。
- **37–47 秒**：手机有回话、钥匙没回话，这段一眼就懂，也是我最喜欢的地方。46–47 秒的「多一点／少一点」我猜是在说充电的劲儿，但气泡小，我第一眼只顾着看上面的问题。

### 4. 想评论什么

- 「所以磁吸那一圈主要是帮忙对准的吗？我一直以为就是靠那圈磁铁充的。」
- 「我充一会儿就烫，挪一下又能充，原来位置差一点也有影响啊。」

### 5. 建议（按重要程度）

1. **影响理解｜11–18 秒。** 这一段我最想看清三步：下面那圈先亮、蓝线穿过上面那圈、上面那圈再亮。蓝线可以少几根，把穿过手机那圈的几根画清楚。「下面的磁一变，手机这圈的电也跟着动」比「过去的是磁」更贴合我刚看到的画面。
2. **影响理解｜29–36 秒。** 放正和放歪并排时，我想直接看到穿过上面那圈的蓝线哪里少了。接着让两圈磁铁一吸、手机就回到正中，我就能顺着看懂磁吸在这里帮了什么忙。
3. **影响观感｜3–6 秒。** 4 秒既然已经露出铜圈，可以直接接「两边各藏着一圈铜线」。我已经记住开头的问题，这时更想看手机里面有什么。
4. **可有可无｜22–24 秒。** 如果想保留「理顺」这一步，可以在黑块旁边用一个小图画出「来回的箭头进去、朝一个方向的箭头出来」，我扫一眼就能跟上。

只看了逐秒抽帧和字幕，听不到配乐。没有改文件，也没跑技术检查。

## 看草稿 v1.1（2026-11-27）

### 1. 第一印象

磨砂外壳透出两圈铜线挺抓眼，放正和放歪这次看得出差别，但讲到手机那圈电也动起来时，我的眼睛还是先被蓝线抢走了。

### 2. 会不会看完

- **2 秒，会留。** 手一松开就看到橙色闪电，配上「没插线，电怎么进手机的？」我马上知道在讲无线充电。
- **5 秒，有一点想划。** 开头已经问过电怎么进去，中间又说一次没线，到 5 秒还是在问电怎么过去。6–8 秒看到手机和充电板分开、露出两圈铜线，我才觉得开始有答案了。
- **15 秒，会再等两秒。** 我想看手机那圈到底会发生什么，但这也是最容易掉队的地方。14–16 秒蓝线占了大半个示意图，我扫一眼分不清该看上面还是下面。
- **我大概会看到 53 秒的小提示，54 秒进片尾就划。** 手机和钥匙的对比让我重新来劲。我会为这段点个赞，也可能把最后的排查提示转给老抱怨无线充发烫的人。提示够短，我看一遍就能记住，倒不太会专门收藏。

### 3. 看懂了什么 / 没看懂什么

| 时间 | 我第一遍看到的 |
|---|---|
| **11–18 秒** | **前半段懂了，关键一步还得靠字幕。** 11–13 秒蓝线比较淡，我能看到它们是从下面那圈周围出现的。14–15 秒蓝线一下变得很显眼，两圈都被罩住。16–17 秒我读懂了「手机那圈的电也动了」，但第一眼没从画面里找到上面那圈和刚才有什么不同。到 19 秒蓝线淡下去，上圈的橙色才好找。 |
| **22–24 秒** | **看出「理顺」有画出来了。** 23 秒的小波浪变成直线，旁边还框了一个小黑块。到 24 秒下面的橙色块也被框出来，我能猜到是手机里先经过一个零件，再进电池。卡住的是波浪、黑块和电池分在三处，我得来回找，才把它们串成一步。 |
| **29–36 秒** | **这次能看懂放正和放歪的差别。** 29 秒靠标签认左右，31 秒配上蓝线和小电池图标，我能看出右边接到的少。33 秒右边底座泛橙，我读成「放歪这边更容易热」。35–36 秒也看得出多了一圈磁铁，但我还想看它怎么把原本偏开的两圈拉回正中。 |
| **37–47 秒** | 手机和钥匙并排是我最喜欢的一段。两边都有「问」，只有手机那边有「回话」，我不用看懂波形也跟得上。46–47 秒的「多一点」「少一点」让我看懂手机充着的时候还在跟板子沟通。 |

### 4. 我真会发的评论

- 「原来手机一边充电一边还在跟充电板说‘少一点’啊😂」
- 「我那个带指环的壳一放上去就容易热，今晚摘了试试。」

### 5. 建议，按重要程度排

1. **影响理解｜先改 14–17 秒。** 讲完蓝线穿过手机外壳后，把蓝线压淡一点，留一拍只让上面那圈的橙色变化最显眼。我想在读到「也跟着动起来了」的同时，自己就能找到是哪一圈动了。
2. **影响理解｜把 23–24 秒的三个东西连起来。** 波浪、小黑块、直线可以沿同一路径排，直线再接到电池。现在每个符号单看都能认出来，顺序要靠我自己拼。
3. **影响观感｜让两圈铜线更早露出来。** 如果 5 秒问「怎么过去」时两层已经开始拉开，我就能一边看画面给的新信息，一边等答案。
4. **可有可无｜给 35–36 秒磁吸一个短动作。** 让偏开一点的手机吸回正中，我会更容易把那圈磁铁和前面的「放正」联系起来。29–33 秒的对比已经够我看懂。

## 看草稿 v4（2026-11-28；注意：这一轮给它的字幕表误用了旧版，它按画面说话，画面部分的意见有效）

### 1. 第一印象

手机一放下就亮起充电符号，我会停下来想「对啊，电到底怎么进去的？」，后面最让我有「原来如此」感觉的是手机放歪以后，充电板上冒出一团热。

### 2. 会不会看完

- **2 秒，不会划。** 问题一眼就能读完，闪电符号亮起来也很直观。手机一眼认得出，手有点像蜡做的，尤其是 0 秒搭在手机边上的几根手指，指缝看起来挤在一起，但我还是会继续看。
- **5 秒，还会看。** 手机和底座已经拆开，露出上下两圈铜线，我想知道中间隔着一段怎么也能充。只是「没有线连着」和「那电怎么过去」连着读，感觉开头的问题又问了一遍。
- **15 秒，开始想划。** 刚看懂磁铁插进线圈、灯亮了一下，画面又切回充电板，问「可充电板里没有会动的磁铁？」我得自己把刚才的实验和手机接起来。**16–20 秒最容易划走**，因为蓝线、蓝点和橙圈同时出现，我还在找该看哪儿，答案已经出来了。
- **如果撑过这段，我会看到 55 秒左右的小提示。** 放歪、发热、拿掉指环，这几张一眼就懂。我可能会顺手点赞，收藏和转发的动力一般。看到片尾卡开始出字，我就会划下一条。

### 3. 看懂了什么／没看懂什么

给的字幕表和拼图在 **9 秒起**明显对不上。比如表里已经在讲板子里的电流，9 秒画面却是磁铁插线圈、灯亮；表里后半段讲手机「回话」，40–48 秒的画面讲的是金属发热和降速、停充。下面的秒数以**拼图上实际看到的画面和字幕**为准。

| 秒数 | 刷过去时我看懂了什么 |
|---|---|
| **4–8 秒** | 看懂手机和底座里各藏着一圈铜线。上下拆开的画面比「发射线圈」「接收线圈」的小字更好懂。 |
| **9–15 秒** | 看懂磁铁动的时候灯会亮一下。「磁一变，线圈里就有电」这句能记住。回到充电板时，我还不知道里面哪个东西在做刚才磁铁做的事。 |
| **16–22 秒** | 看到上面那圈变橙了，也读懂了字幕在说手机里的电动起来了。但第一眼有点像在看蓝点从底座往手机跑。到 21 秒读到「电没走过去，过去的是磁」，我才回头想蓝线是在表示什么。 |
| **24–27 秒** | 波浪线经过小黑块变成直线，再接到电池，这段我一眼就明白「理顺」是什么意思。 |
| **31–38 秒** | 看懂了手机挪偏、充电板变热，挪回来热色就消下去。偏了以后到底少了什么，我得在一堆蓝线里找。接着看到「各有一圈磁铁」，我又犹豫了一下：这圈磁铁是帮手机吸到正中间，还是刚才说的充电靠的就是它？ |
| **40–55 秒** | 金属片里出现一圈圈红线，接着变热，我能跟上。47 秒两根条也能看出「板子送得多，手机收到得少」，但红色那截代表差多少，还是代表正在降速，我第一眼没读出来。最后摘指环、把手机放正，是我最记得住的画面。 |

### 4. 想评论什么

- 「所以磁吸那一圈就是帮忙对准的吗？我一直以为吸上去的那个磁铁就是负责充电的。」
- 「我那个带金属指环的壳，放上去有时候亮一下就停了，看到后面才想到可能是它。」

### 5. 建议（按重要程度）

1. **影响理解｜先把字幕表和抽帧对上。** 尤其是 37–48 秒，我看到的是金属片发热和两条横条，表里读到的是手机回话。先确认 v4 实际用哪一段，才好判断后半段接得顺不顺。
2. **影响理解｜把 14–22 秒的变化分三下给我看。** 先让我盯着下面那圈，看它的电流换向；再让几根蓝线明显变一下；最后上面那圈亮起来。现在橙圈、蓝线和蓝点一起抢眼，我读到答案才知道该看谁。
3. **影响理解｜把「对准了有什么用」直接画出来。** 31–38 秒可以让对准和偏开用同一个角度，突出穿过上面那圈的蓝线怎么变少。磁铁出现时，我最想看到的是它把两圈吸到正对的位置。
4. **影响观感｜缩短 3–6 秒的重复提问。** 闪电亮过以后，我已经知道是在问没插线怎么充。早点露出两圈铜线，会比继续换一句话问同一个问题更留得住我。开头那只手如果还要修，我最先注意到的是指缝。

## 看草稿 v4.1（2026-11-28，字幕表已更正）

### 1. 第一印象

手机一放下就亮起充电标志，我会想知道电到底怎么进去的，但看完最记得的是手机放歪了为什么会发烫。

### 2. 会不会看完

- **2 秒，不划。** 橙色闪电一亮，我马上知道在讲无线充电。手有点像蜡做的，但我第一眼看的是屏幕。
- **5 秒，大概不划。** 手机和底座拆开、露出两个铜圈，我想看这俩圈怎么配合。不过字幕还在绕着「没线，电怎么过去」问，已经有点等答案了。
- **15 秒，先不划。** 刚看完磁铁一动、灯亮一下，我也想知道充电板里没有会动的磁铁，那到底靠什么。**最可能划走的是 18–22 秒**，蓝线和橙点挤在一起，我还在找哪个东西变了，字幕已经跳到「过去的是磁」。
- 如果撑过这段，我大概会看到 **55 秒的小提示**，片尾卡出来就划。挪歪变热、夹块金属也变热，这两段我会点赞。可能会发给那个总抱怨无线充电烫的朋友，我自己大概不会收藏。

### 3. 看懂了什么 / 没看懂什么

- **7–13 秒**，看懂了手机和底座各藏一个线圈，也看懂了磁铁进出时灯会亮一下。灯亮是我第一次能直接从画面上看出「这里有电了」。
- **16–22 秒**，大致懂了底座先动了什么，手机那圈才有电。但「它让电流来回换向」的「它」我得回想一下。到「手机这圈被磁穿过」时，我只看到一片蓝线罩住两个圈，没一眼看出**蓝线先怎么变、手机那圈又什么时候有了电**。「过去的是磁」还让我想到后面那圈会吸住手机的磁铁。
- **24–27 秒**，波浪线过了小黑块变成直线，电池里的橙色也多了。这段看一遍就懂，芯片是把来回跑的电变成电池能收的样子。
- **31–38 秒**，手机挪偏、底座变黄，再挪回来，最容易跟上。看到磁吸那一圈时，我能猜到是帮手机对准，但字幕只说两边各有磁铁。我会短暂卡一下，刚才还说里面没有会动的磁铁，这里这圈又是干什么的？
- **40–48 秒**，夹进去的金属片自己亮成一小块黄，发热这件事很直观。后面两根条我能看懂一长一短，但我会顺着字幕理解成「只要送出的比收到的多，就会停充」。红色那截到底代表什么，我得停一下才有机会看明白。

### 4. 想评论什么

- 「原来我每次放歪还硬充，烫的是底座啊😂」
- 「后面吸住手机的那圈磁铁，跟前面说的‘过去的是磁’是两回事吗？」

### 5. 建议

1. **影响理解｜先改 16–22 秒。** 我想先看见底座那圈的橙点换向，再看蓝线跟着变，最后看手机那圈的橙点亮起来。字幕里把「它」直接叫「充电板」，把「过去的是磁」说成「底座的磁场一变，手机线圈里就有了电」。我在磁铁点灯那段已经看懂了，最想在这里认出同一个过程。
2. **影响理解｜给 37–39 秒的磁吸一个明确结果。** 两圈吸上时，让手机从偏一点的位置扣回正中，字幕补一句「这圈磁铁帮手机对准」。刚看完放歪会发热，我能马上接上。
3. **影响理解｜把 46–48 秒的红色差额和停充接起来。** 两根条之间突然多出来的那截红色可以先单独亮一下，再显示降速或停充。字幕用「差太多」也比「送出的比收到的多」更好跟。
4. **影响观感｜4–7 秒早点露出两圈铜线。** 开头的手机和闪电我会留。一拆开就让我看见两圈铜线，能少等一句重复的问题。这几秒最有看课件的感觉，后面的挪偏和变热就明显更像在看演示。
5. **可有可无｜手和手机的质感。** 0 秒右侧几根手指贴得很紧，确实有点蜡像感。手机的听筒、厚边和充电标志已经足够让我一眼认出来。我会先改中间那段，再看手要不要修。
