# EP.05 体脂秤 · 评论回复（2026-11-10）

数据（用户报告，上线约 12 小时，抖音）：浏览近 4 万，获赞 373，收藏 57，评论 39。评论区最关心的是「准不准」。

## 1. 「四电极测出来 22.3，八电极测出来 15.6，该相信哪个？」

```text
两个都不算“标准答案”，但八电极一般更靠谱一点：四电极只踩脚，电基本只在两条腿之间走，上半身靠公式猜；八电极手脚一起握，电能走过全身。拿医院的 DEXA 对比的研究里，八电极也跟得更紧。再加上两台秤的公式不一样，绝对值本来就对不上。建议固定用一台、每天同一时间光脚测，看它自己的变化。想要准数，可以去医院做 DEXA（双能 X 线体成分检测）。
```

## 2. 「穿上袜子上秤有没有影响？」

```text
有影响，要光脚。体脂秤靠脚底贴住那几块金属片通电，隔着袜子电很难过去，体脂就测不准（说明书里都写了要光脚）。体重倒是不受影响。
```

## 3. 置顶 / 统一回复「准不准」

```text
统一回一下大家最关心的“准不准”：体脂秤给的是估算，换一台秤差好几个点很正常，单次的数别太当真。但同一台秤、每天同一时间、光脚测，它的变化趋势是有参考价值的。想知道准确的体脂，医院的 DEXA（双能 X 线体成分检测）更准。
```

## 依据
- 八电极比四电极（只踩脚）和 DEXA 更一致：Tanita 研究，八电极与 DEXA 的相关 r = 0.87，四电极 r = 0.82（[Pietrobelli et al., EJCN 2004](https://www.nature.com/articles/1601993.pdf)，仅读到摘要）。
- 不同设备 / 公式不能互换，个体误差大，但同一人的排序 / 变化相对稳定：[J Transl Med 2024 综述](https://translational-medicine.biomedcentral.com/counter/pdf/10.1186/s12967-024-05272-x.pdf)；[Journal of Electrical Bioimpedance 2018](https://doaj.org/article/99e9cfd1dacc41d9ac891ea50f382c76)；[Measurement Toolkit](https://measurement-toolkit.org/anthropometry/objective-methods/bioelectric-impedence-analysis)。
- 要光脚、穿袜子会出误差：[Tanita BC-418 说明](https://www.notice-facile.com/en/manual/1271279/tanita+bc-418)；[Omron](https://omronhealthcare.com/scales)；另一品牌说明书写明穿袜子或丝袜会导致测量误差（[示例](https://manualedistruzioni.it/aws/scale/msl-180/user-manual/2c75j)）。「穿袜子就测不出体脂」没有找到统一来源，所以回复里只说「测不准」。
- 「电基本只在两条腿之间走」：FACTS.md 第 11 行（仅单一来源）。
