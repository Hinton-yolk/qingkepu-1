# SPEC — EP.05 体脂秤：体脂秤怎么知道你有多少脂肪？（内容关卡 2 草稿）

GOAL:    看完的人能复述：体脂秤脚下的金属片在给你通一股很弱的电，从一只脚进、沿腿上去、从另一只脚出来；肌肉里水多，电好走，
         脂肪里水少，电难走；脂肪越多电越难走 —— 体脂秤其实是一台测电阻的表；电阻再加上身高、体重、年龄、性别套公式，才"算"出体脂率
         （所以第一次用要填资料）；水一变，数就变，所以看趋势。
OUTPUT:  单文件 canvas 页面，`window.seek(t)` 画第 t 秒（纯函数，种子随机 mulberry32）；1080 × 1920，30 fps；`node render.mjs` 出帧，
         H.264 yuv420p CRF 16，AAC 256k `-aac_coder fast` → `out/ep05-tizhicheng.mp4`。
TIME:    52.25 s × 30 fps = 1567 帧；120 BPM；所有提示点在 0.25 s 网格上。片头（第 1 段）0–2.75 s（用户 2026-11-09：片头缩短）。
         相对脚本只移动了两处（都 ≤ 0.5 s，落到拍点上）：名词 21.25 → 21.0，闭环句 40.75 → 41.0。
         打叉 5.0、名词 21.0、闭环那一脚 41.0（都在拍点上）；片尾卡 49.25 起，问号 50.5 落在最后一个 DO 上。
MOTION:  第 0 帧右脚正往玻璃秤上落（0.5 s 落稳），左脚已在秤上；每段停留都匀速漂移；暗场里电荷一直在往上走；
         快动作（落脚、转橙底、打叉、推近、拉到正面、钻进去、名词、拉出、卡片、横移到手机、再踩一次、片尾）在 BLUR 窗口里做 6 次子采样运动模糊。
         没有任何抖动：唯一的"呼吸"是很慢的（指针 0.35 Hz、水滴 0.4 Hz、亮片 0.5 Hz），振幅都在 1–3 px。

## 空间与相机

一个连续空间（世界单位 mm；x 向右，y 朝镜头，z 向上）：地上一台 320 × 320 mm 的深色钢化玻璃体脂秤（玻璃顶面 z = 26），
玻璃上四块拉丝不锈钢电极片（每只脚前掌、脚跟各一块），显示屏在脚尖前面、朝向站在秤上的人；一个人面向镜头站在秤上，只画腰以下
（光脚、短裤，腰部往上在图层里渐隐）；秤右边的地上平放一部手机（通用 App 界面，无品牌）。

一台正交相机，带俯仰角 θ（90° = 正前方平视，0° = 正上方俯视）：`screen = A·(x, piv + (y − piv)·cosθ − z·sinθ) + B`，
`key()/interp()`（对数螺线插值）沿用 EP.04；放大镜圆窗里用同一套相机（`mx = −1` 可镜像）。

人体画法：腿 = 水平椭圆环（按真人比例：踝骨 70 mm、踝上最细 58 mm、小腿最粗 108 mm 在 330 mm 高、内侧更鼓、膝 500 mm、裆 800 mm，
Catmull-Rom 平滑成每 18 mm 一环）；脚 = 正面平底环（长 245、前掌宽 95）；五个脚趾各自一根小管 + 指甲。每对相邻环投影后取凸包并成一个
轮廓（并集），在单独图层里"先描墨线、再挖空、再平涂"，所以 X 光时只剩外轮廓，不会出现内部的环线。肤色 #EBCBA5 / 暗部 #D6AD84 /
指甲 #F3DCCB；短裤灰蓝 #78808C；明暗只来自一层左上来光的柔和渐变，没有任何纹理。

## SOUND（music/score.mjs，全部代码合成）

- F 大调，120 BPM 直拍十六分，系列同一套合成器音色和鼓组。
- 钩子 = 秤的开机提示音 mi-sol-la（A6 C7 D7），测量中的"嘀"是 C7（sol）；闭环那一脚提示音解决成 mi-sol-DO（A6 C7 F7）。电流的"嗡"声在 F2（87.3 Hz），只在含 F 的和弦下全响。
- 和声（本系列第一次用）：讲解段走下行低音 F – C/E – Dm – Am/C – Bb – F/A – Gm – C（I–V6–vi–iii6–IV–I6–ii–V），一秒一个和弦；
  开场悬在 ii–V（Gm7–Csus–C），误区落在 vi（Dm），后半段 ii–V–I–vi（Gm7–C–F–Dm）。名词前是 IV–V（Bb–C）→ 停半拍 → I（F）。
  （EP.01/03：C 大调 IV–V–iii–vi；EP.02：G 大调 vi–IV–I–V；EP.04：D 大调 IV–V … vi–ii–V–iii–IV–V。）
- 三种织体：开场 = 提示音 + 轻鼓 + 长低音 + 八分拨弦；讲解 = 八分脉冲和弦 + 八分低音（跟着下行低音）+ 十六分"电流"闪音（讲脂肪时变成闷的八分，脂肪变厚时一颗颗掉）；
  揭晓 = 四踩、反拍开镲、八度低音 + 主旋律。后半段加马林巴琶音（新颜色）。揭晓前（20.75、40.75）停半拍。
- 打叉前 0.5 s 真静音；最响三下（混音前峰值）：打叉 −1.3、名词 −1.1、闭环那一脚 −1.0 dBFS，其余 ≤ −2.6 dBFS。
- 每个问题同一个上行四度（C6 → F6）。音效：落脚、秤的"嘀"、tick、打叉、电流嗡声、水滴 plink，没有噪声嗖嗖声。母带 `tools/master.sh` → −14 LUFS。
