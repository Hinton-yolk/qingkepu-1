# EP.05 体脂秤 · 观众反馈（Codex 扮演，2026-11-09）

看的是：逐秒抽帧（3 张拼图）、字幕时间表、两张封面、publish.md。听不到声音。是否采纳由用户决定。

1. **第一印象**

画面干净，东西一眼认得出来；“踩上去其实在通电”比“亮片是不是装饰”更让我想继续看。

2. **会不会停下来，什么时候想划走**

- **封面：**小红书里我会有机会点开，尤其是刚被体脂数字搞烦的时候。大字够清楚，但放大镜里的截面和表盘，我第一眼不知道是什么，主要靠标题吸引我。两张封面给我的吸引力差不多。
- **2 秒：会留下。**脚踩上去先出体重、再出体脂率，配这个问题，我会想：“对啊，它怎么知道的？”
- **5 秒：是第一个可能划走的位置。**“你是不是以为亮片只是装饰”没说中我，我没想过它是装饰，只是不知道有什么用。打叉时还没得到新信息；后面“正在给你通电”才能把我拉回来。
- **15 秒：大概率继续看。**我已经看懂电从两条腿绕过去，也知道它在测“难不难走”，接下来确实想知道这跟脂肪有什么关系。不过前面连续几个问句，让我有一点“还在等答案”的感觉。
- **更可能提前离开的是 25–27 秒。**“原来是测电阻”已经给了我一个答案。后面“为什么每次测都不一样”跟我更有关，但要到 36 秒才出现。

如果看到后面的数字波动，我会愿意看到实用提示；片尾卡出来就划走。

3. **看懂了什么，哪里别扭**

我看懂的主线是：**金属片通很弱的电 → 肌肉和脂肪让电通过的难易不同 → 再结合个人资料算体脂率 → 水分变化也会影响数字，所以看趋势。**最有用的是后半段，它解释了我为什么不能拿一次读数判断自己胖没胖。

几个卡点：

- **3–5 秒：**“以为是装饰”有点替我安排了一个我没有的想法。
- **14–24 秒：**表盘没有明确告诉我哪边代表“难走”，我主要靠字幕理解。两个样本下面的指针，单看图不能马上读懂。
- **22–24 秒：**“电越难走，脂肪就越多”让我先记成一个很直接的判断；**39–43 秒**又说水变了数字也变，我会回头疑惑：“那它怎么分清是脂肪多，还是水少？”这是我看完最想问的。
- **30–32 秒：**图里有“体重”，字幕只列身高、年龄、性别。我能猜体重刚才已经称过了，但这一屏既要读字幕又要看五个框，有点忙。
- **45–47 秒：**“它不是在称脂肪，是在用电算”好记，但“估算”这个意思，在小红书正文里比视频里明确。只看视频，我仍不清楚那个百分数该信到什么程度。
- **50–52 秒：**起搏器提醒那行小字，在这组图里明显比主字幕难读，容易只顾着看趋势线就漏掉。

我只看到了逐秒抽帧和字幕时间表，听不到音乐，不能判断实际播放的流畅度和卡点效果。

4. **会不会互动，想评论什么**

**会考虑点赞；收藏意愿一般，转发意愿低。**知道一个以前没想过的原理，值得点个赞。但实用结论只有“同一时间测、看趋势”，我大概记住就走了。如果朋友正因为体脂率忽高忽低焦虑，我会转给他。

我可能真的会发的评论：

- “难怪我早晚测差那么多，所以不一定是胖了？”
- “那它怎么分清我是脂肪多，还是身体里水少？”
- “只踩两只脚，就能算出上半身的脂肪吗？”

第三个问题，小红书正文已经回答了；只看视频我还是会问。

5. **建议，按重要程度排**

1. **22–24 秒和 45–47 秒，把“估算”的意思说清楚。**现在我容易先记住“电阻大就是脂肪多”，后面再被水分变化弄糊涂。结尾明确落到“结合资料估算体脂”，更能回答标题。
2. **3–5 秒，换掉“只是装饰”这个猜测。**直接围绕“这几块金属片在给你通电”制造意外，更贴近我真实的未知，也能更早给出值得留下的信息。
3. **把 36 秒的“每次测都不一样”提前露出来。**比如在解释完电阻后就接这个疑问。我在 25 秒觉得答案已经听完了，需要早点知道后面还能解释我的实际困扰。
4. **14–24 秒，让表盘直接标出“好走／难走”。**我不用先学会读指针，才能看懂两边差别；否则这部分主要还是在读字幕。
5. **48–52 秒，把起搏器提醒放大、单独留出清楚的位置。**现在视觉注意力都在手机曲线上，小字容易漏掉。

## v3（57.25 秒）· 观众反馈（Codex，2026-11-09）

**1. 第一印象**

原来体脂秤会给我通电，这个值得看；看完最记得的是“水少了，也可能被算成脂肪多”。

以下只根据抽帧、字幕时间表和发布文案反馈；我听不到音乐，不能判断实际播放的流畅度和声画节奏。

**2. 会不会停下来、在哪里划走**

- **封面：**小红书里会有点进去的意愿。问题很明确，秤和脚一眼认得出来。不过圆圈里的剖面，第一眼有点像肉肠切面，我会先看标题，没立即看懂放大图。两张封面的吸引力对我差不多。
- **第一帧／2 秒：**会停住。体重变成体脂率，正好对应“它怎么知道”的疑问。但这时只是好奇，还没到非看不可。
- **5 秒：**会继续。“亮片正在给你通电”比开头的问题更抓我，“我怎么没感觉”也确实是我会想的。
- **15 秒：**还会看，但开始有点急：已经问了“通电想知道什么”，现在又问“跟脂肪有什么关系”，我会想“直接告诉我吧”。好在马上出现肌肉和脂肪的对比。
- **最容易划走的是 22.5–25 秒：**“所以它是测电阻的表”让我以为答案讲完了。后面“为什么每次不一样”能重新拉住我，这个问题比前一句更贴近使用体验。
- **39–44 秒想快进：**填身高、年龄、性别这件事我已经明白了，继续看滑块操作，感觉在等下一条信息。
- **48 秒以后：**“看趋势”我会读，随后可能划走，不太会专门等片尾卡。

**3. 看懂了什么、哪里别扭**

看懂的主线是：**通电 → 看电有多难走 → 根据身体里的水和个人资料估算体脂。**数字变化不一定代表脂肪变化，这是我觉得最有收获的地方。

几个具体卡点：

- **11–13 秒：**腿上的线路能让我明白电从一边走到另一边，但仪表的指针本身不直观。我需要再读“好走／难走”才知道它在表示什么。
- **16–21 秒：**肌肉、脂肪并排是好懂的，但小水滴、小圆点、细线同时出现，我主要靠字幕理解。单看画面，未必能马上看出哪边更难走。
- **23–24 秒：**记住了“测电阻”，但还没明白电阻怎么变成百分比。后面补了资料和估算，才接上。
- **34.75–38 秒：**“水都是正常的”有点含糊，我会问“正常是多少？”后一句“水一少，就会被算成脂肪多”反而一下就懂。这段是全片最值得记住的。
- **39–44 秒：**知道它需要个人资料，但不知道这些资料怎么影响结果。“加上你的身高、年龄、性别”听起来有一点像把几个数直接相加。正文里的“套进公式里算”更明白。
- **45.75–48 秒：**“不是在称脂肪，是在用电估算”把前面收住了，这句读完，我觉得标题的问题确实回答了。

小红书正文我会先扫①–④和小提示，不会逐字读完。里面“上半身靠公式推算”会让我额外停一下，这是片中没讲、但正文里挺吸引我的信息。

**4. 会怎么互动**

**会点赞，收藏意愿一般，转发给正在减脂的人会比转发群聊更有可能。**收藏的理由主要是测量提示，不是前面的原理。

我可能真的会发：

**5. 建议，按重要程度排**

1. **让 16–21 秒的“好走／难走”直接出现在肌肉和脂肪旁边。**现在我还要低头认仪表；直接标出来，看图就能接住区别。
2. **压短 39–44 秒填资料的演示。**资料项出现后，我就知道要填什么了；更想马上看到“这些资料一起用来估算”。
3. **把 25 秒“为什么每次测都不一样”接得更紧。**22.5 秒很像结束点，下一问早点出现，更容易让我留下来看真正跟自己有关的部分。
4. **34.75 秒把“水都是正常的”说得更具体一点。**例如“它先按正常含水量来算”，我更容易接上后面的“水少会算成脂肪多”。
5. **封面的放大图加一个短标注，例如“电穿过身体”。**现在大标题负责吸引我，圆圈还没提供一个一眼能懂的新信息。
