# EP.05 体脂秤 · 观众反馈（Codex 扮演，2026-11-09）

看的是：逐秒抽帧（3 张拼图）、字幕时间表、两张封面、publish.md。听不到声音。是否采纳由用户决定。

1. **第一印象**

画面干净，东西一眼认得出来；“踩上去其实在通电”比“亮片是不是装饰”更让我想继续看。

2. **会不会停下来，什么时候想划走**

- **封面：**小红书里我会有机会点开，尤其是刚被体脂数字搞烦的时候。大字够清楚，但放大镜里的截面和表盘，我第一眼不知道是什么，主要靠标题吸引我。两张封面给我的吸引力差不多。
- **2 秒：会留下。**脚踩上去先出体重、再出体脂率，配这个问题，我会想：“对啊，它怎么知道的？”
- **5 秒：是第一个可能划走的位置。**“你是不是以为亮片只是装饰”没说中我，我没想过它是装饰，只是不知道有什么用。打叉时还没得到新信息；后面“正在给你通电”才能把我拉回来。
- **15 秒：大概率继续看。**我已经看懂电从两条腿绕过去，也知道它在测“难不难走”，接下来确实想知道这跟脂肪有什么关系。不过前面连续几个问句，让我有一点“还在等答案”的感觉。
- **更可能提前离开的是 25–27 秒。**“原来是测电阻”已经给了我一个答案。后面“为什么每次测都不一样”跟我更有关，但要到 36 秒才出现。

如果看到后面的数字波动，我会愿意看到实用提示；片尾卡出来就划走。

3. **看懂了什么，哪里别扭**

我看懂的主线是：**金属片通很弱的电 → 肌肉和脂肪让电通过的难易不同 → 再结合个人资料算体脂率 → 水分变化也会影响数字，所以看趋势。**最有用的是后半段，它解释了我为什么不能拿一次读数判断自己胖没胖。

几个卡点：

- **3–5 秒：**“以为是装饰”有点替我安排了一个我没有的想法。
- **14–24 秒：**表盘没有明确告诉我哪边代表“难走”，我主要靠字幕理解。两个样本下面的指针，单看图不能马上读懂。
- **22–24 秒：**“电越难走，脂肪就越多”让我先记成一个很直接的判断；**39–43 秒**又说水变了数字也变，我会回头疑惑：“那它怎么分清是脂肪多，还是水少？”这是我看完最想问的。
- **30–32 秒：**图里有“体重”，字幕只列身高、年龄、性别。我能猜体重刚才已经称过了，但这一屏既要读字幕又要看五个框，有点忙。
- **45–47 秒：**“它不是在称脂肪，是在用电算”好记，但“估算”这个意思，在小红书正文里比视频里明确。只看视频，我仍不清楚那个百分数该信到什么程度。
- **50–52 秒：**起搏器提醒那行小字，在这组图里明显比主字幕难读，容易只顾着看趋势线就漏掉。

我只看到了逐秒抽帧和字幕时间表，听不到音乐，不能判断实际播放的流畅度和卡点效果。

4. **会不会互动，想评论什么**

**会考虑点赞；收藏意愿一般，转发意愿低。**知道一个以前没想过的原理，值得点个赞。但实用结论只有“同一时间测、看趋势”，我大概记住就走了。如果朋友正因为体脂率忽高忽低焦虑，我会转给他。

我可能真的会发的评论：

- “难怪我早晚测差那么多，所以不一定是胖了？”
- “那它怎么分清我是脂肪多，还是身体里水少？”
- “只踩两只脚，就能算出上半身的脂肪吗？”

第三个问题，小红书正文已经回答了；只看视频我还是会问。

5. **建议，按重要程度排**

1. **22–24 秒和 45–47 秒，把“估算”的意思说清楚。**现在我容易先记住“电阻大就是脂肪多”，后面再被水分变化弄糊涂。结尾明确落到“结合资料估算体脂”，更能回答标题。
2. **3–5 秒，换掉“只是装饰”这个猜测。**直接围绕“这几块金属片在给你通电”制造意外，更贴近我真实的未知，也能更早给出值得留下的信息。
3. **把 36 秒的“每次测都不一样”提前露出来。**比如在解释完电阻后就接这个疑问。我在 25 秒觉得答案已经听完了，需要早点知道后面还能解释我的实际困扰。
4. **14–24 秒，让表盘直接标出“好走／难走”。**我不用先学会读指针，才能看懂两边差别；否则这部分主要还是在读字幕。
5. **48–52 秒，把起搏器提醒放大、单独留出清楚的位置。**现在视觉注意力都在手机曲线上，小字容易漏掉。
