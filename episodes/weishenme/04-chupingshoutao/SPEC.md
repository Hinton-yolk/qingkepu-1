# SPEC — EP.04 触摸屏：戴着手套，为什么点不动屏幕？（内容关卡 2 草稿）

GOAL:    看完的人能复述：屏幕不管你按没按；玻璃下面有一张横竖两层的通电细线网，手指一靠近就把附近几格的电"引走"一点，
         屏幕一行行扫，哪格电少了就是你点的位置（电容屏）；手套不导电，电引不走；只要导电，香肠也能点；触屏手套在指尖织进了导电线。
OUTPUT:  单文件 canvas 页面，`window.seek(t)` 画第 t 秒；1080 × 1920，30 fps；`node render.mjs` 出帧，H.264 yuv420p CRF 16，AAC `-aac_coder fast`。
TIME:    51.75 s × 30 fps = 1553 帧；120 BPM，26 小节；所有提示点在 0.25 s 网格上（字幕时间与脚本一致，未移动）。
         打叉 6.5、名词 22.0（小节线）、咔 40.5（拍点）、片尾问号 50.0（小节线）。片尾卡从 48.75 开始。
MOTION:  第 0 帧来电在响（手机振动、头像波纹）、戴毛线手套的手指已经在划；暗场里电极上一直有电流脉冲在走、每条弧线上都有电荷在流；
         每段停留都有缓推或漂移；快动作（划、钻、拉出、手进出）在 BLUR 窗口里做 6 次子采样的运动模糊。

## 空间与相机

一台手机（世界单位 mm，屏幕平面 z = 玻璃顶面，手指和香肠在玻璃上方）。一台正交相机，带一个俯仰角 θ：
`screen = A·(x, piv + (y − piv)·cosθ − z·sinθ) + B`；θ = 0 时就是前几集的相似变换相机 `key()/interp()`（对数螺线插值）。

- 亮场景（θ = 0）：手机正面，来电界面；手从右下方进来（成人比例：食指 80 mm，掌宽 84 mm）。
  毛线手套 = 冷灰蓝羊毛（#5B6B7F，浅色针脚 #8C9BAD，墨线），和光手指分得开；触屏手套 = 同一只手套，指尖是一块银灰导电纱（#BCC3CA）。
  光手指 = 东亚肤色（#EBCBA5，暗部 #D6AD84，指甲 #F3DCCB，墨线），剖面里同一套颜色。
- 一镜到底（8.75–12.75）：推向接触点（接听滑块）→ 手指抬走留下触碰波纹 → 匀速穿过玻璃（11.25–11.5 暗场接上）→ 平视的电极网 → 镜头倾到 θ = 50°，网立起来、交叉点上冒出电场弧线。
- 暗场里同一台相机在三个角度之间转（都是连续镜头）：
  · 网（θ = 50°，11.5–14.75）：横竖两层透明细线、交叉点的光、弧线上流动的白色电荷、沿行电极跑的电流脉冲。
  · **侧切面（θ = 90°）**：沿被摸的那一行切开——上面是盖板玻璃，玻璃下面是列电极（截面）和行电极（一条线），
    每个交叉点两侧四道弧线从行电极绕上来落到列电极，外面两道伸出玻璃；白色小电荷沿弧线一直在走；每个交叉点下面挂一根读数条。
    手指剖面（皮肤、肉、末节/中节指骨、指甲）从上面压在玻璃上。
  · 俯视（θ = 0）：整张网，每格的光 = 读数；扫描线一行一行扫；手指画成半透明的俯视轮廓，盖在被摸的那一格上。
- 拉出（29.25–30.5）：从俯视拉回亮场景：手机平放、黑屏（θ = 45°）。香肠一段在倾斜视角里，旁边一个放大镜圆窗（同一个侧切面）；
  触屏手套一段先回到正面，再第二次钻进去（俯视 → 侧切面），最后从侧切面直接转回正面的来电。

## LOOK

浅灰 #ECEBE6 + 墨 #141414 + 唯一强调色信号橙 #FF4A1C；误区一拍橙色铺底（全片唯一一次）；暗场 #17191C、浅色字 #F1F0EC。
白色小点 = 电荷（沿弧线从行电极走到列电极）；橙 = 被引走的电荷 / 掉下去的读数 / 锁定 / 答案；毛线手套 = 灰蓝 #5B6B7F；导电纱 = 银灰；皮肤 = #EBCBA5。
得意黑字幕（x 96，基线 330/472，112 px，名词句 96/140 px 砸入）；Noto 标注 ≥ 44 px（香肠标注 54 px，细引线）；无角标、无边框。

## SOUND（music/score.mjs，全部代码合成）

- D 大调，120 BPM 直拍十六分。铃声本身就是钩子动机 mi-sol-la-sol-mi-sol；接通（咔）时解决成 mi-sol-DO。振动马达调在 D3（146.8 Hz）。
- 和声：开场 IV–V（G–A），误区落到 vi（Bm，假终止）；讲解一路走五度圈 vi–ii–V–iii–IV–V（Bm–Em–A–F#m–G–A），名词那一下才第一次落到 I（D）。
  （EP.01/03：C 大调 IV–V–iii–vi；EP.02：G 大调 vi–IV–I–V；EP.04 v1：A 大调 IV–I–V–vi。）
- 三种织体：开场 = 铃声 + 轻踩镲 + 持续低音；讲解 = 八分脉冲和弦 + 八分低音型（根-根-五-八）+ 十六分"电流"闪音（手套段整体低通、去掉闪音）；
  揭晓 = 四踩、反拍开镲、八度低音、反拍和弦 + 主旋律。揭晓前（21.75、40.25）停半拍。
- 打叉前 0.5 s 真静音；最响三下：打叉 −1.3、名词 −1.1、咔 −1.0 dBFS（混音前峰值），其余 ≤ −2 dBFS。
- 每个问题同一个上行四度（A5→D6）。所有打点在 beats.json 的十六分网格上。母带 `tools/master.sh` → −14 LUFS。
