# EP.06 人脸解锁 · 事实与来源（v1，2026-11-11）

| # | 说法 | 依据 | 来源 | 状态 |
|---|---|---|---|---|
| F1 | 面容 ID 往脸上打成千上万个看不见的点，做出脸的深度图；另外拍一张红外图像 | 「原深感摄像头会通过投射并分析成千上万个不可见的点来捕获准确的面部数据，进而创建你面部的深度图；另外它还会捕获你面部的红外图像」 | Apple 支持「关于面容 ID 先进技术」support.apple.com/zh-cn/102381（2026 年 9 月版） | 已查（官方）。旧版资料写「超过 30,000 个点」，现行官方页只写「成千上万个」，片中不写数字 |
| F2 | 屏幕顶部的元件：点阵投影器、红外镜头、泛光感应元件 | 原深感摄像头系统的组成 | Apple 产品页 / 技术规格（中文名待逐个对照） | **待核中文名** |
| F3 | 红外镜头从旁边看，光点会挪位置；离得越近，挪得越多；拼起来得到深度 | 结构光三角测量：投影器和相机之间有基线，物点深度改变时，光点在相机像面上的位置沿基线方向移动，移动量与深度的倒数成正比 | 结构光测深的通用原理（教科书 / 综述，待补一篇）；苹果未公开具体算法 | 原理；**说明面容 ID 用的是这一类方法**，具体实现不公开。脚本只说「挪得越多」，不说方向 |
| F4 | 它会适应你的外观变化，比如化妆 | 「面容 ID 会自动适应你的外观变化，如化妆或长出面部毛发」 | Apple 支持 102381 | 已查（官方） |
| F5 | 化妆改的是颜色，脸的高低没变 | 化妆品是很薄的一层，改变的是可见光下的颜色和明暗，不改变面部几何形状 | 常识推理 + F1、F4 | 推理。不说「红外下看不见妆」（没有来源） |
| F6 | 修容让鼻梁看着更挺，但深度不变 | 修容用深浅颜色制造阴影错觉；深度图测的是几何距离 | 推理（同 F5） | 推理 |
| F7 | 戴口罩时，只看眼睛周围 | 「戴口罩使用面容 ID」功能可分析你眼睛周围的独有特征；需 iPhone 12 及更新机型、iOS 15.4 或更高；要在「设置 › 面容 ID 与密码」里打开；眼睛不能被遮挡，戴太阳镜时不能用 | Apple 支持 support.apple.com/zh-cn/102452 | 已查（官方） |
| F8 | 眼睛周围的特征也是独有的 | 同 F7「独有特征」 | 同 F7 | 官方说法；戴口罩时误识概率比全脸更高一些（102381） |
| F9 | 小提示：没认出时马上输密码，它会记下这个样子 | 面容 ID 匹配失败、但匹配质量高于某一阈值，并且用户紧接着输入密码时，会再采集一次并补充已登记的数据 | Apple Platform Security（apple-platform-security-guide.pdf，Face ID 一节）；Face ID Security Guide | 已查（官方）。片中加小字「样子和你很接近时才会记」 |
| F10 | 2D 人脸解锁和 3D 不同 | 只用前置摄像头的 2D 识别没有深度信息；面容 ID「始终需要深度信息，平面打印件或 2D 数字照片并不包含这些信息」 | Apple 支持 102381 | 只进文案；不点名任何安卓品牌，也不讲怎么骗过（H5） |

## 简化 / 示意（片中要加注）
