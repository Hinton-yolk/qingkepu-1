## 白话版

化了妆，拿起手机看一眼，锁开了；戴着口罩，看一眼，也开了。样子都变了，它怎么还认得你？

因为它不只在「看」你，还在「量」你。（下面以 iPhone 的面容 ID 为例。）

屏幕顶上藏着一个小小的投影器，往你脸上打出成千上万个光点，用的是红外光，人眼看不见。旁边还有一个红外镜头，从旁边、斜着一点去看这些光点。同一个光点，落在近处和落在远处，在镜头里的位置不一样：离得越近，挪得越多。每个点都这么算一遍，就得到你脸的高低起伏，叫「深度图」。另外它还会拍一张红外照片。深度图加红外照片，一起拿去和你存的样子比。

化妆主要改的是颜色。口红、粉底都只是薄薄一层，比它能分辨的高低薄得多，所以深度图几乎不变。修容能让鼻梁「看着」更高，那是颜色深浅造成的错觉；深度图量的是真实的距离，鼻梁的高度没变。妆会让那张红外照片有些变化，所以妆很浓时它偶尔会认不出，它也会慢慢适应你的新样子。

戴上口罩，下半张脸量到的只是口罩，那就只看眼睛周围：眼睛周围的特征也是每个人独有的。这个要在设置里打开「戴口罩使用面容 ID」，眼睛不能被挡住；安全性比看全脸低一些，官方说也可以不开。

所以妆会变，口罩会挡，但你脸的形状一直在。

小提示：浓妆没认出来时，马上输一次密码；如果它判断和你本人很接近，就会把这次的样子临时补进去，下次更容易认出。

## 拆题四问
1. **为什么（化了妆还认得你）？** 它主要量的是脸的高低起伏（再加一张红外照片），化妆主要改颜色，深度几乎不变。
2. **不（不只在看照片），意味着什么？** 它要「量」：往脸上打光点，从旁边斜着看同一个光点挪了多少，算出深度。
3. **如果用颜色去「改形状」（修容），会怎样？** 眼睛看着变了，深度图量的高度不变。**必须演示**：修容前后，深度图上鼻梁那条轮廓线完全重合。
4. **是了，又意味着什么？** 口罩挡住下半张，它就只用眼睛周围的特征，所以还能认。

- 原来是这样：人脸解锁不只在看，还在量。
- 原来还可以这样：修容改得了眼睛看到的高低，改不了它量到的高低。
- 结尾回扣标题：「妆会变，口罩会挡，/ 但你脸的[形状]还在」。

## 画面怎么做（内容定了再细化）
- **开头的人**：只画侧脸下半部分特写（嘴唇、口红、下巴）和拿手机的手，黄种人肤色；不画整张正脸，避免「假」（D7）。
- **钻进去之后**：主角就是「脸的高低起伏」，用灰阶立体脸面（深度图），不画真人脸。立体脸取自开源 3D 头模（选定后在 FACTS 记来源和许可证，要允许商用），性别、脸型和开头那个人一致；仍在 Canvas2D 里画、用 render.mjs，不换管线（D8）。
- **光点**：稀疏、淡灰白、标「示意」（E2）；不用信号橙，橙色只给关键词。
- 对比一次只亮一边（B11）。

## v1 → v2 改了什么（审核第一轮、监督第一轮）
- **化妆前后不再打架**：面容 ID 用「深度图 + 红外照片」两样比对。改成「妆主要改颜色，高低几乎没变」，画面上深度图不动、红外照片淡淡变一点；这就解释了为什么浓妆偶尔认不出、为什么小提示有用。删掉「它会一点点适应」那一拍（和小提示重复）。
