# EP.06 人脸解锁 · 观众反馈（Codex 扮演，2026-11-11）

看的是：逐秒抽帧（3 张拼图）、字幕时间表、两张封面、publish.md。听不到声音。是否采纳由用户决定。

**1. 第一印象**

**题目让我想停一下，但中间比我预期的费脑。**“化妆变了样，手机怎么还认识”跟我有关；看到后面的线条图，我会从“看看冷知识”变成“还得认真学一下”。

以下只根据抽帧、字幕时间表和发布文案判断。音乐好不好、动画实际是否流畅，我听不到也看不全。

**2. 会不会停下来、什么时候想划走**

- **封面：小红书版更想点。**脸、手机和问题更集中，扫一眼就知道讲什么。抖音版上方留白比较多，第一眼没那么紧凑。两张都有一点别扭：标题提了口罩，人物却没戴；脸上引出的放大圆图，我能猜是扫描结果，但不太知道里面那些曲线是什么。
- **2 秒：会留下。**涂口红、举手机、锁打开，问题和画面对得上。虽然“化妆还能解锁”不算特别惊讶，但我确实没想过为什么。
- **5 秒：继续看。**“它不只在看你，还在量你”是让我有兴趣的第一句。我想知道它怎么量。
- **15 秒：开始犹豫。**我已经知道它在量脸的高低，但又被问“怎么看出高低”，还没等到化妆和口罩的解释。此时会想：到底什么时候讲回我关心的事？
- **最可能在 17–20 秒划走。**“同一个点会挪位置”里的点，我没跟住；图上有脸、斜线、镜头、参考面、小横条，我不知道先看哪一个。不太会倒回去研究，更可能直接划走。
- 如果撑到 **27 秒**，化妆和修容会重新抓住我。**43 秒以后**我觉得问题已经答完了；小提示可能留住我，片尾卡我会划走。

**3. 看懂了什么，哪里别扭或有疑问**

一句话复述：**按片中的 iPhone 例子，手机会用光点量脸的高低，再跟存下来的特征比较；化妆没有明显改变高低，戴口罩则改看眼周。**

具体卡点：

- **3–7 秒：适用范围容易漏看。**“以 iPhone 面容 ID 为例”是小字。我如果用安卓，可能把整条理解成“我的手机也是这么工作的”。小红书正文解释了差别，但刷视频时我未必展开。
- **8–10 秒：为什么我从没看见这些光点？**画面让我知道有光点，但“红外、人眼看不见”在发布文案里才说清。只看片时我会冒出这个问题。
- **16–20 秒：“挪位置”是相对什么挪？**我能读懂结论，但没有从图里看明白。“离得越近”也让我迟疑：是整张脸靠近手机，还是鼻尖比脸颊更近？
- **24 秒：深度图、红外照片、“存着的你”出现得有点挤。**能猜到在比对，但刚看完复杂图，还要马上分辨两个小窗口，有些跟不上。
- **29–34 秒：修容这段最好懂。**“看着更高”和“实际高度没变”直接对应我的经验。不过它跟前一句“妆主要改颜色”有些重复。
- **36–42 秒：口罩部分更像告诉我答案。**眼周圈出来了，但“也是你独有的”让我继续想问：具体认的是眼形，还是眼睛周围的高低？旁边小图太暗，我看不出差别。设置提示也容易漏掉，我会问为什么自己的手机戴口罩还是打不开。
- **46–49 秒：小提示有用，但主字幕显得很肯定。**我第一眼会记成“浓妆认不出，输一次密码就能学会”；下面的限制小字不容易读进去。

**4. 会不会点赞 / 收藏 / 转发 / 评论**

**可能点赞，不太会收藏，转发意愿一般。**知道原理后有一点“原来如此”，但不是需要反复查的东西。末尾小提示比原理更可能让我收藏；如果朋友经常抱怨化妆后解锁失败，我会想到转给她。

我真的可能发的评论：

- “所以修容骗得过我的眼睛，骗不过手机😂”
- “我戴口罩还是打不开，是要另外开设置吗？”
- “安卓也这样吗？我这个没刘海也能人脸解锁。”

**5. 最多 5 条修改建议，按重要性排序**

1. **16–20 秒：只让我追一个点。**把这个点和它在镜头里对应的位置突出，其余线条变淡；先演示一个位置，再换一个位置。把“离得越近”说成“鼻尖离手机更近”之类的具体对象。我现在最大的障碍是找不到该追谁。
2. **10–25 秒：减少连续追问，早点回到化妆。**“打点为了什么→量高低→怎么看高低→拼起来是什么”绕得偏久。可以把“每个点挪多少，拼起来是什么？”直接换成答案，让我更早得到标题的回应。
3. **36–42 秒：让口罩设置条件更显眼。**别只在角落放“需在设置里打开”，至少在出现口罩时明确提示一次。眼周图也放大、提亮一点，否则我只记得“看眼睛就行”。
4. **3–10 秒：把两句容易漏掉的信息放进阅读主线。**明确这是 iPhone 面容 ID 的例子；光点出现时补“红外光，肉眼看不见”。这能马上解答“我手机也这样吗”和“我怎么没见过”的疑问。
5. **46–49 秒：把小提示的条件并进大字。**例如分两拍表达“浓妆没认出？马上输密码”“样子足够接近时，下次可能更容易认出”。现在最抢眼的承诺比限制条件强，容易只记住一半。

## v3（2026-11-11）

**1. 哪里变好了，哪里还卡**

- **15–25 秒俯视图：明显改善，但还没到一眼就懂。**17–18 秒鼻尖上的橙圈、下面橙色的位移标记，让我有东西可追了。19–20 秒直接说“鼻尖离手机更近”，再拿鼻尖、脸颊、脸侧比较，比上一版泛泛说“离得越近”清楚。不过我还是要停一下想：**下面那个点，跟脸上圈住的点到底怎么对应？**我能读懂“鼻尖挪得更多”，但斜线交叉的过程还没完全看明白。21–23 秒直接给“拼起来就是高低起伏”，比继续问问题省劲；24 秒两个小窗口出现后，我主要顾着读字，细节没看进去。
- **34–43 秒口罩段：现在能注意到要开设置了。**35 秒人物下面的橙框，比上一版容易看见；37–38 秒眼周和旁边图一起框出来，也知道它关注哪一块了。但41–42 秒“眼周的特征也是你独有的”，对我来说还是一个结论：**具体认的是眼形，还是眼周的高低？我从图里分不清。**这里真会想评论：“要开哪个设置？”
- **46–50 秒小提示：比上一版不容易误会。**“和你够接近时”进了大字，我不会只记住“输密码就一定学会”。但这句话读着有点别扭：**谁和我够接近？**结合上下文能猜是这次的样子跟原先存的样子接近。这个提示有用，我会愿意多留这几秒。
- **8–10 秒**补了“红外光，肉眼看不见”，我之前“怎么从没见过这些点”的疑问解掉了。**27–34 秒**仍然最好懂，修容看着变高、实际没变，跟我的经验直接对上。

**2. 我会不会停、什么时候想划走**

- **2 秒：会停。**涂口红、举手机、解锁，马上知道跟自己有关。
- **5 秒：继续。**“还在量你”让我想知道它量什么。
- **15 秒：有一点不耐烦，但会再给几秒。**已经听明白在量高低，还没回到化妆。
- **最可能离开：18–20 秒。**如果没跟住点和线，我不会倒回去研究。新版比上一版更有机会让我撑过去，但这仍是门槛。
- 撑到25秒，化妆、修容、口罩能把我留下来。**50秒片尾卡出现就划走**，我要的答案已经有了。

**3. 我看懂的主线**

以片里的 iPhone 为例，手机用光点量脸的高低，再跟存下来的特征比；化妆主要改颜色，戴口罩时则靠眼周认人。

**4. 最多三条建议，按重要性**

1. **17–20 秒再明确一次“脸上这个点→镜头里这个位置”。**现在知道盯橙圈，但两个位置的对应还得自己想；其他斜线可以再淡一点。
2. **35–42 秒把“眼周特征”说具体一点，设置提示写出设置名称。**我已经看见“要打开”，接下来想知道“打开什么”；眼周小图也还不足以让我看出它认什么。
3. **48–50 秒把“和你够接近时”换成对象明确的话。**比如“这次的样子和存下的够接近，下次更容易认出”，让我不用猜谁跟谁比。

## v4（2026-11-11）

**这版比 v3 更能跟上：口罩和小提示基本讲明白了，17–20 秒的点线图还是最费脑的地方。**

1. 新版哪里变好了，哪里还卡

- **15–18 秒：脸上的点和镜头里的位置，现在能对上了。**鼻尖橙圈、橙色虚线、下面“镜头里”的橙圈，让我能顺着找过去，不再只是看到两个各自亮着的点。但我还是要主动沿线看一遍，才明白它们在说同一个点。
- **19–20 秒：懂了结论，过程还有点绕。**“鼻尖离手机更近，挪得就更多”配下面长短不同的横条，我能理解鼻尖、脸颊、脸侧挪得不一样。不过切到脸颊、脸侧后，几条斜线又挤在一起，我会丢掉自己刚才追的那条。**对应哪个位置能找出来，但具体从哪里挪到哪里，还没一眼看懂。**抽帧也看不出连续移动时会不会更清楚。
- **21–25 秒：能接上了。**“拼起来→高低起伏”让我知道前面折腾那些点是为了什么。24 秒两个小窗口，我主要读到了“深度图／红外照片”，里面的细节没看进去。
- **34–43 秒：上一轮的疑问基本解掉。**35 秒能看到具体要开“戴口罩使用面容 ID”；37–42 秒上面的图标“高低”、下面标“样子”，再配“眼周的高低和样子”，我终于知道不是只认眼形。小图里究竟有哪些细节不同，我仍然看不出来，但不妨碍理解这段。**39–41 秒又问一次“够认出你吗”，我有点想催它直接给答案。**
- **46–50 秒：比 v3 顺口，也知道谁跟谁比了。**我会理解成“这次的样子，跟之前存下的样子够接近”。只是画面紧接着就开锁，容易让我记成“输一次密码，下次就好了”，那个“够接近”的条件没有开锁动作那么抢眼。

2. 会不会停，什么时候想划走

- **2 秒：会停。**化妆、举手机、解锁，跟我的生活直接有关。
- **5 秒：继续看。**“还在量你”让我想知道量的是什么。
- **15 秒：开始有点急，但愿意再看几秒。**已经知道量高低了，想早点听到化妆为什么没关系。
- **最可能离开仍是19–20秒。**如果忙着读字幕没跟住线，我不会倒回去研究。这版比 v3 容易撑过去。
- 撑到25秒，修容和口罩会把我留下来；小提示我也愿意看，**50秒之后进片尾卡就划走。**

3. 一句话复述主线

**片里的 iPhone 会量脸的高低、结合样子跟存下来的特征比，化妆没怎么改高低，戴口罩时则靠露出的眼周认人。**

4. 还剩的修改建议，按重要性

1. **17–20 秒把“从哪挪到哪”再突出一点。**我已经能找到脸上和镜头里的对应点了，接下来最需要的是看清下面那个位置的变化；切到脸颊、脸侧时，其余线再淡一点。
2. **48–50 秒别让开锁画面盖过条件。**让“够接近”先被读完，再出现开锁结果，免得我只记住输密码就能解决。
3. **39–43 秒可以更直接。**“只看眼睛周围，够认出你吗？”这句略拖，直接接“眼周的高低和样子……”我会更愿意往下看。
