# 手机天天充电，会把电池充坏吗？ · 内容关卡 1

状态：**白话版 v1 + 拆题四问 + 逐句脚本 v1 + 开头备选，等用户确认**（2026-11-16）。用户确认后才进节点 ①（审核 + 监督）。
选题：用户 11-16「手机到底能不能频繁多次充电，对电池寿命的影响」；并入选题库「为什么充到 80% 就变慢了」做第 5 段。

## 白话版（v1）

手机一天要插好几次线，晚上还插着充一整夜。这样天天充，会把电池充坏吗？

你是不是以为，充一次，电池就少一次命？其实电池**不数你插了几次**。

电池里有一群会搬家的锂。充电，就是把它们从这一边搬到那一边；用电，它们再搬回来。整整搬完一趟，才算一次。充两次半格呢？加起来，还是一次。

那电池到底是怎么老的？锂塞得太满的时候，有一些会被**粘**在表面，再也搬不动了。能搬的锂少了，电池就不耐用了。

什么时候粘得最快？**又满又热**的时候。

那夜里插着充一整晚呢？不少手机会先停在 80%，等你快起床，才充满。

所以，想充就充，别让它又满又热。
小提示：边充边打游戏、闷在被子里充，最容易发烫。

## 拆题四问
1. **为什么不（会充坏）？** 电池的寿命按「累计搬了多少」算，不按「插了几次」算：两次半格 = 一次。
2. **不，意味着什么？** 想充就充，零碎地充不吃亏（甚至浅充浅放更温和，FACTS #2）。「用光再充」是老电池的说法（不进片）。
3. **如果真让它老，会怎样？（必须演示）** 锂塞满负极时，一部分在表面和电解液反应，变成一层膜，锂被困住；越满、越热，困得越快。**演示**：同一群锂来回搬，每一趟都有几粒变灰、留在膜里，下一趟能搬的变少，电池外框缩小。
4. **是了，又意味着什么？** 怕的是「一直满、一直热」，所以手机夜里先停在 80%，快起床再充满；我们自己要做的，是别让它充电时发烫。

- 原来是这样：电池不数插了几次，数的是搬了多少；老化是锂被粘住了。
- 原来还可以这样：手机夜里自己停在 80%，就是为了「少满一会儿」。
- 结尾回扣标题：开头问「会充坏吗」，结尾「想充就充，别让它[又满又热]」。

## 错误猜测 + 打叉
建议**用**：「你是不是以为，/ 充一次，就[少一次]命？」——观众真会这么想（「电池有充电次数」这话到处都是），而且只对一半：电池确实有寿命，但数的不是次数。翻转句：「它不数你[插了几次]」。

### 六段式对照
1. 现象：0–2.75（插线充电）
2. 错误猜测：2.75–7.25（充一次少一次 ✕ → 它不数插了几次）
3. 钻进去：7.25–10.5（手机 → 电池 → 极片之间）
4. 一个机制：10.5–24.25（锂来回搬；搬满一趟才算一次；两次半格 = 一次）
5. 原来还差这一步：24.25–45.0（锂被粘住 → 电池变老；又满又热最快 → 夜里先停 80%）
6. 回到开头：45.0–52.25（同一个插线动作 → 闭环句 → 小提示）
