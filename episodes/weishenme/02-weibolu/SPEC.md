# SPEC — EP.03 微波炉 v2（v1 + 反馈：一镜到底钻进米饭、"被水吃掉"重做、转盘的问答改词、闭环重做、配乐 C）

GOAL:    看完的人能复述：微波炉不是从里往外热；微波让饭里的水分子跟着来回扭、挤来撞去就热了；微波一路被水吃掉，
         只钻得进外面两三厘米，所以外面烫、中间凉；转盘让每块饭轮流经过热点。
OUTPUT:  单文件 canvas 页面，`window.seek(t)` 画第 t 秒；1080 × 1920，30 fps；`node render.mjs` 出帧，H.264 yuv420p CRF 16，AAC `-aac_coder fast`。
TIME:    59.75 s × 30 fps = 1793 帧；120 BPM，30 小节；叮 2.0、打叉 8.0、名词 36.0、还差一步 38.0、叮 50.0 都在小节线上。
MOTION:  每一秒都在动：第 0 帧转盘就在转、炉灯亮着；水分子一直在扭（机制段的主画面）；停留段都有缓推或漂移。

空间：厨房里一台微波炉的正面（略俯视，能看见炉膛底和转盘），门玻璃里一碗剩饭，碗画成剖面（看得见饭里面哪儿热）。
      一台相机：整台微波炉 → 碗 → 退回炉膛 → 侧壁小方片 → 控制面板后面的管子 → 跟着微波进炉膛，一镜到底：碗 → 饭 → 一粒米 → 米里面（暗场：水分子）
      → 拉回炉膛（热点、转盘）→ 拉回整台微波炉 → 片尾徽标。
