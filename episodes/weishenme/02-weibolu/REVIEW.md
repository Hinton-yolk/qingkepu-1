# REVIEW — EP.03 微波炉 v1

按白话版 v1（用户确认：剩饭开场，揭晓"水"，还差一步用转盘）做。时长 59.75 s。

## 自检循环（CLAUDE.md）

| 项 | R1 | R2（终版） |
|---|---|---|
| 前 2 秒钩子 | 7（炉子偏小） | 8：第 0 帧问题 + 转盘在转、嗡嗡响，2.0 叮，2.5 剖面看到外圈橙、中间灰 |
| 手机尺寸可读性 | 7（水分子特写太小、＋/－看不清；"管子"认不出） | 8：特写放大到 4 倍、＋/－清楚；管子在说到"微波"时描橙框 |
| 运动质量 | 7（从暗场出来时几帧糊；热点段的反射波像乱线） | 8：出暗场镜头先快后慢、亮场景晚 0.15 s 出现；反射波减到两条、更平滑 |
| 变化 | 8 | 8 |
| 品牌 | 8 | 8 |
| 声画同步 | 8 | 8：所有命中点最大误差 0.23 帧 |

修过的问题：碗在 2 s 之后被错误地停在侧边（转盘角度函数）→ 停在正前方；"扭得飞快，挤来撞去"首帧砸字溢出屏幕 → 改为渐显；
炉子开场放大 12%；控制面板后的镜头右移，管子不再被裁；门玻璃网点在"看进炉膛"时提前淡出。

## 成片实测

`out/ep03-microwave.mp4`：1080×1920，30 fps，1793 帧，59.75 s，H.264 yuv420p CRF 16 + AAC 256k（`-aac_coder fast`），18.4 MB；
−14.4 LUFS，真峰 −2.5 dBTP，无 AAC 尖峰（可听窗口最大偏差 1.1 dB）；节拍网格 119.997 BPM，所有命中点最大误差 0.23 帧；
无黑帧；单独渲染的帧与整片逐字节一致。

运动（tools/motion.py）：中位 2.72 / 秒（EP.02 3.11、EP.01 6.79），平均 4.59；除片尾徽标外每一秒都在动。
偏低的是几处特写停留：碗的剖面（开场之后、误区、最后一句和小提示）、单个水分子特写（21–25 s）——这些地方动的是蒸汽、分子漂移和缓推，面积小。

# REVIEW — EP.03 v2（看片反馈）

| 反馈 | v2 的处理 |
|---|---|
| 配乐换换，别审美疲劳 | A（lo-fi 电钢琴半速）、B（马林巴 shuffle）被否："不好听，不协调"。C 回到系列原来的音色和直拍，只换曲子：G 大调（"叮"= DO）、vi–IV–I–V、新旋律、反拍开镲 + 反拍贝斯 + 十六分琶音。用户确认"这个声音可以" |
| 19 s 钻进米饭要一镜到底 | 镜头从炉子（Z 1.5）匀速推到一粒米（Z 300，约 200 倍），米粒里出现水点，暗场在最后 0.35 s 接上，暗场里继续以同样的速度推到一个水分子的特写；中间不切、不回头 |
| "为什么被水吃掉"看不懂；"两三厘米"被挡 | 重做：水分子排成 8 列，波从表面进来，每经过一列被咬掉一截（虚线包络一级一级往下），那一列扭起来、变橙，一列比一列淡，第四列之后就没了；每咬一口一个音，一口比一口轻。字幕「微波每碰到水分子，就被[吃掉]一点」。"两三厘米""中间"移到上方 y 784 |
| 39 s 改词 | 「为什么需要转盘[转动]呢？」→「因为微波来回反弹 / 不均匀， / 会叠出一块块[热点]」（三行，96 px） |
| "再按一次 / 我在扭 / 还没轮到我"很尬 | 去掉对话。「再热一次，看看微波去了[哪儿]」→ 按下开始，剖面里一道道微波从表面（也穿过碗）钻进饭里，走一小段就消失；虚线标出到得了的地方，外圈变橙，中间一直灰 → 叮 →「所以中间凉：微波只热得到[外面]的水」；小提示时虚线随着热往里缩 |

成片实测（`out/ep03-microwave.mp4`，1080×1920，30 fps，1793 帧，59.75 s，19.7 MB）：−14.3 LUFS，真峰 −2.4 dBTP，无可听的 AAC 尖峰（最大 1.6 dB，开镲）；
节拍网格 120.007 BPM，所有命中点最大误差 0.30 帧；无黑帧；单独渲染的帧与整片逐字节一致。运动：中位 3.10 / 秒（v1 2.72），一镜到底那几秒 10.9 / 9.5 / 23.3。
