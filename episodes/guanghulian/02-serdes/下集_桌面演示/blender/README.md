# 02 下集 · 桌面演示版 · 演示装置场景和 y6 试镜头（2026-11-11）

分镜：`../文字分镜_v3.md`。质感、灯、镜头、后期沿用 `../../../blender_desk_look/`（同一间房、同一扇窗、同一张桌子）。

## 文件
- `make_textures.py`：翻面纸签（读带口 / 收货的芯片）、计数轮数字、节拍器刻度牌。
- `rig.py`：整套装置 + y6 的关键帧动画 + 渲染。用法见文件头。
- `comp.py`：合成。后期（高光晕、暗角、颗粒，参数同 `post.py`，颗粒逐帧换）+ 字幕 + 两张小签 + 占位声音 → mp4。
- `runpod_y6.json`：GPU 终版的任务表（`tools/runpod_render.py`）。

## 装置（都按真实尺寸，单位米）
| 东西 | 怎么来的 | 尺寸 / 做法 |
|---|---|---|
| 节拍器 | **代码建**。找过 CC0 模型：Poly Haven 的 521 个模型里没有；Sketchfab、Blend Swap 要登录才能下载；Poly Pizza 拦自动访问 | 木壳机械节拍器的样子：底 110 mm 见方、高 215 mm，摆杆在正面，黄铜游码，刻度牌 40–208 |
| 盖点臂 | 自创，代码建 | 和摆杆同轴、固定在一起的一根曲臂。摆到右头时臂端的小印章正好落在窄缝正前方的白边上；摆到左头时抬起约 6 cm |
| 透明尺 | **代码建**（CC0 没找到） | 亚克力，204 × 32 × 2.5 mm，一格（24 mm）一道刻度。y6 里已被拿走，放在桌子前沿 |
| 纸带 | 自创，代码建 | 宽 42 mm：远侧 3 mm 白边、26 mm 数据道、近侧 13 mm 白边。一格 24 mm。走在一条黑色导轨上 |
| 读带口 | 自创，代码建 | 从远侧伸出来的黄铜板，中间一道 5 mm 的窄缝；近侧白边露在外面，蓝点盖在那里 |
| 小灯 | 自创 | 缝边一只琥珀色小灯，黑白交界过窄缝时亮 |
| 计数器 | 自创 | 一只数字轮（0–9）。**分镜写的是翻牌计数器，这里先用了数字轮**（真的能转，做起来稳）；要翻牌再改 |
| 纸签 | 自创 | 立在计数器上的小牌，绕横轴翻面 |
| 印带器、托盘和八张小卡、第二只节拍器 | 自创，代码建，**只是占位的样子** | y6 不入画，全景里看得到；轮到 y2、y3 时再细做 |
| 木纹、墙面 | Poly Haven CC0 贴图 | `wood_table_001`（桌面 4k）、`plywood`、`american_walnut_veneer`（2k）、`painted_plaster_wall`（2k） |

## y6 的时间表（24 帧 / 秒，216 帧 = 9 秒）
- 一格 = 20 帧（0.83 秒）；纸带每秒走 28.8 mm。
- 黑白交界过窄缝（小灯亮、鼓）：第 0、20、40、60、80（进长黑带）、180（出长黑带）帧。
- 盖点（啪）：每格正中。第 10、30、50、70 帧（黑白相间的四格）；第 90、110、130、150、170 帧（长黑带，五个）；第 190、210 帧（白格）。
- 摆到左头（轻嗒）：每 20 帧一次，长黑带中间四下（100、120、140、160），第 180 帧那一下和出黑带的鼓合上。
- 计数轮：新一段黑带进来时清零，每盖一个点加一，白格不动；长黑带数到 5 以后停住。
- 纸签第 10–22 帧翻面。相机第 52–178 帧从读带口中景慢推到窄缝近景，一个镜头不切。

## 主 agent 自己定的几处（分镜里没写死，等用户看）
1. **每一格都盖点，白格也盖**：收货端每个节拍都清点一次，不知道这一格是黑是白。长黑带下面正好五个。
2. **计数轮在新一段黑带进来时清零**（示意），所以最后停在 5。
3. **纸签翻面后不淡掉**：实物不会淡出，翻过来就一直是「收货的芯片」。
4. **百叶拉起一半、太阳从左前方进来**（定妆静帧是从左后方）：装置正面朝相机，从左后方照正面全在阴影里；百叶的影子落在背后的墙上，纸带上没有条纹。
5. 字幕时间是估的（这台机器上没有配音文件）；声音是代码合成的占位音，只用来对动作。

## 重新出图
```bash
# 素材（不进仓库）：Blender 5.2.3、Poly Haven 贴图、Noto 字体，地址见 ../../../blender_desk_look/README.md；另加
#   https://dl.polyhaven.org/file/ph-assets/Textures/jpg/2k/plywood/plywood_{diff,rough,nor_gl}_2k.jpg
#   https://dl.polyhaven.org/file/ph-assets/Textures/jpg/2k/american_walnut_veneer/american_walnut_veneer_{diff,rough,nor_gl}_2k.jpg
python3 make_textures.py <素材目录> <tex目录>
blender -b -P rig.py -- <tex> <素材> out/t.png 25 32 still=170          # 270×480 看构图，约 10 秒
blender -b -P rig.py -- <tex> <素材> out/E.png 25 32 cam=E still=90      # 整套装置的横屏全景
blender -b -P rig.py -- <tex> <素材> out/draft 50 24 thr=0.08 fs=0 fe=215   # 540×960 草稿
blender -b -P rig.py -- <tex> <素材> out/anchors.json 50 24 anchors=1    # 合成用的屏幕锚点
python3 comp.py out/draft out/anchors.json <素材目录> out/y6_draft.mp4
```
Blender 5.2 的坑：后台模式下「新关键帧插值」的偏好设置不生效，匀速 / 阶跃的关键帧要在 F 曲线上显式设（`rig.py` 的 `set_interp`），否则纸带会缓入缓出、蓝点会提前慢慢长出来。
