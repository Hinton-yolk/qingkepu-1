- `overlay.py`：合成的小部件（后期、小纸签、字幕条、五站条、系列名）。`sheet.py`：拼接触表。
- 镜头和所在的拍：y1｜y2｜y3d、s34a（y3）｜s34b、y4d、s34c（y4）｜y5｜y6g、y6c（y6）｜y7｜y8d、y8c｜y9e、s9a（y9）｜s9b（y10 + y11）｜y12c、y12g、y12a｜y13｜y14。
  s34a / s34b / s34c、s9a / s9b、y6g / y6c 各是同一条时间线上的不同机位，分开渲（切点两侧的运动模糊才不会串）。
- 新加的素材：Poly Haven「retro_multimeter」（CC0，当「总耗电」「每个比特」两只表，指针是单独的零件）。下载：`https://api.polyhaven.com/files/retro_multimeter` 里 gltf / 2k 那一组，放进 `<素材目录>/retro_multimeter/`。手机没有找到 CC0 模型（Poly Haven 没有），按真实尺寸代码建。


## 全片的 GPU 渲染（2026-11-11，RunPod，RTX 4090，每小时 0.89 美元）
- 任务表用 `gen_jobs.py` 生成（每个镜头一个任务），场景包是 `film.py` + `rig.py` + `tex/` + 素材目录里的 jpg、`retro_multimeter/`、`pcb_gpt/`（约 44 MB）。
- **动作草稿**：540×960、48 采样、隔帧渲（`step=2`），984 帧，每帧约 1.6 秒，墙钟 29 分钟，约 0.43 美元。用 `comp_film.py --step 2` 合成。
- **终版第一次**：1080×1920、128 采样、阈值 0.02，实测每帧 9.3 秒（亮场）/ 8.5 秒（暗场 192 采样），是 y6 试镜头（4.0 秒）的两倍多：现在的场景东西多，采样占了绝大部分时间。照这样全片要 4 美元多，渲了 3 分半就停掉删机（约 0.1 美元）。
- **终版**：改成 48 采样（暗场 96）、阈值 0.03。同一帧 64 采样和 128 采样对比，平均差 0.64 / 255，肉眼看不出。
- **终版**：1080×1920、48 采样（暗场 96）、阈值 0.03，1962 帧，两台 4090 分别跑了 97.6 和 102.0 分钟，约 2.96 美元（平均每帧约 6 秒，含启动和传场景包）。合成后动效检查 PASS。封面：`cover.py <终版帧目录> <字体目录> <输出目录>`。
- 教训：估终版的时间要用**同一个场景**的实测，不能拿试镜头的每帧秒数去乘；开渲后先看头十几帧的 `times_*.txt`，不对就马上停。
- 合成：`python3 comp_film.py <帧目录> <锚点目录> <素材目录> <配音轨.wav> <输出.mp4> --audio <成品音轨.wav>`；锚点和声音事件用 `film.py ... shot=<镜头> anchors=1` 逐镜头生成；配乐和音效 `../audio/score.py`。

# y6 试镜头那一版的记录（2026-11-11）

分镜：`../文字分镜_v3.md`。质感、灯、镜头、后期沿用 `../../../blender_desk_look/`（同一间房、同一扇窗、同一张桌子）。

## 文件
- `make_textures.py`：翻面纸签（读带口 / 收货的芯片）、计数轮数字、节拍器刻度牌。
- `rig.py`：整套装置 + y6 的关键帧动画 + 渲染。用法见文件头。
- `comp.py`：合成。后期（高光晕、暗角、颗粒，参数同 `post.py`，颗粒逐帧换）+ 字幕 + 两张小签 + 占位声音 → mp4。
- `runpod_y6.json`：GPU 终版的任务表（`tools/runpod_render.py`）。

## 装置（都按真实尺寸，单位米）
| 东西 | 怎么来的 | 尺寸 / 做法 |
|---|---|---|
| 节拍器 | **代码建**。找过 CC0 模型：Poly Haven 的 521 个模型里没有；Sketchfab、Blend Swap 要登录才能下载；Poly Pizza 拦自动访问 | 木壳机械节拍器的样子：底 110 mm 见方、高 215 mm，摆杆在正面，黄铜游码，刻度牌 40–208 |
| 盖点臂 | 自创，代码建 | 和摆杆同轴、固定在一起的一根曲臂。摆到右头时臂端的小印章正好落在窄缝正前方的白边上；摆到左头时抬起约 6 cm |
| 透明尺 | **代码建**（CC0 没找到） | 亚克力，204 × 32 × 2.5 mm，一格（24 mm）一道刻度。y6 里已被拿走，放在桌子前沿 |
| 纸带 | 自创，代码建 | 宽 42 mm：远侧 3 mm 白边、26 mm 数据道、近侧 13 mm 白边。一格 24 mm。走在一条黑色导轨上 |
| 读带口 | 自创，代码建 | 从远侧伸出来的黄铜板，中间一道 5 mm 的窄缝；近侧白边露在外面，蓝点盖在那里 |
| 小灯 | 自创 | 缝边一只琥珀色小灯，黑白交界过窄缝时亮 |
| 计数器 | 自创 | 一只数字轮（0–9）。**分镜写的是翻牌计数器，这里先用了数字轮**（真的能转，做起来稳）；要翻牌再改 |
| 纸签 | 自创 | 立在计数器上的小牌，绕横轴翻面 |
| 印带器、托盘和八张小卡、第二只节拍器 | 自创，代码建，**只是占位的样子** | y6 不入画，全景里看得到；轮到 y2、y3 时再细做 |
| 木纹、墙面 | Poly Haven CC0 贴图 | `wood_table_001`（桌面 4k）、`plywood`、`american_walnut_veneer`（2k）、`painted_plaster_wall`（2k） |

## 发光信号那一段（`glow=1`，用户 11-11：「加，就按照A来处理」）
- 纸带前面放一块真电路板：Poly Haven「Circuit Board」（CC0，Benny Weimer），缩到 0.6，约 24 cm 见方。下载：`https://api.polyhaven.com/files/circuit_board` 里 gltf / 2k 那一组（gltf + bin + 三张贴图，约 10 MB），放进 `<素材目录>/circuit_board/` 或用 `model=<目录>` 指过去。
- 走线：沿板上电容和芯片之间的空道另画的一条 1.1 mm 宽的发光带，斜下去进方形芯片左侧的引脚；引脚的 x 和窄缝对齐。亮暗图样和纸带同一份、同速。
- 金色 = 电信号。**不画成激光**（这一集是电）。跳变到达时引脚金色闪一下；每个节拍正中芯片上蓝色亮一下。
- 灯：百叶放下来合上（`blind=0.15 slat=-50`），只剩窗缝里的天光，曝光 +2.9。金色的光能照亮旁边的电容，读带口的小灯能照亮黄铜板。后期照旧不加辉光和雾。
- 机位：上半是纸带和读带口，下半是电路板，慢推。只渲前 96 帧（4 秒）。

## y6 的时间表（24 帧 / 秒，216 帧 = 9 秒）
- 一格 = 20 帧（0.83 秒）；纸带每秒走 28.8 mm。
- 黑白交界过窄缝（小灯亮、鼓）：第 0、20、40、60、80（进长黑带）、180（出长黑带）帧。
- 盖点（啪）：每格正中。第 10、30、50、70 帧（黑白相间的四格）；第 90、110、130、150、170 帧（长黑带，五个）；第 190、210 帧（白格）。
- 摆到左头（轻嗒）：每 20 帧一次，长黑带中间四下（100、120、140、160），第 180 帧那一下和出黑带的鼓合上。
- 计数轮：新一段黑带进来时清零，每盖一个点加一，白格不动；长黑带数到 5 以后停住。
- 纸签第 10–22 帧翻面。相机第 52–178 帧从读带口中景慢推到窄缝近景，一个镜头不切。

## 审核留下、定稿前要改的（11-11）
1. 纸签的转轴从卡片正中横穿，字上像划了一道线 → 转轴只留两端短销，或移到下沿。
2. 盖点臂抬起时的影子每个周期扫过计数轮一次，最后的「5」也被扫到 → 计数器右移 / 后移，或臂抬低些。
3. 蓝色采样点（发光段芯片上）过曝偏白 → 压低，保持墨水蓝。
4. 「五个」不好数：白边上一排蓝点都一样 → 等用户定（白格的点画空心 / 给五个点标 1–5 / 出带后的啪压低）。
5. 合成：字幕样式还不是系列的深色撕边条 + 奶油字；五站条和系列名没加；「五个，不是四个」小签和同文字幕叠着。

## 主 agent 自己定的几处（分镜里没写死，等用户看）
1. **每一格都盖点，白格也盖**：收货端每个节拍都清点一次，不知道这一格是黑是白。长黑带下面正好五个。
2. **计数轮在新一段黑带进来时清零**（示意），所以最后停在 5。
3. **纸签翻面后不淡掉**：实物不会淡出，翻过来就一直是「收货的芯片」。
4. **百叶拉起一半、太阳从左前方进来**（定妆静帧是从左后方）：装置正面朝相机，从左后方照正面全在阴影里；百叶的影子落在背后的墙上，纸带上没有条纹。
5. 字幕时间是估的（这台机器上没有配音文件）；声音是代码合成的占位音，只用来对动作。

## 重新出图
```bash
# 素材（不进仓库）：Blender 5.2.3、Poly Haven 贴图、Noto 字体，地址见 ../../../blender_desk_look/README.md；另加
#   https://dl.polyhaven.org/file/ph-assets/Textures/jpg/2k/plywood/plywood_{diff,rough,nor_gl}_2k.jpg
#   https://dl.polyhaven.org/file/ph-assets/Textures/jpg/2k/american_walnut_veneer/american_walnut_veneer_{diff,rough,nor_gl}_2k.jpg
python3 make_textures.py <素材目录> <tex目录>
blender -b -P rig.py -- <tex> <素材> out/t.png 25 32 still=170          # 270×480 看构图，约 10 秒
blender -b -P rig.py -- <tex> <素材> out/E.png 25 32 cam=E still=90      # 整套装置的横屏全景
blender -b -P rig.py -- <tex> <素材> out/draft 50 24 thr=0.08 fs=0 fe=215   # 540×960 草稿
blender -b -P rig.py -- <tex> <素材> out/anchors.json 50 24 anchors=1    # 合成用的屏幕锚点
python3 comp.py out/draft out/anchors.json <素材目录> out/y6_draft.mp4
# 发光信号那一段（4 秒）
blender -b -P rig.py -- <tex> <素材> out/draft_glow 50 32 thr=0.06 glow=1 model=<电路板模型目录> fs=0 fe=95
blender -b -P rig.py -- <tex> <素材> out/anchors_glow.json 50 24 anchors=1 glow=1 model=<电路板模型目录>
python3 comp.py out/draft_glow out/anchors_glow.json <素材目录> out/y6_glow_draft.mp4 --glow
```
Blender 5.2 的坑：后台模式下「新关键帧插值」的偏好设置不生效，匀速 / 阶跃的关键帧要在 F 曲线上显式设（`rig.py` 的 `set_interp`），否则纸带会缓入缓出、蓝点会提前慢慢长出来。
另一个坑：代码里生成的图（`bpy.data.images.new` + 写 `pixels`）要 `pack()`，否则 Cycles 读到的是空图（金色脉冲不亮）。
