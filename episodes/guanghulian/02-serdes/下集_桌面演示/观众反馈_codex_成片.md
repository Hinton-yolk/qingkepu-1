**一句话感受：桌面装置有质感，“芯片靠信号里的鼓点找节拍”让我觉得有意思，但第一次刷到，我很可能在弄明白装置之前先划走。**

我看的是抽帧和字幕，听不到实际配音、音乐和“嗒、啪”的声音，所以声音能不能留住我，这里判断不了。

**1. 前 3 秒：我会犹豫，划走的可能偏高。**

第一眼知道是在讲“芯片怎么认 0 和 1”，手机消息乱码也认得出来。但“少数一个 1”需要反应一下：少了什么？为什么聊天会变成这样？

而且从给出的抽帧看，开头手机里的消息已经是乱码。我没有先看到一句正常的话，再看到它变坏，所以更像“拿乱码举例”，没让我当场感受到“就差一个，整句话居然坏了”。

我可能会多留到 **5 秒**看看这个精致的小装置要干什么；如果那时还没抓住意思，就会走。

**2. 哪些地方看懂了，哪些地方容易掉线**

| 时间 | 我的真实反应 |
|---|---|
| **3–6 秒** | 知道是在讲芯片之间传数据，但还不知道纸带、摆锤、读带口分别负责什么，先跟着看。 |
| **7–11 秒** | “四个还是五个”是个能让我好奇的问题。但我看到纸带上有格子，会想：不是能直接数格子吗？需要靠字幕提醒自己，实际信号是一段平的东西。 |
| **12–16 秒** | 第一次明确看懂：**原来得知道每一份持续多久，才能数出有几个。** |
| **19–27 秒** | 全片最好懂的一段。跟歌拍手→听鼓点→信号跳一下，就是鼓点，这个连接我能跟上。芯片上出现发光信号，也让我重新集中注意力。 |
| **29–35 秒** | 能理解“找到节拍以后，五个就不会数成四个”。但数字轮在变，我不一定能同时追清每一个蓝点，更多是接受了最后的答案。 |
| **35–40 秒** | “一直是 1 就没鼓点，拍子会跑偏”我懂了。不过只看这些帧，我没有很明显地看出究竟偏在了哪里。 |
| **41–46 秒** | **最想追问的地方：打乱以后怎么还能还原？** 字幕告诉我可以，画面没有让我一眼认出“这就是刚才那串数据”。 |
| **47–60 秒** | 最容易走神。刚理解节拍，又接着听 SerDes、速度翻倍、信号糊、修信号、耗电占面积。我开始只记住“越快越难、越费电”，细节掉了。全景里的装置也变小了。 |
| **63–66 秒** | “总耗电”和“每个比特”两只表，让我短暂卡住：是总耗电下降，还是只说每送一份数据更省电？ |
| **68–72 秒** | 回到消息终于正常，前后接上了，这个收尾有满足感。 |
| **74–81 秒** | “听准节拍”记住了；“拆回一排”我没真正看懂。如果已经看到这里，我会看完，但下一篇预告对我的吸引力一般。 |

**3. 字看不看得清**

基于拼图判断，不能当成实际手机全屏测试：

- **开头问题和手机聊天大字最好读**，白底黑字的小纸签也容易找到。
- **底部主字幕基本能辨认，但不轻松。** 两行字幕出现时，我会优先读字幕，漏看盖点和数字变化。
- **蓝色实心点、空心圈、尺子刻度偏细。** 它们似乎承担了重要解释，但我第一眼不会主动盯着看。
- **47–50 秒的全景、60–64 秒的远景**里，小纸签变成“知道那里有字，懒得读”。右上系列名也基本会被我忽略。
- 没看到特别明显的字幕挡住关键动作。更大的问题是：**要同时看字幕、计数轮和纸带，眼睛忙不过来。**

**4. 看完能用一句话说什么**

> 芯片传数据时，会靠信号变化找准节拍，这样一长串 0 和 1 才不会数错。

这是我真正带走的内容。“排成一列、拆回一排”反而没有节拍这个知识点记得牢。

**5. 我会怎么互动**

- **点赞：** 如果看完，会点。听鼓点这个解释让我学到了东西，画面也有认真做的感觉。
- **收藏：** 大概率不会，我日常暂时用不上。
- **评论：** 最可能写：**“打乱了还能还原，那接收那边怎么知道按什么规则还原？”**
- **转发：** 不会随手转发，除非正好有朋友喜欢电脑、芯片。

**6. 最想让作者改的 5 件事，按重要程度排**

1. **开头先让我看到一句正常消息，再当场变乱码。** 现在一上来就是乱码，我少了“出事了”的直观感受。

2. **“四个还是五个”那里，让我明确看到一次数错。** 连续黑色那一段、四次盖点、最后漏掉的一份，最好能在同一个近景里对应上。我想亲眼发现错在哪里。

3. **“拍子跑偏”给一个明显的后果。** 比如原本盖在格子中间的点，后来压到边上。我就能马上明白“跑偏”不是一句抽象的话。

4. **“打乱—还原”让我认出前后是同一串。** 不需要讲复杂规则，但至少让我看到：原来长这样，途中变了，最后确实变回来了。

5. **后半段讲到哪件事，就让我看清哪件事。** 讲信号糊时看清它怎么糊，讲修信号时看清修前修后；全景里的小标签我真的不会逐个读。结尾“拆回一排”也需要一个能认出来的动作。

**7. 两个平台分别说**

**抖音：** 我更可能在 **3–6 秒**就划走，或者在 **47 秒左右**觉得“后面又开始讲新东西了”而离开。最能留我的，是数错的瞬间和芯片上的发光信号，前提是我能看清发生了什么。

**小红书：** 如果标题让我知道是在解释“芯片怎么不数错数据”，我会更愿意停下来，没懂的地方也可能回看。但收藏前，我希望能清楚复述“怎么数错、怎么数准”，目前后一个讲得更明白。
