## 一、桌上的演示装置

一条纸带从左走到右。左边是发货端，右边是收货端，手机放在最右边（收到的消息显示在它上面）。

| 桌上的东西 | 代表什么 |
|---|---|
| 小托盘里并排的八张小卡（左端） | 并排的数据（一排） |
| 印带器：把小卡一张一张印成纸带上的一格 | 发货端：排成一列 |
| 纸带：黑格 = 1，白格 = 0；下沿一条白边；**不画格线** | 线上的信号 |
| 读带口：一道窄缝，缝边一只小灯 | 收货端：任何一刻只看得到当前的电平 |
| 黑白交界过窄缝：小灯闪一下 + 一声鼓 | 信号的跳变（鼓点） |
| 节拍器（读带口旁） | 收货端自己的时钟 |
| 摆锤摆到左头「嗒」一声；摆到右头在白边上盖一个蓝点 | 「嗒」该和交界对齐；蓝点落在格子正中 = 在比特中间清点一次 |
| 透明尺：刻度 = 发货端印一格的宽度 | 每个比特占多长时间（节拍）；尺是给观众看的，收货端没有 |
| 打乱盒（印带器后）、还原盒（读带口后） | 扰码 / 解扰 |
| 墨的洇边 | 信号在路上变糊 |
| 修字盒、插线板上的功率计、「每个比特」小表 | 修信号的电路；总耗电；每送一个比特花的电 |
| 切刀 + 小托盘（右端）：一格切一段，并排放好 | 收货端：拆回一排 |

三种声音分开：印带器是低低的机械声；交界是**鼓**；节拍器是木头的「嗒」。**鼓只在黑白交界响。**

v2 里的纸箱、画中画、翻牌以外的多余道具已删。

## 二、逐拍分镜

约 1:19，十四句都留。字的上限：同屏大字 ≤ 8 个；小纸签每张 ≤ 8 字、同屏最多 2 张；角注和字幕不算。
画面外的固定元素按系列 skill：顶部五站条（y = 200，快递叫法，亮「打包出发」）、右上角系列名、字幕在抖音文案区上方。合成时在前景加几粒很虚的灰尘。

### 开头（0–7.5 秒）

**y1 · 0.0–2.5 · 机位 A（手机特写，慢推）**
- 口播：少数一个比特，这句话就全乱了。（正常语速，约 2.2 秒）
- 画面：手机屏幕上一条收到的消息「今晚七点，老地方见」。第 0 帧「七」字已经在变，乱码从这里一路蔓延到句尾，1.2 秒时后半句全乱；「今晚」两个字不变。
- 大字：手机上方纸签「芯片怎么数清 0 和 1？」（10 字符，按 8 个大字的上限略超，见「待你定」1）
- 声音：提示音，接一串错位的轻响。

**y2 · 2.5–7.5 · 机位 B（跟着纸带横移，全片唯一一条横移）**
- 口播：**AI** 芯片之间的数据排成一列跑，到了对面，要一个一个数清楚。
- 画面：切到桌子左端。托盘里八张小卡并排着，印带器把它们一张张吞进去，吐出来是一条纸带。镜头跟着纸带往右走，停在读带口；画面右边缘看得到手机。
- 小签：托盘旁「一排」，纸带旁「排成一列」；镜头经过时路线图小卡闪过。

### 问题（7.5–19.5 秒）

**y3 · 7.5–12.5 · 机位 D（发货端，2 秒）→ 切 C2（窄缝特写，3 秒）**
- 口播：可连续五个 1，在线上就是一段平平的高电平：四个，还是五个？
- 画面：印带器连印五下黑，出来是一整段连着的黑，没有接缝。切到窄缝：黑带经过，缝里一直是黑的，小灯不闪。读带口上的翻牌计数器在「4」和「5」之间来回翻。
- 小签：「黑 = 1　白 = 0」；计数器自己就是「4？5？」。角注「示意：只画两种电平」。
- 声音：发货端五下低低的机械声；到窄缝这边只有沙沙声，没有鼓。

**y4 · 12.5–19.5 · 机位 C1（读带口 + 节拍器）**
- 口播：要数清，就得知道每个比特占多长时间，这就是节拍。可高速连接通常不另外送一个节拍器过去。
- 画面：一把透明尺落在黑带上，刻度把它分成五格，一格标「节拍」。说到「不另外送」：镜头里露出发货端那只节拍器，它正要被搁到纸带上跟着走，被一张「不随货送」的纸签挡回去；透明尺也被拿走。读带口这边只剩它自己的节拍器，摆得比鼓点稍慢。
- 小签：「一格的时间 = 节拍」→ 换成「不随货送」。
- 声音：节拍器的「嗒」和交界的鼓明显对不上。此时还不盖点。

### 办法（19.5–33.5 秒）

**y5 · 19.5–24.5 · 机位 C3（节拍器特写，合成里慢推）**
- 口播：就像跟着一首歌拍手：没人给你打拍子，你听着鼓点，自然就跟上了。
- 画面：黑白相间的纸带经过窄缝，每个交界小灯闪一下、响一声鼓。节拍器的「嗒」比鼓晚了，下一摆就早一点；早了，再晚一点。几下之后「嗒」正好落在鼓上。
- 小签：小灯旁「鼓点」。
- 声音：配乐只留鼓；「嗒」一点点靠上去。

**y6 · 24.5–33.5 · 机位 C1 → C2**
- 口播：芯片也一样：信号每跳一下，就是一个鼓点。它跟着鼓点校准自己，再按节拍一个一个清点：五个，不是四个。
- 画面：
  1. 「芯片也一样」：读带口上的纸签翻面，「读带口」→「收货的芯片」。「信号每跳一下」：小灯旁的「鼓点」下面多一行「= 信号跳一下」。
  2. 那段长黑带再来一次。进黑带的交界：一声鼓。然后**没有鼓**，节拍器自己走：摆到右头盖一个蓝点，一、二、三、四、五，都落在白边上、间距均匀。出黑带的交界：又一声鼓，正好和「嗒」合上。计数器停在「5」。
- 小签：第一个蓝点旁「数一个」；最后「五个，不是四个」。
- 声音：鼓、嗒嗒嗒嗒嗒、鼓。五下是节拍器的声音，不是鼓。

### 麻烦和补救（33.5–45.5 秒）

**y7 · 33.5–38.0 · 机位 C2**
- 口播：可要是一长串全是 1，没有鼓点，拍子就会慢慢跑偏。
- 画面：一段很长的黑带。小灯不闪，没有鼓。节拍器还是匀速摆，只是比该有的慢一点点，没人纠正它。透明尺放回带上当参照：蓝点一格比一格更靠右，从格子正中滑到格边；滑过格边的那一个变成珊瑚色，计数器少数了一个。
- 小签：「没有鼓点」→「越偏越多」。
- 声音：只剩匀速的「嗒」，鼓一直不来。

**y8 · 38.0–45.5 · 机位 D（3 秒）→ 切 C1（4.5 秒）**
- 口播：所以很多链路发出去之前，先把数据打乱，**让鼓点不会断太久**；收到以后，再按同样的规则还原。
- 画面：发货端，长黑带进打乱盒，出来是有黑有白的花带。切到读带口：小灯又一下下闪，鼓回来，蓝点回到格子正中。花带过还原盒，出来还是那一长段黑。
- 小签：盒子上「打乱」「还原」。角注「示意」。

### 代价（45.5–62.5 秒）

**y9 · 45.5–49.5 · 机位 E 静帧（整套装置，1.5 秒）→ 切 C2**
- 口播：难的是，SerDes 的速度大约每过几年就要翻一倍。
- 画面：整套装置同框，桌沿一张签「这一整套 = SerDes」。切到窄缝：黑白相间的一段带，纸带走得和刚才一样快，但每一格只有原来一半宽；节拍器摆得快一倍。
- 小签：「每条通道：格子窄一半」。

**y10 · 49.5–57.5 · 机位 C2 → 机位 E（一次拉开，全片第二个真要动的镜头）**
- 口播：越快，信号在路上越容易糊，节拍越难听准；所以它自己也带着不少修信号的电路，这些都要耗电、占面积。
- 画面：墨的洇边从头到尾一样宽，前面格子宽，看不出来；现在格子窄了，洇边把整格吃成一片灰。小灯该闪的时候不闪，蓝点又开始乱。读带口前加一只修字盒，格边清楚了一些；格子再窄一档，又糊，发货端也加一只，收货端再加一只。镜头拉开：盒子占了小半张桌子，插头都在一个插线板上，功率计指针往上走。
- 小签（错开出现，同屏不超过两张）：「越快越糊」→「修信号」→「耗电」「占地方」。
- 声音：每加一只盒子「咚」一声，嗡声升高。

**y11 · 57.5–62.5 · 机位 E 静帧（合成里慢推到两只表）**
- 口播：每一代都在拼同一件事：跑得更快，还要每送一个比特，少花一点电。
- 画面：节拍器再快一档。功率计（总耗电）不往回落。它旁边的小表「每个比特」，指针被一点点往下压，压下去一点又弹回一点。盒子个头小了一圈，数量不少。
- 小签：「更快」「每个比特更省」。

### 收尾（62.5–78.5 秒）

**y12 · 62.5–69.0 · 机位 C1（3.5 秒）→ 切 A（3 秒，配乐停半拍）**
- 口播：回到开头那句话：每秒上千亿个比特，一个都不能数错，它才能完整地到你手里。
- 画面：读带口这边蓝点稳稳地一个接一个，计数器飞快地翻。切到手机：乱码从「七」字起一个个变回来，「今晚七点，老地方见」。
- 小签：读带口旁「一条通道 · 每秒上千亿个」。

**y13 · 69.0–74.5 · 机位 C1 往右带到托盘和手机（合成里平移）**
- 口播：一句话带走：发出去排成一列，收进来听准节拍、拆回一排。
- 画面：说到「拆回一排」，读带口后面的切刀跟着节拍器一下一下落，每下正好切一格，小段并排落进托盘，排成和左端一样的八张。
- 小签：依次出现，前一张淡掉再出下一张：「排成一列」「听准节拍」「拆回一排」。

**y14 · 74.5–78.5 · 机位 A**
- 口播：下一篇：信号上路以后，为什么越跑越模糊？
- 画面：路线图小卡落在手机旁，「你在这里：打包出发」，下一站「路上」亮一下。桌上那截洇了墨的纸带还在画面里。

## 四、机位和花钱

| 机位 | 拍什么 | 用在 | 怎么做 |
|---|---|---|---|
| A | 手机特写（桌子右端） | y1、y12 后半、y14 | 静帧 + 合成 |
| B | 跟着纸带横移 | y2 | **真动，GPU，约 5 秒** |
| C1 / C2 / C3 | 读带口中景 / 窄缝特写 / 节拍器特写 | y3–y9、y12、y13 | 三张静帧；纸带走、蓝点、小灯、洇墨在云端 CPU 合成；节拍器渲一个摆动循环反复用 |
| D | 发货端特写 | y3、y8 | 静帧 + 合成 |
| E | 整张桌子 | y9、y10、y11 | 静帧 + **一次拉开（GPU，约 4 秒）** |

- 静帧在云端 CPU 上渲，不花钱（定妆那张 15 分钟）。所以画面的变化主要靠多切几个机位，不靠多渲运动镜头。
- 真要动的只有 B 和 E 两条，合计约 9 秒。超预算时的兜底：这两条改成对静帧做视差推进，不上 GPU。
- **第一个试镜头先做机位 C 的合成**（纸带在静帧上走、蓝点、节拍器循环），不花钱。它占全片约 35 秒，最容易看着假（接触阴影、洇墨）。这一关过了再给 B、E 报价租卡。
- 每集 3 美元够不够，要等上面两步做完才知道。
