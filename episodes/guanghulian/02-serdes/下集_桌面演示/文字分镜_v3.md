## 一、桌上的演示装置

一条纸带从左走到右。左边是发货端，右边是收货端，手机放在最右边（收到的消息显示在它上面）。

| 桌上的东西 | 代表什么 |
|---|---|
| 小托盘里并排的八张小卡（左端） | 并排的数据（一排） |
| 印带器：把小卡一张一张印成纸带上的一格 | 发货端：排成一列 |
| 纸带：黑格 = 1，白格 = 0；下沿一条白边；**不画格线** | 线上的信号 |
| 读带口：一道窄缝，缝边一只小灯 | 收货端：任何一刻只看得到当前的电平 |
| 黑白交界过窄缝：小灯闪一下 + 一声鼓 | 信号的跳变（鼓点） |
| 节拍器（读带口旁） | 收货端自己的时钟 |
| 摆锤摆到左头轻轻「嗒」一声；摆到右头「啪」地在白边上盖一个蓝点 | 「嗒」该和交界对齐；蓝点落在格子正中 = 在比特中间清点一次。观众数的是「啪」 |
| 透明尺：刻度 = 发货端印一格的宽度 | 每个比特占多长时间（节拍）；尺是给观众看的，收货端没有 |
| 打乱盒（印带器后）、还原盒（读带口后） | 扰码 / 解扰 |
| 墨的洇边 | 信号在路上变糊 |
| 修字盒、插线板上的功率计、「每个比特」小表 | 修信号的电路；总耗电；每送一个比特花的电 |
| 切刀 + 小托盘（右端）：一格切一段，并排放好 | 收货端：拆回一排 |

声音分开：印带器是低低的机械声；交界是**鼓**；节拍器摆到左头是很轻的「嗒」，盖点是清楚的「啪」。**鼓只在黑白交界响；要观众数的只有「啪」。**

v2 里的纸箱、画中画、翻牌以外的多余道具已删。

### 问题（7.5–19.5 秒）

**y3 · 7.5–12.5 · 机位 D（发货端，2 秒）→ 切 C2（窄缝特写，3 秒）**
- 口播：可连续五个 1，在线上就是一段平平的高电平：四个，还是五个？
- 画面：印带器连印五下黑，出来是一整段连着的黑，没有接缝。切到窄缝：黑带经过，缝里一直是黑的，小灯不闪。读带口上的翻牌计数器在「4」和「5」之间来回翻。
- 小签：「黑 = 1　白 = 0」；计数器自己就是「4？5？」。角注「示意：只画两种电平」。
- 声音：发货端五下低低的机械声；到窄缝这边只有沙沙声，没有鼓。

**y4 · 12.5–19.5 · 机位 C1（读带口 + 节拍器）→ 切 D（1.5 秒）→ 切回 C1**
- 口播：要数清，就得知道每个比特占多长时间，这就是节拍。可高速连接通常不另外送一个节拍器过去。
- 画面（观众建议：先演「自己数会数偏」，再解释；用户 11-11 采纳）：
  1. 先让读带口自己数一次。它的节拍器没对过，摆得偏慢；那段长黑带经过时，「啪、啪、啪、啪」只盖下四个蓝点，间距偏大。计数器停在「4」，变珊瑚色。第一个点旁小签「数一个」。
  2. 「每个比特占多长时间，这就是节拍」：一把透明尺落在黑带上，贴着纸带一起走，刻度把黑带分成五格。四个点对五格，一眼看出少了一个。一格旁标「节拍」。
  3. 「不另外送」：切到发货端，印带器旁那只节拍器正要被搁到纸带上跟着走，被一张「不随货送」的纸签挡回去；透明尺也被拿走。切回读带口，只剩它自己那只偏慢的节拍器。
- 小签：「数一个」→「一格的时间 = 节拍」→「不随货送」（一次只留一张）。
- 声音：四下「啪」，然后是一声低低的错音。

### 办法（19.5–33.5 秒）

**y5 · 19.5–24.5 · 机位 C3（节拍器特写，合成里慢推）**
- 口播：就像跟着一首歌拍手：没人给你打拍子，你听着鼓点，自然就跟上了。
- 画面：黑白相间的纸带经过窄缝，每个交界小灯闪一下、响一声鼓。节拍器的「嗒」比鼓晚了，下一摆就早一点；早了，再晚一点。几下之后「嗒」正好落在鼓上。
- 小签：小灯旁「鼓点」。
- 声音：配乐只留鼓；「嗒」一点点靠上去。

**y6 · 24.5–33.5 · 机位 C1 → C2**
- 口播：芯片也一样：信号每跳一下，就是一个鼓点。它跟着鼓点校准自己，再按节拍一个一个清点：五个，不是四个。
- 画面：
  1. 「芯片也一样」：读带口上的纸签翻面，「读带口」→「收货的芯片」，停一秒后淡掉。「信号每跳一下」：小灯旁的「鼓点」下面多一行「= 信号跳一下」，长黑带进来前淡掉。
  2. 那段长黑带再来一次。进黑带的交界：一声鼓。然后**没有鼓**，节拍器自己走：摆到右头「啪」地盖一个蓝点，一、二、三、四、五，都落在白边上、间距均匀。出黑带的交界：又一声鼓，正好和左头的轻「嗒」合上。计数器停在「5」。
- 小签：最后「五个，不是四个」（「数一个」已在 y4 出现过）。
- 声音：鼓、啪啪啪啪啪、鼓。数得出来的是五下「啪」（盖点）；左头的轻「嗒」在中间只有四下，压低，不抢。

### 麻烦和补救（33.5–45.5 秒）

**y7 · 33.5–38.0 · 机位 C2**
- 口播：可要是一长串全是 1，没有鼓点，拍子就会慢慢跑偏。
- 画面：一段很长的黑带。小灯不闪，没有鼓。节拍器还是匀速摆，只是比该有的慢一点点，没人纠正它。透明尺放回带上当参照（贴着纸带一起走）：节拍器慢，每个点都盖晚了一点，蓝点一格比一格更靠后沿（晚到的一侧，画面上是左边），从格子正中滑到格边；滑过格边的那一个变成珊瑚色，计数器少数了一个。点的位置合成时按节拍器周期和纸带速度算，不手摆。
- 小签：「没有鼓点」→「越偏越多」。
- 声音：只剩匀速的「嗒」，鼓一直不来。

**y8 · 38.0–45.5 · 机位 D（3 秒）→ 切 C1（4.5 秒）**
- 口播：所以很多链路发出去之前，先把数据打乱，**让鼓点不会断太久**；收到以后，再按同样的规则还原。
- 画面：发货端，长黑带进打乱盒，出来是有黑有白的花带。切到读带口：小灯又一下下闪，鼓回来，蓝点回到格子正中。花带过还原盒，出来还是那一长段黑。
- 小签：盒子上「打乱」「还原」。角注「示意」。
