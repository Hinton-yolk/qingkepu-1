# 光互连 02 下集 · 桌面演示版 · 事实与来源

口播的事实沿用 `../抖音版_上下集/FACTS.md` 和 `../douyin-split/FACTS.md`（底稿 `articles/ep02.md`）。这里只列这一版新加的画面说法。**都还没过审核。**

| 画面 / 口播 | 依据 | 结论 |
|---|---|---|
| 纸带黑格 = 1、白格 = 0，一格接一格从左走到右 | 两电平（NRZ）串行数据的画法；真实的 100G 级以上通道用 PAM4（见 `../douyin-split/FACTS.md`「连续五个 1」一行） | 类比 + 简化 |
| 读带口是一道窄缝，只看得到当前这一小段 | 接收端在某一时刻只能判断当前电平 | 类比 |
| 纸带上不画格线，五格黑连成一整段 | 连续相同的比特之间没有跳变，电平上没有分界 | 成立（类比表达） |
| 节拍器每响一下，在格子中间盖一个红点 | 接收端按恢复出来的时钟、在比特中间采样 | 类比 |
| 黑白交界每过一次，节拍器被往对的方向推一点 | 时钟数据恢复用数据跳变判断本地时钟相位超前还是滞后，再修正（见 `../douyin-split/FACTS.md`「早了往后拨一点」一行） | 类比（示意） |
| 很长的黑带：没有交界，节拍器越摆越偏 | 长连 1 / 长连 0 没有跳变，时钟恢复无从校准 | 成立（类比表达） |
| 打乱盒 / 还原盒，「同一套规则」 | 扰码 / 解扰用同样的多项式；口播说「很多链路」 | 成立；盒子内部不画，角注「示意」 |
| y8 口播「让鼓点不会断太久」 | 扰码让长串相同电平变得极少，不是绝对保证（`../下集_新风格/FACTS.md` 扰码一节） | 成立 |
| 速度翻倍画成格子变窄、纸带走的速度不变 | 信号在线上的传播速度没变，变的是每个比特占的时间（`DECISIONS.md` 2026-11-11「合成的做法」） | 成立 |
| 格子变窄后墨洇开、交界发灰 | 类比信号在路上变模糊（码间干扰），细讲在 03 | 类比 |
| 修字盒越来越多、功率计指针上升、占掉小半张桌子 | 原文：SerDes 自己带着不少修信号的电路，都要耗电、占面积。盒子数量和指针位置不对应具体数字 | 示意 |
| 纸带切成小段并排落进托盘 | Des：把一列拆回一排（解串） | 类比 |
