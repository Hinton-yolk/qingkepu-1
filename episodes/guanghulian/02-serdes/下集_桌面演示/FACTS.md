# 光互连 02 下集 · 桌面演示版 · 事实与来源

口播的事实沿用 `../抖音版_上下集/FACTS.md` 和 `../douyin-split/FACTS.md`（底稿 `articles/ep02.md`）。这里只列这一版新加的画面说法，对应 `文字分镜_v3.md`。等级沿用原表：〔摘〕= 有来源摘录，〔待核〕= 还没对照来源。

| 画面 / 口播 | 依据 | 结论 |
|---|---|---|
| y1 消息从「七」字起往后变乱码，前面的字不变 | 串行数据少数一位，后面所有位都错位；前面不受影响。真实链路会检测并纠正 / 重传。乱码字是示意 | 示意 |
| 小卡并排（一排）→ 印成纸带（一列）→ 切段并排（一排），每段正好一格 | Ser 把并行数据排成串行，Des 拆回并行。八张只是示意的数量 | 类比 |
| 纸带黑 = 1、白 = 0 | 两电平（NRZ）的画法。每条通道 50G 级以上多用四电平 PAM4，较低速的链路很多仍是两电平（`../douyin-split/FACTS.md`「连续五个 1」一行） | 类比 + 简化；角注「示意：只画两种电平」 |
| 读带口是一道窄缝，只看得到当前这一小段 | 接收端在某一时刻只能判断当前电平 | 类比 |
| 纸带不画格线，五格黑连成一整段 | 连续相同的比特之间没有跳变，电平上没有分界 | 成立（类比表达） |
| 透明尺的刻度 = 一格 =「节拍」；尺和发货端的节拍器「不随货送」 | 原文：这类高速连接通常不另外送时钟。发货端当然有自己的时钟，只是不单独送过去 | 类比 |
| y4 没对过的节拍器偏慢，五格黑只盖了四个点 | 同下一行；一下慢出一整格是夸大的示意 | 示意 |
| y4 收货端的节拍器「稍慢」，所以数不准 | 收发两端的时钟各自独立，频率、相位有小偏差。偏差的大小是示意 | 示意 |
| 摆到左头的「嗒」对齐交界，摆到右头的蓝点落在格子正中 | 时钟恢复让时钟沿对齐数据跳变，采样点在比特中间（`../douyin-split/FACTS.md`「在每个比特的正中间看一眼」） | 类比 |
| y5「嗒」晚了下一摆就早一点 | 用跳变判断本地时钟超前还是滞后，再修正（`../douyin-split/FACTS.md`「早了往后拨一点」一行） | 类比（示意） |
| y6 纸签：「读带口」→「收货的芯片」；「鼓点 = 信号跳一下」 | 对应关系 | 类比 |
| y6 长黑带里没有鼓，节拍器自己走完五下 | 连续相同比特期间没有跳变可用，时钟靠惯性走 | 成立（类比表达） |
| y7 节拍器匀速但略慢，蓝点一格格滑向格边，滑过后少数一个 | 长连 1 / 长连 0 没有跳变，本地时钟的小偏差没人纠正，采样点慢慢滑出比特中间。不画成「越摆越慢」 | 成立（类比表达）；偏差大小是示意 |
| 打乱盒 / 还原盒 | 扰码 / 解扰；口播说「很多链路」。盒子内部不画 | 成立；角注「示意」 |
| y8 口播「让鼓点不会断太久」 | 扰码让长串相同电平变得极少，不是绝对保证（`../下集_新风格/FACTS.md` 扰码一节） | 〔摘〕 |
| 用四电平的通道也要扰码 | `../下集_新风格/FACTS.md` | 〔待核〕；片中不提 |
| y9 纸带速度不变、格子窄一半、节拍器快一倍；签上写「每条通道」 | 信号在线上的传播速度没变，变的是每个比特占的时间（`DECISIONS.md` 2026-11-11）。速度指每条通道 | 成立 |
| y9 口播加「这套负责发货、收货的电路，叫 SerDes」；桌沿的签「这一整套 = SerDes」 | SerDes = 发货端的串行化 + 收货端的解串（含时钟恢复） | 成立 |
| y10 洇边一直一样宽，格子窄了才把整格吃掉 | 类比码间干扰：通道造成的展宽大致固定，比特越短，占的比例越大。细讲在 03 | 类比 |
| y10 糊了以后小灯该闪不闪、蓝点又乱 | 信号模糊后跳变位置不准，时钟更难锁 | 类比 |
| y10 修字盒发货端、收货端都有 | 发送端和接收端都有均衡电路。盒子数量不对应具体电路 | 示意 |
| y10 功率计上升、盒子占掉小半张桌子 | 原文：SerDes 自己带着不少修信号的电路，都要耗电、占面积 | 示意 |
| y11 总功率计不回落，只有「每个比特」小表被往下压；盒子变小但不变少 | 口播说的是每送一个比特少花电，而且是「在拼」。每条通道的总功耗不一定下降 | 示意；「总功耗多半持平或上升」〔待核〕，片中不说 |
| y12 签「一条通道 · 每秒上千亿个」贴在读带口旁 | 每条通道 112 Gb/s 级（原文） | 成立 |

## y6 试镜头（`blender/`，2026-11-11）新加的画面说法

| 画面 | 依据 | 结论 |
|---|---|---|
| 每一格都盖一个蓝点，白格也盖；长黑带下面正好五个 | 接收端每个比特周期采样一次，采样前不知道这一位是 0 还是 1 | 成立（类比表达） |
| 盖点臂和摆杆固定在一起：摆到左头对齐交界，半个周期后摆到右头，印章落在格子正中 | 时钟沿对齐跳变，采样点在比特中间（同上表「摆到左头的嗒……」一行） | 类比 |
| 计数轮在新一段黑带进来时清零，每盖一个点加一，白格不动，最后停在 5 | 只是把「这一段连续的 1 数出几个」显示出来；真实接收端不这样计数 | 示意 |
| 一格 24 mm、0.83 秒一格、摆幅 ±22° | 道具尺寸和节奏，为了看得清；不对应任何真实速率 | 示意 |
| 节拍器外形：底 110 mm 见方、高 215 mm 的木壳，刻度 40–208 | 常见机械节拍器的大致尺寸和速度范围，凭印象建的，没有对照具体型号 | 〔待核〕；只是道具外形 |
| （发光段）走线上亮的一段 = 1、暗的一段 = 0，和纸带同速走进芯片引脚 | 两电平信号的高 / 低电平沿走线传到接收端。电信号本身不发光；一格 24 mm、每秒 28.8 mm 只是为了和纸带对上，真实信号在走线上的速度约为光速的一半到六成，视板材而定（没有查来源，片中不出现） | 示意；角注「示意：电信号本身不发光，金色为示意」 |
| （发光段）跳变到达引脚时闪一下；每个节拍正中芯片上蓝色亮一下 | 同上表：跳变 = 鼓点；采样点在比特中间 | 类比 |
| （发光段）电路板是一块老式主板的 CC0 模型，走线是我们沿板上的空道另画的，不是模型上原有的走线 | 只当「芯片和走线」的实物背景 | 示意 |
| （发光段）信号画成一条走线 | 高速通道实际是差分对（两条线），画成一条是简化 | 简化；片中角注只写「示意」，要不要专门注明等用户定 |
