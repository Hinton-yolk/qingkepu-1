光互连 02 下集 · 质感样张（r1 去塑料感 + r2 Epic 化）· 2026-11-10

1. 解压到不含中文的路径（例如 D:\Render\lookdev\）。可以把上一个包里的 blender_path.txt 复制过来，省得再拖 blender.exe。
2. 双击 lookdev.bat。两轮（r1 去塑料感、r2 Epic 化）× 两个引擎（EEVEE、Cycles 用显卡），共 10 张。
   预计 EEVEE 几分钟；Cycles 带体积光会慢一些，每张可能几十秒到一两分钟。
3. 把 lookdev 文件夹压缩发回，再截一张窗口截图（看得见 FRAME_TIME 和 CYCLES_DEVICE）。

r2（Epic 化）比 r1 多了：低角度暖色逆光藏在散热器后面，光从鳍片缝隙漏出来成光柱（体积光）；主板铺到远处，长满芯片、散热器、电感、内存条，远处没入暗处。
r1（去塑料感）改了什么：主板换成暗墨绿哑光阻焊 + 清漆，走线、金焊盘、丝印、过孔都压在阻焊下面（不再是凸起的塑料条）；
散热片改成拉丝铝；环境光压低、后侧轮廓光加强；雾更淡；景深按毫米单位换算过（EEVEE 里应该能看到背景虚化）。
