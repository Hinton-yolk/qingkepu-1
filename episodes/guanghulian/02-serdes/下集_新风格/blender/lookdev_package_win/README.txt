光互连 02 下集 · 质感样张（去塑料感）· 2026-11-10

1. 解压到不含中文的路径（例如 D:\Render\lookdev\）。可以把上一个包里的 blender_path.txt 复制过来，省得再拖 blender.exe。
2. 双击 lookdev.bat。会用 EEVEE 和 Cycles（用显卡）各渲 3 张：B 段第 45、120 帧，A 段第 40 帧。
   预计 EEVEE 两三分钟；Cycles 每张可能十几到几十秒，第一次还要编译一两分钟。
3. 把 lookdev 文件夹压缩发回，再截一张窗口截图（看得见 FRAME_TIME 和 CYCLES_DEVICE）。

这一版改了什么：主板换成暗墨绿哑光阻焊 + 清漆，走线、金焊盘、丝印、过孔都压在阻焊下面（不再是凸起的塑料条）；
散热片改成拉丝铝；环境光压低、后侧轮廓光加强；雾更淡；景深按毫米单位换算过（EEVEE 里应该能看到背景虚化）。
