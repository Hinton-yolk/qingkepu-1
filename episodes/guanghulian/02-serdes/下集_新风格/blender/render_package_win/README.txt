光互连 02 下集 · 新画面版 · EEVEE 渲染包（正式版开头两段 + 背景）· 2026-11-10

1. 解压到不含中文的路径（例如 D:\Render\ep02x\）。需要 Blender 5.x（和云端测试用的 5.2.3 一致最好）。
2. 渲之前：插上电源；Windows「设置 → 系统 → 屏幕 → 显示卡」里把 blender.exe 设成「高性能（NVIDIA）」；笔记本垫高散热。
3. 先双击 preview_eevee.bat：试渲 3 帧，看每帧多久（FRAME_TIME）。把窗口截图和 preview 里的 3 张图发给 Claude。
4. 速度可以的话，再双击 start_render_eevee.bat 渲正式版：A 段 72 帧 + B 段 120 帧 + 5 张背景，共 197 张。
   按每帧 12–15 秒估，约 40–50 分钟。中途停了可以再双击，已渲的会跳过。
5. 渲完把 output 文件夹整个压缩成 zip 发回。字幕、五站条、光带动画、配乐都在云端合成。

这一版画的是：桌上的手机（消息变乱码）→ 信号飞出去 → AI 服务器主板上的一对差分走线（金色光带是示意：两根线之间的电压差）。
背景静帧不带光带，光带在云端画成会流动的动画。
素材：assets_dl 里的 HDRI 来自 Poly Haven（CC0）；assets 里的图是脚本生成的。
