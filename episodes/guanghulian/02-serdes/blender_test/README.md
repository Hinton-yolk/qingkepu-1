# Blender 测试镜头：02 上集开头（2026-11-09）

用户看过 MKBHD × EpicSpaceman 的《I shrunk down into an M5 chip》（Blender 做的），问能不能借助 Blender 做片子。先拿 02 上集开头（8.25 秒，配音同正片）做一个测试镜头。

- `shot_open.py`：全部用 Python（bpy）搭场景，不开图形界面。木桌、DB-25 并口插头（25 根针看得见）+ 灰色粗线、USB-C 插头 + 黑色细线；线上跑发光小环（并口线稀、慢，USB 密、快，带运动模糊）；俯拍慢推、浅景深。同时导出每帧锚点 `anchors.json`。
  `blender -b --python shot_open.py -- <输出目录> <宽> <高> <采样> [帧号…]`
- `composite.py`：帧放大到 1080×1920，叠大字问题、「25 根线 / 4 根线」引线标签、速度标签、字幕（抖音位置 y = 1400），配正片开头的声音。

渲染时间（这台云端容器：4 核 CPU、无显卡，Cycles）：1080×1920、20 采样约 58 秒一帧；测试片用 720×1280、16 采样约 19 秒一帧再放大，198 帧约 1 小时。
有显卡的电脑上（Cycles 用 GPU 或 EEVEE）同样的镜头大约几分钟。
