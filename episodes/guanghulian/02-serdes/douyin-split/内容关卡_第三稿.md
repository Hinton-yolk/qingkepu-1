## 第 1 条：AI 越来越快，芯片之间的路却越修越少？（预计约 61 秒）

**这条只讲一件事**：速度一高，几十条路很难让每一批数据「一起到」，所以干脆只修几条路、排成一列跑。

**口播**（加粗 = 开头两句，放慢 + 同步大字）

- **AI 越来越聪明，**
- **靠的是上万颗芯片一起练。**
- 它们每算一步，都要互相交换数据。
- 可芯片之间最快的连接，偏偏只修几条路。
- 其实你早就见过：25 针的老打印机线，跑不过只有 4 根线的 USB。
- 为什么路少了，反而快？
- 直觉上，路越多，一次送出去的就越多。
- 可几十条路一起送，有个前提：每一批货，必须一起到。对面等齐了，才能拼出完整的数据。
- 跑得慢的时候，这不难：一批和一批隔得远，晚到一点也来得及。
- 可速度一快，一批接一批挤得越来越紧，留给「一起到」的时间就越来越短。
- 这时哪怕有一条路长了一点点，那件货晚到一步，就混进了下一批，整批数据就拼错了。
- 路越多，越难让每一条都一样长。
- 所以干脆反过来：只修几条路，让数据排成一列，一个接一个地跑。不用再等谁，每条路都能一路提速。
- 一句话带走：
- 路少不是退步。速度一高，「一起到」比「路多」更难。
- 下一条：排成一列以后，连续五个 1，对面怎么数清？

**画面**

- ① 手机里和 AI 对话 → 镜头拉远，变成一大片芯片，每算一步光点在芯片之间来回
- ② 两颗金属芯片之间只有两条亮线；打印机线（25 针）和 USB（4 根线）比速度
- ③ 透视通道：十几条发光的路伸向远方，一批批光点冲向镜头，近处一道发光的「到达门」
- ④ 慢的时候批与批隔得远，全部穿过门；变快以后一批紧挨一批，门越来越窄
- ⑤ 第 7 条路多绕一小段，那颗光点晚到、变红、混进下一批；拼出的数据打红叉
- ⑥ 十几条路收成两条，光点排成一列、拉出长长的光尾，速度一路往上

## 第 2 条：数错一个 0 和 1，会怎样？（预计约 57 秒）

**这条只讲一件事**：没人给接收端打拍子，它从每一次跳变里对表、锁住节拍，在每个比特正中间清点；数据先打乱，保证跳变够多。

**口播**（加粗 = 开头两句，放慢 + 同步大字）

- **你刷的每条视频，**
- **都是一串 0 和 1。**
- 可在线上，没有一个个分开的 0 和 1：连续五个 1，就是一条直线。
- 是四个，还是五个？数错一个，数据就错了。
- AI 芯片之间每秒要这样数上千亿个，还没人告诉它节拍。它怎么数清？
- 要数清，就得知道每个比特有多长：这就是节拍。
- 秘密在这些跳变里：每次从 0 变 1、从 1 变 0，接收端就拿它对一次表。
- 早了，就往后拨一点；晚了，就往前拨一点。对上几次，节拍就锁住了。
- 锁住以后，在每个比特的正中间看一眼，一个一个清点：五个，不是四个。
- 可要是一长串全是 1，没有跳变，它就没法对表，节拍会慢慢跑偏。
- 所以发出去之前，数据会先被打乱，让 0 和 1 混得够勤；收到以后，再按同样的规则还原。
- 一句话带走：
- 芯片不是在看 0 和 1，是在听节拍：每一次跳变，都是它的节拍器。
- 下一条：芯片号称速度翻倍，该问它哪三个问题？

**画面**

- ① 手机里一段风景视频碎成 0 和 1，飞成一条发光的信号；连续五个 1 是一条直线
- ② 两把刻度尺一把数出 4、一把数出 5；角落小画面花屏
- ③ 「每秒 1000 亿+」；节拍器被划掉
- ④ 跳变处闪光，下面一排薄荷色节拍光柱先是乱晃，每遇到一次跳变就被拨正一点，几次后锁住
- ⑤ 锁住后光柱落在每个比特正中间，1-2-3-4-5 依次点亮
- ⑥ 一长串 1：光柱慢慢跑偏变红 → 数据被打乱成密集跳变，光柱重新锁住；收到后还原

结尾：纸桌上一张文字条「一句话带走」+ 黄色荧光笔，片尾「下一条」。

## 第 3 条：AI 芯片「速度翻倍」，该信几分？（预计约 46 秒）

**这条只讲一件事**：看到「速度翻倍」，先问三句：在什么路上跑的？每个比特花多少电？真实芯片上跑通没有？

**口播**（加粗 = 开头两句，放慢 + 同步大字）

- **AI 芯片的新闻，**
- **天天在说速度翻倍。**
- 可这就像汽车说最高时速 300，没说是在什么路上跑的。
- 看懂这类新闻，先问三个问题。
- 第一问：在什么路上跑出来的？
- 同样写着 224G，一个能推过一米长的铜缆，一个只跑几厘米。
- 路越长、损耗越大，越难跑。
- 第二问：每传一个比特，花多少电？
- 要是每个比特的电降不下来，速度翻倍，耗电也跟着翻倍。几万颗芯片一起跑，每一点电都是成本。
- 第三问：在真实芯片上跑通了吗？
- 纸面和仿真里的速度，和真做出芯片、测出来的速度，是两回事。
- 一句话带走：
- 下次看到速度翻倍，先问三句：什么路？多少电？跑通没有？
- 下一条：信号上路以后，为什么会越跑越模糊？

**画面**

- ① 几张「速度翻倍」的新闻卡（标题虚构，不点名）、×2
- ② 时速表拉到 300，一边平坦高速、一边坑洼土路
- ③ 两颗刻着 224G 的金属芯片：一颗拖出一米长的发光铜缆，一颗只有几厘米走线；长路上的信号越跑越糊
- ④ 电表：速度翻倍、每比特的电不降 → 总耗电翻倍；镜头拉远，几万颗芯片一起亮
- ⑤ 纸面/仿真的虚线芯片 → 真实芯片，测出来的信号画面，打勾
- ⑥ 三张问题卡排成一排：什么路？多少电？跑通没有？

结尾：纸桌上一张文字条「一句话带走」+ 黄色荧光笔，片尾「下一条」。
