## 第 1 条：路越多，照片越容易拼错（约 44 秒）
**翻译**：数据 = 一张照片；并行 = 把照片切成几十条，一条一条路送；时间对不齐 = 有一条晚到半步、拼进了下一张照片。

| 口播 | 画面（同步） |
|---|---|
| **你发出去的每张照片，** | 第一帧：手机聊天里刚发出去的一张照片，中间一条错了位；旁边标注「晚到半步的一条」 |
| **在芯片之间都要跑一趟。** | 照片从手机飞进一颗芯片 |
| 直觉上，修几十条路，把照片切成几十条一起送，最快。 | 照片切成 12 条横条，各走一条路往前飞 |
| 慢的时候确实没问题：每一条都按时到，照片拼得严丝合缝。 | 一张一张照片慢慢到，每张都拼好，打勾 |
| 可速度**一快**，一张紧跟着一张；哪条路长了一点点，那一条就晚到半步，拼进了下一张。 | 说到「一快」的那一刻，照片一下子加速、一张贴着一张；第 7 条路多绕一段，那一条慢动作落进下一张 |
| 照片就成了这样。 | 镜头推近：拼出来的照片中间一条错位（和第一帧呼应） |
| 聊天、转账也一样：没有纠错的话，错一位，意思就全变了。 | 一条消息「转账 999 元」，一位变了成「转账 991 元」（示意） |
| 路越多，越难让每一条都一样长。 | 几十条路各自弯一点，一张张照片都拼歪 |
| 所以最快的芯片反过来：只修几条路，让数据排成一队，一个接一个跑。不用等谁，就能越跑越快。 | 照片化成一串像素排成一队，沿两条路飞，越来越快；到了对面按顺序拼回去，完整无缺 |
| 一句话带走：路少，反而不会乱。 | 纸条 + 荧光笔 |

## 第 2 条：芯片数 0 和 1，靠的是耳朵（约 48 秒）
**翻译**：数错 = 一句消息变乱码；节拍 = 拍子；跳变 = 鼓点；时钟恢复 = 跟着一首歌拍手；扰码 = 让歌里一直有鼓点。

| 口播 | 画面（同步） |
|---|---|
| **少数一个 1，** | 第一帧：聊天里发出去「今晚七点，老地方见」，对面收到一串乱码；乱码旁标注「少数一个 1」 |
| **这句话就全乱了。** | 乱码那一句抖一下，字一个个变 |
| 芯片之间每秒要数上千亿个 0 和 1。可线上连着五个 1，看起来就是一条直线：四个，还是五个？ | 那句话化成一条发光的信号；平的一段旁边「4？」「5？」轮流闪 |
| 没人在旁边打拍子，它怎么数清？ | 一个节拍器出现，被划掉 |
| 就像你跟着一首歌拍手：没人给你打拍子，你听着鼓点，自然就跟上了。 | 一首歌的声波 + 一双拍手的手（剪影），手跟着鼓点拍 |
| 芯片也一样：信号每跳一下，就是一个鼓点。它跟着鼓点校准自己，几下就踩准了。 | 信号每一次跳变都亮一下、配一声鼓；下面的拍子光柱一点点对齐，「咔」一下全部踩准 |
| 踩准以后，每一拍看一眼：五个，不是四个。 | 五个 1 一拍一个亮起来：1-2-3-4-5 |
| 可要是一长串全是 1，就像歌里拖了一个长音，没有鼓点，拍子就会慢慢跑偏。 | 一段很长的平线，鼓声停了，拍子光柱慢慢歪掉、变红 |
| 所以发出去之前，先把数据打乱，让鼓点一直都在；收到以后，再还原回来。 | 一长串 1 被打乱成有起有伏的信号，鼓点回来了；对面还原，那句「今晚七点，老地方见」完整出现 |
| 一句话带走：芯片数 0 和 1，靠的不是眼睛，是耳朵。 | 纸条 |
| 下一条：芯片说速度翻倍，该问哪三句？ | 片尾 |

## 第 3 条：速度翻倍，到手可能打对折（约 41 秒）
**翻译**：路况 = 千兆宽带到卧室只剩一半；每比特的电 = 手机跑分越高越烫手掉电；实测 = 发布会续航 vs 到手续航。

| 口播 | 画面（同步） |
|---|---|
| **发布会上的速度翻倍，** | 第一帧：发布会大屏「速度 ×2」，台下一部手机「实测 ×1」，标注「到手：打对折？」 |
| **到手可能打对折。** | 手机上的实测条只走到一半 |
| AI 芯片的新闻也一样，天天在说速度翻倍。先问三句。 | 几张新闻卡划过；三张问题卡砸下来 |
| 第一句：在什么路上跑的？就像千兆宽带，到你卧室可能只剩一半。 | 一张户型图：路由器旁「1000M」，隔两堵墙的卧室「500M」 |
| 同样写着 224G，有的能推过一米长的铜缆，有的只跑几厘米。 | 两颗刻着 224G 的芯片：一颗拖着一米长的铜缆，一颗只有几厘米 |
| 第二句：费不费电？就像手机，跑分越高，越容易烫手掉电。几万颗芯片一起跑，电费就是真金白银。 | 手机跑分数字飞涨、温度计变红、电量往下掉；镜头拉远，几万颗芯片一起亮，电费表狂转 |
| 第三句：真机测过没有？发布会上的续航，和你到手的续航，常常是两回事。 | 发布会 PPT「续航 2 天」裂开碎掉；旁边真手机「1 天」；然后换成真芯片插着探针在测 |
| 一句话带走：下次看到速度翻倍，先问：什么路？费不费电？实测了吗？ | 纸条 |
| 下一条：信号上路以后，为什么越跑越模糊？ | 片尾 |

事实要点（定稿后写进 FACTS.md）：
- 「照片切成几十条」是类比：并行总线一次传一个字的多个比特，不是照片的横条；画面上的「错位」是把「某一位晚到、被算进下一拍」可视化。
- 「没有纠错的话，错一位意思就全变了」：真实链路有纠错和校验，口播加了前提；「999 变 991」是示意。
- 「跟着歌拍手」「千兆宽带到卧室只剩一半」「跑分越高越烫手」「发布会续航」都是类比；宽带例子说的是「可能」。
