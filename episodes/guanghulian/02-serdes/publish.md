```
老打印机的并口线有 25 根线，每秒大约两兆字节；只有 4 根线的 USB，每秒几十兆。
AI 训练时，上万颗芯片每算一步都要交换数据，它们之间最快的路，也只修几条。

为什么不多修几条路，一起送？
① 很难同时到：慢的时候，每一批都按时到齐；速度一快，一批紧跟着一批，哪条路长了一点点，那件货就晚到一步，混进下一批（就像一排运动员要同时冲线，跑得越快越难齐）
② 出口不够：芯片对外的引脚就那么多，每多一条线，就多占面积、多耗电

所以反过来：只修少数几条路，让数据排成一列，每条路都跑到极快。今天一条通道，每秒要送出上千亿个比特。
干这件事的电路叫 SerDes：Ser（串行化）把并排的数据排成一列，Des（解串）到了对面再拆回一排。

一句话带走：速度一高，并排走就难对齐，所以数据要排成一列出发。

下集：排成一列以后，对面怎么数清 0 和 1？

```

标题：

```
芯片怎么数清0和1？靠听鼓点
```

备选标题：
```

```
```
没人打拍子，芯片怎么数清0和1
```

正文：
```
少数一个比特，后面的比特全部错位，一句「今晚七点，老地方见」就成了乱码。

芯片之间的数据排成一列跑，到了对面要一个一个数清楚。可连续五个 1，在线上就是一段平平的高电平：四个，还是五个？
要数清，就得知道每个比特占多长时间，这就是「节拍」。可高速连接通常不另外送一个节拍器过去。

就像跟着一首歌拍手：没人打拍子，你听着鼓点就跟上了。
芯片也一样：信号每跳一下就是一个鼓点，它跟着鼓点校准自己，再按节拍一个一个清点（业内叫时钟数据恢复）。
要是一长串全是 1，没有鼓点，拍子就会慢慢跑偏。所以很多链路发出去之前，先把数据打乱，让鼓点一直都在；收到以后再按同样的规则还原。

难的是，SerDes 的速度大约每过几年就要翻一倍：越快，信号越容易糊，节拍越难听准，修信号的电路都要耗电、占面积。每一代都在拼：跑得更快，还要每个比特少花一点电。

一句话带走：发出去排成一列，收进来听准节拍、拆回一排。

上集：线越多，反而越慢？
下一篇：第二站 路上，信号为什么越跑越模糊？

#光互连 #AI算力 #芯片 #SerDes #时钟恢复 #扰码 #硬科技 #科普
```

### 置顶评论
```
上集讲了为什么要排成一列（线越多，反而越慢？）。你跟着歌拍手的时候，有没有拍着拍着就跑偏？芯片也会，所以要先把数据打乱。
```
