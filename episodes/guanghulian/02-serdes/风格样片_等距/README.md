# 风格样片：等距实物剖面（2026-11-09）

用户问「动画演示风格上还有没有其他适合的」，选了先看「等距实物剖面」。拿 02 上集的两段做样片，音频直接用正片那两段，和纸桌版并排比：
- 0–8.25 秒 = 正片开头：并口线（25 根）vs USB（4 根），线头剖开露出铜芯；排线上的货并排慢慢挪，USB 上排成一列飞快地跑；收件台上 USB 一秒摞一张照片，并口线的进度环二十秒才一圈（比例示意）。
- 8.25–17.1 秒 = 正片 23.25–32.1：五条车道，第 3 条中间多绕一小段坡；慢的时候一批批都在时间窗口里到齐 ✓，快了 0.3 秒一批，绕坡的那件掉进下一批 ✗（下面的平面面板把「拼出来的数据」摊开给你看）。

文件：`iso.html`（Canvas2D 等距投影，`window.seek(t)` 纯时间函数）、`render_iso.mjs`（`node render_iso.mjs frames 30 17.125` 出帧）。成片和对比片不进仓库。
投影比标准等距更俯一点（竖屏要上下铺开），字幕位置和抖音版一致（y = 1400）。
