# 测试镜头二「硅光波导是怎么刻出来的」· 事实与示意说明（2026-11-09）

| 片中说法 | 依据 / 说明 |
|---|---|
| 顶层硅 220 nm | 硅光平台最常用的 SOI 规格是 220 nm 顶层硅（IMEC、AMF、GlobalFoundries 等硅光工艺均以 220 nm SOI 为基础）。 |
| 埋氧层（二氧化硅）约 2 µm | 硅光 SOI 的埋氧层一般 2–3 µm，用来把光和硅衬底隔开、防止漏光到衬底。片中写「约 2 µm」。 |
| 波导宽约 0.5 µm | 1550 / 1310 nm 单模硅条形波导典型截面约 450–500 nm × 220 nm。 |
| 光刻胶照到紫外光后会「变」，显影时被洗掉 | 正性光刻胶：曝光区域在显影液中溶解。片中掩模中间一条铬挡光，所以中间那条胶留下。 |
| 等离子刻蚀，停在埋氧层 | 条形（strip）波导是把顶层硅全部刻穿到埋氧层；脊形（rib）波导只刻一部分，片中演示的是条形。 |
| 光沿着硅走 | 硅折射率约 3.48，二氧化硅约 1.44，折射率差把光限制在硅芯里（全内反射）。 |

## 示意 / 简化（片中角注「层厚、颜色均为示意」「实际是看不见的红外光，青色为示意」）
- 层厚按对数压缩：真实硅衬底约 0.7 mm，是顶层硅的约 3000 倍。
- 掩模画成悬在胶上方的一块玻璃（接触 / 接近式曝光的样子）。量产硅光多用 193 nm 深紫外**投影**光刻：掩模在光刻机里，图形缩小 4 倍投到晶圆上。
- 只画了一条波导；真实芯片上同时刻出成千上万条，之后通常还要再盖一层二氧化硅上包层（片中省略）。
- 波导里的光是 1310 / 1550 nm 红外光，人眼看不见；青色只是示意。
