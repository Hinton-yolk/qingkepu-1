测试镜头二「硅光波导是怎么刻出来的」· Blender 渲染包（Windows + NVIDIA 显卡）· 2026-11-09

和上一个包（02 上集开头）用法完全一样。Blender 路径已经记住的话，这次不用再拖 blender.exe。
（blender_path.txt 在上一个包的文件夹里；如果这次又提示找不到，再拖一次就好。）

【渲染】
1. 解压到不含中文的路径，比如 D:\render\waveguide\。
2. （可选）双击 preview_frame.bat：只渲一帧（第 385 帧），看显卡是否在用、一帧多久。
   乘 420 大约就是整段时间。
3. 双击 start_render.bat，开始渲整段（14 秒，30 fps，1080x1920，420 帧）。窗口别关。
4. 完成后 output 文件夹里有两个文件，都发回给 Claude：
   - waveguide.mp4（画面，没有字、没有声音）
   - anchors.json（每一帧各层在画面里的位置，给加标签用）
   之后加工序条、层名标签、字幕、配乐都在云端做。

【这个镜头里有什么】
0–2.6 秒   SOI 层块：硅衬底 / 埋氧层 / 顶层硅（大字问题 + 层名标签）
1–2.6 秒   一滴光刻胶落下，铺开
2.8–5.3 秒 掩模滑进来，紫外光一排排照下去，照到的胶发紫光；镜头跟着光往下推
5.3–6.4 秒 显影：照过的胶溶掉，中间那条留下
6.6–8.6 秒 等离子刻蚀：两边的硅被削掉，停在埋氧层
9.0–9.8 秒 去胶，露出硅波导
10–14 秒   镜头绕到正前方；光从远处沿着波导跑过来，从端面射出

【常见问题】同上一个包：找不到 Blender 就把 blender.exe 拖进黑窗口按回车；杀毒软件拦 .bat 选「仍要运行」。
