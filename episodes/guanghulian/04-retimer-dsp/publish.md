备选标题：
```
糊掉的信号怎么修？均衡和Retimer
```
```
音乐App的均衡器，芯片里也有一个
```

正文：
```
音乐 App 里的均衡器，能把高音、低音各自调大调小。
AI 芯片之间传数据，芯片里做的是同一件事。

铜线会吞掉一部分信号，而且削弱「快速跳变」最厉害：棱角被削掉，拖出尾巴，信号就糊了。
修法是反过来补：
① 发出去之前，先把容易被削的跳变加强一点
② 收到以后，再把被削的部分补回来
不是把整个信号一起放大，而是哪部分被吞得多，就补哪部分。业内就叫它「均衡」，和 App 里的均衡器是同一个词。

没有均衡，AI 芯片之间要么只能说得更慢，要么只能把路修得更短。

路太长、两头补不过来，就在路中间设一个检修站：Retimer（重定时器）。
它先均衡，再一位一位认出是 0 还是 1，找准节拍，重新发出一条干净的信号。后半程等于重新出发。
但前提是先认对：认错的那一位，重新发得再清楚，也只是清楚地发错。
更轻的一种叫 Redriver：只做均衡、不重新认数据，更省电、更快，适合路况没那么差的地方。

一句话带走：修信号分两步，先均衡，让信号好认；路太长，就用 Retimer 认清、重新出发。认错的，修不回来。

```

### 小红书
视频文件：`光互连04_小红书_下集.mp4`
封面：`小红书版/ep4下_小红书封面_1080x1440.png`

标题：
```
光模块一半的电，花在哪？DSP最费电
```

备选标题：
```
DSP是什么？光模块里最费电的芯片
```
```
拿掉DSP，光模块省一半电？
```

正文：
```
AI 机房里，大多数光纤两头，都插着一个光模块。
里面最费电的，往往不是发光的激光器，而是一颗专门修信号的芯片：DSP（数字信号处理）。厂商资料里，它常占光模块功耗的一半左右。

DSP 怎么修信号？
① 对收到的波形高速采样：在一连串时刻，把高低记成数字
② 边收边算，推算出原来发的是 0 还是 1
这里有两种数字：采样得到的，描述的是波形；算出来的，才是原本的数据。
就像认一张糊掉的字条，你会结合前后几个字，猜出中间那个。速度越高、信号越糊，它越有用。

DSP 不是第三种检修站，而是检修站里的工具：它可以藏在 SerDes 里、用在 Retimer 里；电信号换乘光之前，光模块里通常也有一颗。

不过，处理得越多，代价越大：多采样、多计算、多打一次节拍，就多花电，也多一点延迟。一个 AI 集群里这样的环节成千上万，电就是这样累积起来的。

所以业内有个新思路（常叫 LPO，线性驱动可插拔光模块）：把光模块里的 DSP 拿掉，让主芯片自己的 SerDes 来修，光模块的功耗能降到一半左右。
但修信号的活没有消失，只是挪到了主芯片身上，对路况的要求也更高。

一句话带走：DSP 是用算法修信号的工具；修得越多，越费电。

上集：芯片里，也装着均衡器？
下一篇：第三站换乘，数据是怎么被装到光上的？

#光互连 #AI算力 #光模块 #DSP #LPO #SerDes #数据中心 #功耗 #硬科技 #科普
```
