# Director-Locked V0.2｜The Message Becomes Light（9 秒局部重构）

> 状态：导演执行规范，**不是完成验收**。制定日期：2026-11-13。对象：Codex 已制作的独立 9.000 s / 270 帧 / 540×960 / 30 fps 电控光测试；不是 T5 20.8 秒整片，也不是 T6 37 秒、125 秒正片。
>
> 唯一命题：**光原本就在那里；金色电信号到达，改变调制器状态，出口的青色光才开始携带信息。** 观众不用字幕也看见“原因→作用→结果”。旧版 0–2s 灰模块推近、2–5s 停板、5–7.5s 发亮、7.5–9s 交八位结果，禁止原样沿用。

## 0. 导演锁定项（不可自行改动）
- **只改 9 秒，30 fps，严格 270 帧，帧号为 0–269。** 竖屏 540×960 用于审阅，交付必要时保留可上采样的物理场景和分层源文件。
- 共 **四个镜头、三个有动机的切点**：S1 f000–044，S2 f045–089，S3 f090–194，S4 f195–269。**不允许**白闪、无动机转台、跨尺度俯冲、交叉溶解、PPT 卡片挪进挪出、悬浮图表或整屏数字标题。
- 金色只指**电驱动的可视化**；青色只指**红外导波光的可视化**。所有光只在设计的波导/纤芯里运动，不以霓虹粒子穿空气。颜色和传播速度**高度示意、慢放**，不要暗示人眼可见红外或真实光学时间尺度。
- 电输入位图样：**10110010**，亮=1，暗=0；零位不得表现为消息消失，仅为较低电平；输出光强状态应与当前电平码一致，光暗**不等于完全熄灭**（建议归一化亮 1.0、暗 0.25–0.35）。光源及入射段始终稳定。
- 用**同一颗实体芯片、同一条输入波导、同一个调制单元和同一条输出波导**组成空间；四镜头不能各画一张互不相干的示意图。允许复用旧 Blender 模型/纹理，但**不继承旧运镜**。
- 以代表性 **Mach–Zehnder 强度调制器**示意：稳定光分两臂；电压作用于相位调节段；合束端的相对相位变化体现为光强变化。不要把它画成电子直接变光子；“电推光变慢半步”只可作为慢放比喻，不当作精确时间延迟或未经验证的器件细节。参考：[Ansys MZM](https://optics.ansys.com/hc/en-us/articles/360042327954-Calculating-modulation-response-MZM-example)、[Silicon phase shifters review](https://pmc.ncbi.nlm.nih.gov/articles/PMC9504597/)。
- 零新增成本：**不得调用付费 GPU、不采购素材、不启用外部付费 TTS**；使用现有 Blender/EEVEE、低采样 CPU 或 2.5D 预演即可。维持 PR #3 Draft，不合并、不发布、不扩展到其它段落。

## 1. 空间规则与运动约定

坐标是**屏幕归一化坐标** `(x,y)`：左上为 (0,0)，右下为 (1,1)。540×960 审核图像，安全重要区域 x=0.07–0.93、y=0.13–0.85。镜头示意中 **C**=青色光真实承载路径，**G**=金色电的电极传播路径，**K**=相机轨迹；这些字母、箭头及控制点**只供制作，不入画**。必须在 Blender 中以投影后的屏幕坐标复核。

视角：一颗暗金属/硅微结构的真实立体空间（约 25°–35° 斜俯角），**不是**正交俯视电路板；低对比哑光衬底、局部高光、前后遮挡和少量景深表现体积。光路、金电极和合束点永远比背景纹路更易读。镜头运动不超过标注幅度，不使用旋转炫技。

### S1｜“它早就亮着”｜f000–044（0.00–1.50s）
**观众认知**：不是空芯片，先认出一束已经存在、稳定前进的光。
- **构图示例（竖屏草图，箭头为制作标记）**：
```text
┌──────────────────┐
│  暗哑光硅芯片斜面  │  上方留有空间纵深
│       ╱   ╲      │
│   C↑ ╱     ╲ ↑C  │  光从下进入、分成两臂
│      ╲_____/      │
│         ↑         │
│    连续青色输入光   │  主体在中下部
│    [微观结构锚点]   │
│                  │
└──────────────────┘
```
- **镜头/主体在画面上的轨迹**：C: (0.47,0.79) → (0.46,0.62) → (0.38/0.61,0.49)，连续、不间断；K: (0.50,0.50) → (0.50,0.46)，极缓慢推近，等效主体放大**≤8%**，不转向。电极在右后侧未激活，不出现醒目的金光。
- **帧锁**：f000 光已在波导内；f012 观众看清输入段；f024 见到分叉；f036–044 入射亮度保持常数，准备与 S2 在分叉中心作 **位置匹配切**。
- **禁**：起手灰模块占满屏、空镜 1 秒、浮字解释“激光输入”。

### S2｜“电正赶来”｜f045–089（1.50–3.00s）
**观众认知**：在同一器件中，另一条金色线路正朝一个作用点靠近。
- **构图示例**：
```text
┌──────────────────┐
│  合束出口 C↑       │
│   C │     │ C     │
│   C │  ◉  │ C     │  ◉=电作用区域，固定可辨
│   C │     │ C   G↑│
│   C ╲_____/    G↑ │
│    C↑          G↑ │  金脉冲从右下向中部
│     输入稳定       │
└──────────────────┘
```
- **轨迹**：光 C 按 S1 原路径稳定上行；金色驱动 G: (0.86,0.77) → (0.79,0.60) → (0.72,0.46)，可见有**位沿真实电极传播**，不能只是整个电极泛光；K 缓慢侧移 (0.50,0.49) → (0.47,0.49)，投影位移 **≤30 px**；无摇镜/倾斜。
- **帧锁**：f045 S1 同位置匹配；f055 金色位列首次进入画面；f073 最前沿抵达金电极的前导段；f084–089 留一小段“就要到达”的视线预期。切到 S3 保持**同一作用区域、相同左右关系**，不能换画面方向。
- **禁**：小字“电信号”突然贴图、两条线毫无位移却一起闪。

### S3｜“电改变光”｜f090–194（3.00–6.50s）——全片唯一高潮
**观众认知**：输入光稳定；电确实到达一个位置；合束后输出的光跟着变化。
- **构图示例**：
```text
┌──────────────────┐
│           C↑ 输出 │  输出线宽、亮度能在手机看清
│          ╱ ╲      │
│   C上臂│   │C下臂│
│       │ ◉ │  G↑  │  金色电驱动作用于一臂相位段
│       │   │  G↑  │  合束区形体是画面视觉中心
│        ╲_╱        │
│          C↑       │
│      恒定输入光     │
└──────────────────┘
```
- **屏幕位置锁定**：输入段 C 中心约 (0.48,0.78)，分光 (0.48,0.65)；双臂 (0.38/0.59,0.48)，电极活跃点 (0.71,0.51)，合束 (0.49,0.34)，输出 (0.49,0.19)。最终以实例场景的投影坐标微调，但**同框同时可见输入、驱动、输出**。K 全程锁定，屏幕平移 **≤5 px**，无缩放。核心装置约占画面宽 **≥65%**。
- **因果帧锁（可按视觉通路调整至 ±2 帧，事件先后不能颠倒）**：
  - f090–095 输入光恒亮，出口尚未呈现消息图样；电码前沿即将碰到驱动段。
  - **f096 电的第 1 位到达作用区**，f099–101 合束端输出响应；从电极到出口必须有**可见先后 3–5 帧**（仅慢动作导演用的时序提示，不是器件真实延迟）。
  - 8 位电码起始帧依次 **[096,108,120,132,144,156,168,180]**，每位约 12 帧；图样 **[1,0,1,1,0,0,1,0]**；光输出对应帧 **[100,112,124,136,148,160,172,184]**。电走到的那个位置变，输出同一信息继承亮暗；零位为较细/较暗金色驱动而不是空白。
  - f188–194 保留**至少 6 帧**观察变化后的光输出，不再引入新标签/图表。
- **主体轨迹**：G 在右侧电极持续走至作用段 (0.77,0.66)→(0.71,0.51) 并停止作为金色电的路径；C 由下方连续输入→分支→合束→顶部输出，**光不离开芯片**；相位关系用两臂中的局部纹理错位表达，但不放巨型波形面板。
- **技术实现建议**：电码状态驱动双臂相对相位 `Δφ` 的**示意**变化，输出亮暗来自合束而非金色光束“变色”；可使用两条光场纹理/相位偏移和合束亮度作可观察近景。不要用全幅曝光闪烁替代变化。
- **禁**：把 10110010 作为占半屏的大字弹出；只让青色闪而金色没有清晰路径；电光之间隔着大量空白/小标签。

### S4｜“这份消息开始上路”｜f195–269（6.50–9.00s）
**观众认知**：刚刚写上的明暗不是只在局部闪，它沿着芯片里真实的输出波导继续传播，形成释放。
- **构图示例**：
```text
┌──────────────────┐
│        C ↑ ↑ ↑    │  留出光离开画面的方向
│      ╱C输出波导    │
│     ╱             │
│    ● 合束端        │
│   ╱ ╲     G停止    │
│  C  C             │
│      C↑稳定输入     │
│                  │
└──────────────────┘
```
- **轨迹**：信息载光 C 的可见前沿：(0.48,0.38)→(0.55,0.28)→(0.65,0.15)，沿实体弯曲波导运动，**不能直线冲出空气**。K 仅温和跟随 C 的画面主方向 (0.50,0.50)→(0.52,0.44)，小幅上移/右移，画面主体不失踪；上一镜的合束端 **在 f195–218 仍可辨认**，从局部到外部线路要有地理连续性。
- **帧锁**：f195 用输出线/合束端作同位切；f210 见明暗沿上方连续传递；f235 消息行进到弯折；f255–269 镜头减速但**消息仍向前**，以传播动作结束，不勾选、不“大功告成”字卡、不飞到远处 GPU B。
- **禁**：最后一秒仅定格面板、闪屏、白背景或对号。我们只交待“数据已被写入光”，还未“抵达”。

## 2. 剪辑 / 声音 / 材质锁
- S1→S2 **同一分光结构位置匹配**；S2→S3 **同一作用点接动作**；S3→S4 **合束出口方向匹配**。所有切点前后裁切图及 6 帧邻域都需输出做对比。
- 在 9 秒内**不出现任何 PPT 面板、8 格悬浮大 UI、频谱/曲线图、滚动长字幕**。零文字静音版为主，需科学角注放 README 而不是小屏左上角。
- 允许机房环境低频声的极弱延续、金脉冲到达时短促干净的轻击以及输出成型时新的清脆节拍；**不能靠音效挽救看不懂的画面**。先出静音预演，无须正式配音。
- 材质精修、Cycles 提样、贵重云 GPU 全部暂缓。新建一个物理相连的 3D 调制器灰模+最小必要局部发光，比沿用三张漂亮但不相关的背景图更重要。
