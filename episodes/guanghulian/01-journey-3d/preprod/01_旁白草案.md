## 拆题（找这一集要讲透的机制和反转）
标题：一个比特的旅程：从 GPU 到 GPU。

| 四问 | 答案 | 对应镜头 |
|---|---|---|
| 为什么不（一直用电传）？ | 电信号跑得越快、路越长就越模糊，0 和 1 分不清 | S04 |
| 不，意味着什么？ | 要么路上加「检修站」（DSP，耗电），要么把电的路缩短 | S05 |
| 如果换成光，会怎样？ | 激光器给光，调制器把 0 和 1 写上去；光在光纤里损耗小、传得远 | S06、S08 |
| 换成光，又意味着什么？ | 多了两道新难题：电光转换、精密对接 | S06、S07、S10 |

- 「原来是这样」：不是因为光跑得更快，是电的路走不远。
- 「原来还可以这样」：一个比特从 GPU 到 GPU 是一场接力：电 → 光 → 电，抵达就是把出发反着做一遍。
- 结尾回扣标题：一个比特的旅程 = 电与光的接力。

## 和原稿不一样的地方（都要你点头）
1. **比喻**：原稿用「卡车 + 公路 + 高铁」，系列 skill 定的大框架是「寄快递」（2026-11-07）。样稿两个都没展开，只留了站名自带的说法：「检修站」「换乘」「进站」。原因：画面是写实硬件，再叠一层卡车或快递，容易让人把数据当成真的在搬运的东西（任务书第 3 节）。要不要在开头或结尾点一句「寄快递」，请你定。
2. **原稿第二站的一句没进旁白**：「或者把整理工作交给别的位置去做」。样稿只说了「缩短这段电的路」。要补可以加在 n18 后面，约多 2 秒。
3. **原稿没有、样稿新增的**：n37「每条通道，每秒上千亿次」；n25「宽不到半微米」（原稿只说「更细」）。
4. **没讲「从投资角度」**，片尾不放免责声明以外的投资内容（按 2026-11-07 的决定）。
5. **「跑得快」一个词两个意思：第二轮已按外部审阅改了，仍请你确认**。n14、n35 原来的「跑得越快」指数据速率，已改成「数据发得越快」；n29「不是因为光跑得更快」指传播速度，没动。这样两种「快」在片中不再用同一个说法。原稿用的是「跑得越快」，如果你要保留原话，请告诉我。
6. **上一版的「备选 B」（第一句说光并不比铜线里的电信号快）已撤掉**：科学审查认为它踩「不说一样快」，事实也不稳（光纤里约 0.68 c，电路板走线约 0.54 c，铜缆约 0.6–0.8 c，谁快要看具体的线）。
7. **画面和旁白都没有把数据画成小球**：电路板和光纤上画的是沿线分布的亮暗（电压 / 光强），芯片内部画的是导线整体随时间亮暗，「排成一列」用时序示意图表达（见分镜 S03 和科学审查表第 7 条）。
