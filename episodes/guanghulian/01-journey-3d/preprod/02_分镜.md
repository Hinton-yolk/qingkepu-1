# 02 逐镜头分镜（v0.3，待用户确认；第二轮按 PR #3 的 P0–P2 修订了 S01、S03、S04）

- 时间、标注文字、状态以 `timeline/timeline.json` 为准；本文件写导演意图：每个镜头为什么存在、怎么拍、哪些是真实结构、哪些是示意。
- 规格：1080×1920，30 fps，149 秒，4470 帧。
- 每个镜头里的东西分三类，画面上要分得开：
  - **〔实〕真实硬件结构**：按真实尺寸和结构建模，写实材质；
  - **〔示〕简化科学示意**：结构或数量做了简化，屏幕角注写明；
  - **〔喻〕视觉隐喻**：只有站名（检修站、换乘、进站）和路径线，不建模成实体。
- 颜色语义全片不变：**金 = 电信号，青 = 光，珊瑚 = 出错 / 强调**。硬件本身不用这三种颜色发光：跳线用真实的黄色护套，指示灯用绿色。
- 镜头之间尽量不切：下一个镜头的首帧和上一个镜头的尾帧共享「位置 + 运动方向」。全片只有 4 处允许用 1 帧暗场遮一下尺度跳变（S02→S03、S03→S04、S08→S09、S09 内部进 GPU B）。
- 数据不画成小球。怎么画取决于画面有多大（一个符号在电路板上长约 3 mm，在光纤里约 3.8 mm，在硅波导里约 1.3 mm）：
  - **厘米级视野**（S04 的走线、S05 的模块）：画沿线分布的亮暗，按真实的符号长度成比例排（10 cm 走线上约 33 个符号）；
  - **微米到百微米视野**（S03 芯片内、S06 调制器特写、S07 对接）：一个符号比整个画面还长，所以整段线 / 整段光一起随时间亮暗，不画条纹；
  - **机房尺度**（S01、S08 后段、S10）：按真实比例根本分辨不出（30 m 线槽里约 7800 个符号），画成示意图样并加注「示意，未按比例」。

## 尺度旅行总览
```
S01  机房 30 m ─→ 机柜 2 m ─→ 服务器 0.5 m
S02  GPU 模组 0.3 m ─→ 封装 7 cm ─→ 芯片 3 cm ─→ 连线层 50 µm
S03  串化电路 5 µm ─→ 微凸点（直径约 25 µm，间距约 45 µm，示意）
S04  电路板走线 2 mm ─→ 10 cm
S05  光模块 9 cm ─→ DSP 5 mm
S06  硅光芯片 5 mm（调制器的两条相移臂是毫米级）─→ 特写视野约 100 µm
S07  波导 0.4 µm ─→ 纤芯约 8–9 µm ─→ 光纤 125 µm
S08  光纤 ─→ 线槽 ─→ 机房 30 m
S09  接收端模块 ─→ 探测器 20 µm ─→ GPU B 芯片内
S10  GPU B ─→ 机房 30 m（回到第一帧的机位）
```

## S01 数据中心 → 机柜 → 服务器（0–13 秒）
- **为什么要这个镜头**：建立「GPU A 在这里，GPU B 在走廊对面」，并且在头 3 秒就让人看到谜题和答案的轮廓：一条路，先电、再光、再电。
- **画面**
  - 〔实〕冷通道：两排机柜面对面，架空地板的通风格栅，柜顶上方的线槽里是成捆的黄色护套跳线（单模，多芯的 MPO 跳线），顶灯是一条条的灯带。
  - 〔实，示例〕机柜里是 8 颗 GPU 一台的风冷 AI 服务器。正面（冷通道一侧）是风扇墙；**网络光口在机箱后部**（参考机型的做法，见 `08_代表性硬件路径与五站映射.md`；这是推荐方案，没有经用户确认）。
  - 〔喻〕路线：0.3–3.0 秒亮出来。金色从 GPU A 出发，在机箱里先到中部的网卡，再沿内部铜缆到后面板的光口；青色从光口出来，在机柜背面上到线槽，沿线槽过桥到对面，下到 B 柜的后面板；再一段金色经过网卡到 GPU B。3D 里的发光管有的段被机柜挡住，Remotion 沿同一条路线的取样点把整条线补成虚线，并在三段上标「电」「光」「电」。
- **镜头**：冷通道一点透视起步，第 0 帧就在推，比上一版快；4.5 秒起转向机柜 A；7–8.5 秒柜门、上方设备和上盖透明化；8.5–13 秒压到 GPU A 上方，这一段看得到金线从 GPU A 往机箱后方走：先到机箱中部的网卡，再沿一段内部铜缆到后面板的光口。
- **和上一版的差别**：路线从 1.5–7.5 秒提前到 0.3–3.0 秒；开场的通道漫游从 7 秒缩到 4.5 秒；光口从正面改到后部，路线里加了网卡；金色段不再只藏在机箱里。
- **开头检查**：见本文末尾对照表第一行。第一个真正的机制演示仍然在 23 秒以后，这一点没有变。
- **角注**：路线已简化：省去中间的交换机；金 = 电、青 = 光，颜色为示意；服务器结构为示例。
- **转到 S02**：不切。相机继续朝 GPU A 压下去；13.0 秒两边的机位、朝向、速度一致，机箱里的灯光在 11–13 秒过渡成 S02 的灯。金线在 S02 开头还在，13.3–14.8 秒淡出。
- **待你定**：参考机型和光口位置（`08` 第六节）；开头用哪个版本（`01_旁白草案.md`）。

## S02 贴近 GPU 封装 → 进入芯片（13–23 秒）
- **为什么**：从厘米到微米，让观众知道「我们钻进芯片里了」。
- **画面**
  - 〔实〕GPU 模组：散热器（鳍片 + 均热板）升起并淡出，露出封装：基板、金属加强环、中间一颗大芯片、两侧各 4 颗存储芯片（HBM），四周是电感、电容和供电芯片。
  - 〔示〕封装的具体排布是示例，不对应某一款产品；不出现任何厂商标志。
  - 〔示〕穿过硅背面之后的金属连线层：硅和层间绝缘层透明化，连线层数和线宽做了简化（见 S03）。
- **镜头**：对数匀速推进，约 2.5 秒一个十倍；落点是大芯片靠边的位置（串化电路通常放在芯片边缘一带）。18.5 秒穿过芯片背面。
- **3D 尺度字**：大芯片上方「约 3 cm」+ 双箭头，放在场景里。
- **角注**：硅和绝缘层已透明化；连线为简化示意。
- **转到 S03**：穿过硅的那一下用 1 帧暗场，前后运动方向一致。

## S03 SerDes：并排 → 一列（23–39 秒）· 第一站 出发
- **为什么**：第一站的机制：一大排并行数据，被排成一列，变成一条高速电信号。
- **画面**
  - 〔示〕一束并排的金属线（画 32 条，代表「一大排」）从远处的逻辑区伸过来，每条线整体亮或暗，慢慢地一起换一次状态（一排同时到）。
  - 〔示〕并行线汇进一块串化电路（多级二选一的树形结构，画成 32 → 16 → 8 → 4 → 2 → 1）。
  - 〔示〕出来只剩一路信号，节拍是并行线的 32 倍。
  - 〔实，画法为示意〕**输出驱动把这一路信号变成一对互补的线（差分）**：一根电压高的时候另一根低，接收端只看两者之差。这一对线往下穿过两串通孔，到芯片朝下那一面的一对微凸点（倒装芯片：我们是从硅背面钻进来的，连线层和凸点都在更下面）。
  - **叠加的时序示意图（Remotion）**：上半「并行：一拍换一排」，下半「串行：一拍一个」。横轴写明是时间。「排成一列」由这张图讲，不靠在导线上画一串小球。
- **这颗串化电路是谁的**：片中画的是 GPU 自己的高速接口（示例架构里它通向网卡）。真正驱动光模块的那一次串化在网卡芯片里，节拍更快；片中不进网卡，用一条角注和一个标签交代（S03 33.6 秒、S04 41.5 秒）。详见 `08` 第四节。
- **镜头**：先沿并行线平移到串化电路上方，然后停住（讲工序时相机不动，变的是信号）；35.5 秒起跟着那一对差分线**一直往下**，穿过微凸点离开芯片。不绕圈，方位角变化很小。
- **角注**：亮 / 暗 = 1 / 0（真实每条通道每秒约 320 亿个，这里慢放了几十亿倍）；这里画的是 GPU 自己的高速接口，一共 16 条这样的通道，到了网卡数据重新打包、再排一次队（示例架构）；凸点周围的连线和地凸点已省略，芯片到电路板之间还有中介层、基板、焊球，这里略过。
- **标注**：35.8 秒「一路信号，两根线送：电压一正一反（差分，示意）」。真实电路里信号不一定到输出驱动才一分为二，这里是简化。
- **这一段的真实速率**：GPU 自己的接口每条通道约 320 亿比特每秒、两级电平（示例架构，见 `08`）。所以 S03 画两级不是示意，是实情；「上千亿、四级」是网卡之后的事。
- **转到 S04**：跟着这一对差分线继续往下。真实的叠层是：芯片 → 微凸点（间距 40 µm 上下，片中画 45 µm）→ 硅中介层（再布线层 + 硅通孔）→ C4 凸点（约 130 µm）→ 有机基板 → 焊球（约 1 mm）→ 电路板。片中只展示到微凸点和中介层表面，后面几级用 1 帧暗场带过，落到电路板上的**同一对**差分走线。这样 S03 的「一路」到 S04 的「两根线」是在画面里交代过的，不是凭空变出来的。
- **待你定**：串化电路画成多级二选一树可以吗（Q7）；串化画在 GPU 芯片上、网卡只用角注交代，可以吗（Q2）。

## S04 电的路：电路板差分走线（39–55 秒）· 第二站
- **为什么**：电的路的问题：数据发得越快、路越长，信号越模糊。
- **顺序（第二轮按调研改了）**：板上走线 → 路过网卡 → 内部铜缆 → 后部光口。**模糊的演示放在网卡之后的铜缆上**：片中接下来由光模块里的 DSP 整理的，是网卡发出来的这一段信号；网卡之前那一段的模糊，实际由板上的重定时芯片和网卡的接收端先整理过，片中不展开。
- **画面**
  - 〔实〕电路板表层：从 GPU 封装出来的一对差分走线（两条并行的铜线）、阻焊层、过孔。真实布线没有依据之前，板面用素的阻焊色，不画程序条纹，也不画没有来源的元件。
  - 〔示〕走线上的亮暗图样：金色，两根线互补，沿线分布。网卡之前那段板上走线按比例排（每个比特在板上长约 5 mm，见 FACTS）；**网卡之后铜缆上的图样是示意，未按比例**（铜缆的长度和信号速度没查到）。
  - 〔实，示例〕**路过网卡芯片**（41.5 秒，在机箱中部，不进去）：数据在这里重新打包，换成更快的节拍，再发出去。
  - 〔实，示例〕网卡之后是一段内部铜缆，通到机箱后部的光口笼子（44 秒起）。在这一段上，图样离网卡近的一端亮暗分明，越往后越糊、对比越低。旁白 n13 说的「走线或铜缆」各有对应的画面。
  - **叠加（Remotion）**：两条波形，「出发时」方正、「到达时」圆钝；到 48 秒眼图合上，判决门限附近标珊瑚色「0 还是 1？」。44 秒给术语「损耗 + 失真（前后符号互相拖尾）」。
- **镜头**：贴着走线低空跟拍（相机速度和图样速度不同，图样相对画面仍在前进）；路过网卡后沿铜缆继续，后段拉高，看到后部的光口笼子。
- **角注**：亮暗 = 电压高低，波形和铜缆上的图样都是示意（慢放约十亿倍）；网卡之后实际是四级（PAM4），这里画两级。
- **转到 S05**：跟着铜缆进笼子，穿过模块的金手指。
- **这一轮没有建这个镜头的场景**，只改了文字和时间轴。

## S05 检修站：光模块里的 DSP（55–68 秒）· 第二站
- **为什么**：模糊了怎么办：常见方案是在模块里放一颗 DSP 重新判决和整理。它耗电，这是后面很多新技术的出发点。
- **画面**
  - 〔实〕可插拔光模块内部：电路板、金手指、DSP 芯片、驱动器、硅光芯片、激光器、光纤阵列、对外的光口。外壳透明化。
  - 〔示〕DSP 内部不展示。它左边进来的波形是糊的，右边出去的是整齐的。
- **镜头**：停在 DSP 上方不动，变的是两侧的波形（Remotion 叠加，锚在 3D 位置上）。
- **角注**：以含 DSP 的可插拔光模块为例；也有不带 DSP 的方案（如线性直驱 LPO）。这条角注从 55.3 秒挂到镜头结束，保证不把 DSP 说成必经器件。
- **转到 S06**：跟着整理好的电信号从 DSP 走到驱动器。

## S06 换乘：激光器、驱动器、调制器（68–88 秒）· 第三站
- **为什么**：全片最重要的机制：电信号里的 0 和 1 是怎么写到光上的。三个器件各干什么、谁推谁。
- **画面**
  - 〔实〕硅光芯片表面：稀疏的波导、马赫-曾德尔调制器（光分成两路、走两条毫米级的并行长臂、再合成一路，臂上是长条金属电极）、芯片边缘的模斑转换器。这一集不讲干涉，但模型要看得出「分两路再合起来」。
  - 〔实〕激光器是单独的一颗芯片（磷化铟），贴在硅光芯片旁边把光送进波导，不画成从硅芯片上长出来的；驱动器也是单独的芯片。
  - 〔示〕三步，每步只动一样东西：
    1. 激光器亮起，一条均匀的青色光带沿波导走到调制器（稳定的连续光，没有明暗）；
    2. 驱动器把进来的小幅电信号放大（金色，幅度变大），送到调制器电极；
    3. 调制器出口的光带开始跟着电极上的电信号一明一暗。「暗」不是全灭：按标准的消光比下限，「暗」大约是「亮」的四成多，画面里暗的时候仍然有光。
  - **叠加（Remotion）**：上金下青两条波形对齐，证明「光强跟着电信号走」。
- **镜头**：先给一个能看全三个器件的机位，再推到调制器后停住。
- **角注**：以硅光模块为例；光是红外光，看不见，青色为示意；明暗画成两级，实际常用四级（PAM4）。
- **待你定**（见科学审查表第 3、5 条）：
  - 调制器内部要不要展示「分成两路再合起来、相位差决定明暗」（马赫-曾德尔干涉）？样稿只画到「电极加电，出口变明暗」。展示的话要多 6–8 秒。
  - 明暗画两级还是四级。
- **转到 S07**：跟着已调制的光沿波导走向芯片边缘。

## S07 光的路：波导与光纤对接（88–106 秒）· 第四站
- **为什么**：光的路的难点不在路上，在进出站的对接。
- **画面**
  - 〔实〕芯片边缘：硅波导（宽 0.4 µm）、模斑转换器、V 形槽里的光纤（包层 125 µm，纤芯 8.2 µm，模场直径 9.2 µm，屏幕字统一写「约 8–9 µm」）。尺寸按真实比例。
  - 〔示〕模斑转换器只画外形和「光斑由小变大」，内部结构不画。
  - 〔示〕对接演示（装配偏差演示），相机停住：对准时青色光绝大部分进入光纤（真实对接对准时也有零点几分贝的损耗，读数显示的是「相对对准时」的比例）；光纤横向偏 2 µm，一部分光打在包层上散掉（珊瑚色边缘标出漏掉的部分）；偏到 5 µm 只剩约三成；再回到对准。
  - 比例物：一根头发丝横在光纤旁边。
  - **叠加（Remotion）**：「进光纤的光」读数跟着偏移量变。
- **3D 尺度字**：「波导 不到 0.5 µm」「纤芯 约 8–9 µm」「头发 约 70–80 µm」。
- **角注**：模斑转换器为示意；偏移损耗按高斯模场估算。
- **辉光规则**：光约束在芯区，只画很淡的倏逝尾；偏移时漏掉的光要画成确实离开了波导和纤芯。
- **转到 S08**：光进入纤芯，镜头跟进去。

## S08 光的路：沿光纤传播（106–117 秒）· 第四站
- **为什么**：光的路本身好走：损耗小、传得远。同时把最容易误解的一点说破：不是因为光更快。
- **画面**
  - 〔实〕光纤 → 黄色跳线 → 机柜顶的线槽 → 整排机柜。
  - 〔示〕纤芯里的青色亮暗图样沿光纤前进，一路不变糊（和 S04 的走线形成对照）。镜头拉远以后图样只是示意，未按比例，加角注。
- **镜头**：一个连续镜头，在对数刻度上拉远，约 2 秒一个十倍，最后 1.5 秒减速落到机柜 B 上方。
- **转到 S09**：沿线槽落到机柜 B，推进接收端模块。尺度跳变用 1 帧暗场。

## S09 抵达：探测、放大、恢复、解串（117–132 秒）· 第五站
- **为什么**：抵达 = 把出发时做的事反着做一遍。构图和 S06、S03 成镜像，让观众自己看出「反着来」。
- **画面**
  - 〔实 / 示〕接收端硅光芯片上的光电探测器：青色光带进去，出来是很弱的金色电流（亮度明显比 S04 的低）。
  - 〔示〕跨阻放大器把微弱的电流变成够大的电压（金色变亮）；DSP 把 0 和 1 认清。
