# 05 制作依赖、分工和渲染路线（v0.1）

## 一、五种职责和文件所有权
任务书的五种职责和仓库 `CLAUDE.md` 的四个角色并行，对应关系如下。一个文件只归一种职责改；别人发现问题写在审查记录里，不直接动手。

| 职责 | 谁来做 | 只改这些文件 | 对应仓库角色 |
|---|---|---|---|
| Director（导演） | 主 agent | `timeline/timeline.json`、`preprod/01_旁白草案.md`、`preprod/02_分镜.md`、`README.md` | 主 agent |
| Science Reviewer（科学审查） | 独立子 agent，用最强模型，只挑错不改片 | 只写 `preprod/03_科学审查表.md` 的「审查记录」和状态列；`FACTS.md` 由主 agent 按审查结论改 | 审核 |
| Blender Artist（3D） | 主 agent + 子 agent（每个镜头一个文件，互不交叉） | `blender/` | — |
| Motion Designer（动效与合成） | 子 agent | `remotion/` | — |
| Render / QA（渲染与质检） | 主 agent 负责执行渲染、跑自动检查、出测试报告；**「通过」不由主 agent 自己签**，由独立的审核 agent 看报告和画面后签 | `timeline/validate.py`、`previews/`、渲染日志 | 执行归主 agent，签字归审核 |
| 监督 | 独立子 agent（日常用 Sonnet） | `../要求清单_3D与Blender.md` | 监督 |
| 观众 | Codex（要你登录） | 不改文件 | 观众 |

主 agent 负责任务依赖、阶段验收，以及所有提交。

## 二、依赖关系
```
原稿 ──→ 旁白草案 ──→ 【你确认】 ──→ 正式配音（Fish Audio）──→ 按配音重排时间轴
            │
            ▼
        timeline.json ──→ Blender 各镜头脚本（读镜头起止帧）
            │                    │
            │                    ├─→ 低清静帧 / 预演帧 ──→ Animatic
            │                    └─→ 高质量代表帧 ──→ 【你确认材质、灯光、构图】──→ Cycles 序列帧
            ▼
        Remotion（读同一份 JSON：字幕、标注、波形、五站条）
            │
            └─→ 叠在 Blender 序列帧上 ──→ 合成 ──→ 质检 ──→ 四个角色 ──→ 【你判断成片】

FACTS.md ──→ 科学审查 ──→ 标注文字、角注（改动回到 timeline.json）
```
- **唯一的时间来源是 `timeline/timeline.json`**。Blender 和 Remotion 都读它，不各自写死时间。
- Blender 每个镜头输出两样东西：图像序列，以及一份 `anchors_Sxx.json`（每帧里要挂标注的 3D 点投影到屏幕的坐标），Remotion 用它把标签贴在物体旁边。
- Remotion 不重画 Blender 已经做的写实模型；它只画波形、时序图、读数、字幕、五站条、角注、片尾卡。

## 四、渲染路线

| 机器 | 能做什么 | 实测 |
|---|---|---|
| 本次会话的云端容器 | 写场景、跑低清静帧、Remotion 预览和合成 | 4 核 CPU，没有显卡。Cycles CPU 可用；EEVEE 不可用（缺 libEGL）。只适合 270×480 一类的小图 |
| AutoDL（任务书指定） | Cycles / OptiX 渲最终序列帧 | **SSH 连不上**：这个容器的出口只放行 HTTPS，22 端口被拒（本次会话再次实测）。可行的办法见下 |
| RunPod | 同上 | 这个环境已经接了 RunPod 的接口，实测能通（只读查询，账号下目前没有实例）。可以全程走 HTTPS |
| 你的 Windows + RTX 2060 | EEVEE 每帧约 2 秒，Cycles 约 30 秒 | 以前的渲染包做法，仍然可用 |

**连 AutoDL 的三种办法（请选）**
1. 走 JupyterLab：你把实例的 JupyterLab 域名发来，访问令牌通过安全表单填（不要贴在聊天里）。我用它的终端接口装 Blender、验证 CUDA / OptiX、试渲 5 帧。需要把这个域名加进环境的网络白名单。
2. 改用 RunPod：接口已经通了，我可以直接开机、渲染、关机，日志和耗时都能留。按小时计费，开机前我会先报预计费用，等你同意。
3. 渲染包：我出一个 `render_autodl.sh`，你在 AutoDL 的终端里运行，渲完把结果打包传回网盘。

**费用规矩**：没有你的明确同意，不开任何计费实例。每次开机前报：机型、单价、预计时长、预计总价。先试渲 5 帧量出每帧耗时，再估整片。

**先粗估一下量级**（假设，等试渲后更正）：全片 4470 帧；如果 Cycles 在 RTX 4090 上每帧 20–40 秒，整片约 25–50 机时。这只是量级，材质和采样定下来之前不准。
