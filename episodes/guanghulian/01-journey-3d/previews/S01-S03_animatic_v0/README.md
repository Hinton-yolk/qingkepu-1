# S01–S03 低清动态预演 v0：可在仓库里浏览的版本

这是 0–39 秒预演的**抽帧**，给拿不到视频文件的审阅者看。它是粗模预演，不是 Animatic，更不是成片；画面底部那条「预演 v0 · 粗模」是烧进视频的标注。

## 为什么不是视频链接
- 仓库规则：mp4 不进仓库（`CLAUDE.md`「仓库结构」、`.gitignore`）。Issue #2 也要求不要把大 MP4 放进普通 Git。
- 制作环境里没有创建 GitHub Release 或上传附件的工具，所以**视频文件目前无法由 ChatGPT 独立获取**。
- 视频文件已经在 Claude 会话里交给用户。用户如果把它拖进 PR 评论或传成 Release 附件，就有了可访问的地址；用下面的 sha256 核对是不是同一个文件。

## 看图时要知道的限制
- 抽帧是从 540×960 的视频缩小的，字比手机上实际看到的更小；标注的可读性要以 1080×1920 的单帧为准（还没出）。
- 看不出运动的快慢和是否眩晕，只能看出每 0.1 秒的位移。
- 审核和监督看的是同一个视频；观众（Codex）没有看过。
- 已知问题列在 `../../README.md`「粗模的已知问题」；Issue #2 列的七条优先修正都还没修，对照表在 `../../preprod/06_阶段A交接与检查记录.md` 第四节。
