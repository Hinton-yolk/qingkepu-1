# T6-Story《下一颗 GPU，还在等》· 七幕镜头表（主 agent，2026-11-13）

对应 PR #3 第 35 条评论 T6-Story；用户在会话里说了「立即开始」。约 37 秒，540×960，30 fps，动态故事板（Animatic）。
**不继承 T5 的运镜**：不旋转、不俯冲、不穿模、不白闪、不长时间高速推进。只用缓慢平移 / 轻推（每秒画面缩放 ≤ 4%）和有动机的剪辑。
做法：T5 已渲出的 3D 帧当「底板」（静帧），上面叠 2D 动画图层讲因果。没有新的付费渲染。

## 主角：这份结果
- 身份：八位 **1 0 1 1 0 0 1 0**，画成一枚小「结果徽章」（八个小方格横排、圆角胶囊底）。亮格 = 1，暗格 = 0。
- 宏观镜头（第 1、2、3、6、7 幕）：徽章跟着信号走，始终在画面里、位置连续，观众知道「还是它」。
- 微观镜头（第 4、5 幕）：信号本身按 1 0 1 1 0 0 1 0 一亮一暗（亮 = 1，暗 = 0）；徽章在画面角落小尺寸保留。
- 金色 = 电；青色 = 光（颜色为示意）。全片映射不反转。

## 字
- 两版都有：第 1 幕 0–3 s 大字「这一边算完了 / 另一边，还在等」（第 0 帧就完全可见）；A / B 标签；第 4 幕三个贴物短标签「光：一直亮着」「电信号」「输出：跟着变」（各约 1.5–2 s）；第 5 幕「偏一点，就进不去」；第 7 幕「✓ 送到了」。
- 试听版另加底部字幕（就是 PR 里的七句占位口播，可以少用）。没有配音。
- 角注最多一条、只在需要的幕出现（第 3、4、5 幕），不常驻。

## 自检要点（做完以后看片）
1. 第 0–2 秒读不读得出「一个芯片算完了」；第 2–4 秒认不认得出「另一个在等」。
2. 每次转场能不能不猜就知道到了哪里、多大尺度。
3. 第 4 幕：静音时能不能说出「光一直在，电让它一亮一暗」。
4. 结尾徽章和开头是不是一眼对上。
5. 有没有让人晕的镜头运动（缩放 / 平移速度、方向突变）。
