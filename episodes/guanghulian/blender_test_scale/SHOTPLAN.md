# 测试镜头三：「光在芯片里走的路有多细？」· 分镜（2026-11-10，第二版）

- **用户定**：
  - 「反过来推进」：从交换机开场，一路推进到 0.5 µm 的波导；
  - 模块那一级的比例物用「一部手机」。
- **按审核改**：
  - 端面耦合；
  - µm 尺度的光画成连续光带；
  - 大物体在镜头穿过前透明化；
  - 景深随尺度变；
  - 补全 FACTS。
- **规格**：竖屏 1080×1920，30 fps，18 秒（540 帧），EEVEE。先在 RTX 2060 上试渲 3–5 帧确认速度，目标整段 30 分钟以内。
- **依据**：`CLAUDE.md`「3D 镜头语法」、`research/参考片实测_录屏四部.md` §1。

## 一个连续镜头，对数匀速推进
- 画面宽度从约 0.6 m 推进到约 3 µm，约 5.3 个十倍。
- 时间分配：
  - 0–2 秒基本停住，让人读大字问题；
  - 2–16 秒推进，平均约 2.6 秒一个十倍；
  - 16–18 秒停在波导上，出结尾一句。
- 相机俯视约 35°，缓慢绕转。

## 合成（云端）
- **第一帧**：大字问题「光在芯片里走的路有多细？」，放在画面上部，不压住交换机。
- **结尾一句**：「比头发细约 200 倍的路，就藏在每个插口里」（头发约 0.1 mm ÷ 0.5 µm = 200）。
- **角标**：右上系列名，左上「芯片与光 · 尺度」。
- **角注**：轮流出现，放在下方安全区，不和角标挤：
  - 「红外光，颜色为示意」
  - 「外壳 / 上层氧化硅已透明化」
  - 「慢放」
  - 「芯片和模块内部为示例」

## 画面规则
- 青色只给光，金色给电极和焊盘。底色先试深蓝，色相要和青色拉开（用 `tools/frame_stats.py` 看主色），样片后由用户定。
- 光纤跳线护套用中性灰。红细胞用低饱和的暗红，不要像珊瑚色（珊瑚 = 强调 / 出错）。
- 景深：宏观段光圈小（景深深，不像玩具模型），越往微观光圈越大。
- 物体进出：
  - 推进时，大物体在相机穿过前淡出（透明化）；
  - 小物体在进入画面前淡入，不「啪」地出现。
- 层级往下走时用同一个动作：外壳每次都「透明化 + 镜头穿进去」。

## 技术要点
- **缩放**：相机不动，整个世界围绕焦点逐帧缩放，并逐帧打关键帧（不靠 Blender 的线性插值）。
- **焦点**：焦点随层级移动时，平移量按当时的画面宽度换算，避免抖动。
- **灯光**：挂在相机组下面，不随世界缩放。
- **渲染包**：沿用 Windows 包（find_blender.cmd + bat），默认 `--eevee`，输出 `scale.mp4` 和 `anchors.json`。
