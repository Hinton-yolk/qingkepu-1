## 1. Style Bible

### 1.1 总体构思：两个舞台 〔原〕
- **纸桌（浅色，宏观与讲解）**：沿用系列已有的纸桌。
  - 放实物照片感的硬件、原文纸条、快递路线图、读数。
  - 负责「这是什么、在哪、为什么」。
- **视场（深色，微观与光）**：一个圆形「显微镜 / 放大镜视场」在纸桌上打开，里面是深色背景。
  - 放电场、光、信号、截面。
  - 负责「里面怎么发生的」。
- **为什么这样分**：
  - 光和发光信号必须在暗背景上才看得清、才不显得假。
  - 纸桌保留了系列识别度和「纸条一拍」的阅读节奏。
  - 系列 03 / 04 里已经用过放大镜，观众有基础。
- **来源**：〔观〕BE-制造的工艺讲解在暗底上做；〔观〕MK 用浅景深的「微距摄影」感区分尺度。两个舞台的组合本身是〔原〕。

### 1.2 色板（语义固定，全系列不改）〔原〕

| 用途 | 名称 | 色值 | 规则 |
|---|---|---|---|
| 纸桌底 | 纸 | `#EFE9DC`（渐变到 `#E2DACB`） | 只用于宏观舞台 |
| 视场底 | 墨夜 | `#121318`（四角压到 `#0B0C10`） | 只用于微观舞台，不用纯黑 |
| 正文字、描边 | 墨 | `#1B1B1A` | 纸桌上的字和线 |
| 暗底上的字 | 米白 | `#F4EFE4` | 视场内的字和比特 |
| **电 / 电子 / 电压** | 金 | `#F2B33D` | 只要是电信号就用金色 |
| **光 / 光子 / 光强** | 青 | `#3FD0C0`（高亮 `#9BE8DB`） | 只要是光就用青色 |
| **错误 / 损耗 / 强调** | 珊瑚红 | `#E5483F` | 一屏最多一处 |
| 正确 / 通过 | 松绿 | `#2F9E63` | 只用于勾 |
| 材料：硅 | 灰蓝 | `#8A93A6` | 截面图 |
| 材料：二氧化硅 / 玻璃 | 半透明白 | `rgba(244,239,228,.35)` | 截面图、光纤包层 |
| 材料：铜 | 铜 | `#C77D3A` | 走线、互连 |
| 材料：InP（激光芯片） | 紫灰 | `#6E6A86` | 激光器 |
| 光刻胶 | 紫 | `#8E6CC4` | 工艺图（约定色，角注「示意色」） |

- 〔观〕颜色按功能编码、全片不改，是 BE-制造 防迷路的核心手段（旁白 10:08 明说颜色编码是为了「不迷路」）。
- 〔原〕**红外光的颜色规则**：通信用的 1310 / 1550 nm 是人眼看不见的红外光。青色只是约定色，**每集第一次出现光时角注「红外光，颜色为示意」**。不用彩虹色表示不同波长，除非这一集专门讲波分复用（那时用青到蓝紫的冷色阶，并标 nm）。

### 1.3 字体与层级（竖屏 1080×1920）〔原〕

| 层级 | 字体 | 字号 | 用途 |
|---|---|---|---|
| 大字问题 / 封面 | 思源黑体 Black（Noto Sans SC 900） | 96–128 | 每集开头一次、结尾一次 |
| 镜头标签 | 思源黑体 Heavy（800） | 40–48 | 贴在实物旁，≤ 10 字 |
| 读数 / 单位 | IBM Plex Mono 或 JetBrains Mono（等宽，数字对齐） | 36–44 | 「25 Gb/s」「−4 dB」「0.5 µm」 |
| 角注（示意、比例说明） | 思源黑体 Medium（500） | 26–30，60% 透明度 | 右下或左下角，≤ 16 字 |
| 字幕 | 思源黑体 Heavy | 50 | 见 1.8 |

- 一屏同时最多 **3 个标签**；标签出现用打字或从中心弹出（0.2 秒），不从屏幕外飞入。
- 数字和单位之间加空格（`25 Gb/s`），单位用国际写法。

### 1.4 背景 〔原〕
- 纸桌：纸纹 + 极淡的网格（等距网格只在需要空间感时出现）；台灯光池缓慢呼吸（亮度变化 ≤ 4%），保证画面不死。
- 视场：深色 + 中心略亮的径向渐变；**不放任何装饰粒子**；需要空间感时用一条很淡的参考线或刻度。

### 1.5 线条 / 描边 〔原〕
- 三档线宽：3 px（辅助线、尺寸线）、6 px（结构轮廓、信号波形）、10 px（强调圈、主光路）。
- **实线 = 真实存在的东西**（导线、光纤、器件边界）；**虚线 = 不可见或示意**（电场线、时间窗口、对齐线）。
- 线端圆头；转角圆角半径 = 线宽 × 1.5。

### 1.6 硬件质感 〔观〕+〔原〕
- 〔观〕MK、BE 都用写实的 PBR 材质 + 浅景深来让 CG 像「照片」。
- 〔原〕本项目取**半写实**：哑光为主，金属只在插头外壳、引脚、散热片上出现；统一布光（左上暖色主光、右后冷色轮廓光），全系列不变。
- 2D 硬件（纸桌上）：扁平 + 一层柔和投影 + 一条高光边，不做拟物细节堆砌。
- **准确性底线**：接口、引脚数、外形比例照真实器件建模（例如 DB-25 是 25 针、USB 2.0 A 型是 4 个触点）；拿不准的细节宁可省略，不编。

### 1.7 光效 〔原〕
- **发光 = 物理量**：只有光子和正在传输的信号才发光；发光强度对应功率，衰减时亮度真的要降。
- 泛光（bloom）半径 ≤ 物体宽度的 1.5 倍；一屏同时最多 2 个发光源。
- 禁止：装饰性镜头光晕、扫光、无意义粒子。粒子只代表真实的粒子（等离子体里的离子、注入的掺杂原子），每屏 ≤ 60 个，用确定性随机。

### 1.8 字幕 〔原〕（沿用系列已验证的做法）
- 深色撕边条 + 米白字，一行 ≤ 16 字。
- 位置：抖音 y = 1400，小红书 y = 1565，避开平台界面。
- 关键术语在字幕里染语义色（电 = 金、光 = 青）。
- 「纸条一拍」时不出字幕：纸条本身就是文字，避免重复。

### 1.9 镜头语言
- 〔观〕BE-制造、MK：尺度跳转靠一个贯穿的物体或路径带过去，几乎不硬切。
- 〔原〕规则：
  - **一次只做一种运动**：推、拉、横移三选一，不叠加旋转。
  - 推 = 往里 / 往下一层；拉 = 给上下文；横移 = 跟随信号。
  - 到达后**至少停 0.4 秒**再出标签。
  - 运动模糊只出现在转场的 4–6 帧里。
  - 旋转角度 ≤ 30°。

### 1.10 声音节奏
- 〔观〕BE 系列每个物理动作配一个小音效（沉积嘶声、甩胶声），音乐垫底。
- 〔原〕规则：
  - 音效只卡在**画面里的物理事件**上（光点出发、插头插入、判决），不为转场加嗖嗖声。
  - 音乐每集换调性；开头 / 讲解 / 揭晓三段换织体，揭晓前停半拍（沿用现有规则）。
  - 响度 −14 LUFS，音乐比人声低约 12 dB。
- 〔原〕**关于「AI 配音腔调」**：现在用的 Fish「科普」声线是合成音。可选三条路：
  1. 继续调 TTS：逐句控制停顿和语速，重音词加标记。
  2. 用你自己的声音做声线克隆（需要 1–2 分钟干净录音）。
  3. 直接录真人旁白。

  这个需要你决定。

## 2. 8 条动效语法（Motion Grammar）

| # | 名称 | 叙事用途 | 触发条件 | 前后镜头关系 | 时长 | 核心缓动 / 方法 | 常见失败 |
|---|---|---|---|---|---|---|---|
| 1 | **圈定 → 推入** 〔观 BE-CPU 3:07 蓝圈、MK〕 | 进入下一层尺度 | 要讲的东西在当前画面里很小 | 前镜：目标被唯一的高亮圈住；后镜：目标填满画面，且在原位置 | 圈 0.3 秒 + 停 0.4 秒 + 推 0.8–1.2 秒 | 圈：`spring(damping 14)`；推：`bezier(0.7, 0, 0.3, 1)` | 不圈就推（观众不知道要看哪）；推的终点和圈的位置不一致 |
| 2 | **跟随载体** 〔观 BE-制造 跟着晶圆、光刻跟着光束〕 | 解释信号 / 数据的路径 | 讲「从 A 到 B 经过什么」 | 同一个载体（比特、光点）贯穿前后两镜，屏幕位置连续 | 每段 1.5–4 秒 | 镜头横移用线性段 + 两端缓入缓出；载体匀速 | 中途换了载体的颜色或形状；镜头比载体快、甩丢载体 |
| 3 | **工序条 → 圆环** 〔观 BE-制造 5:41–7:15〕 | 多步骤的先后，以及重复 | 一个过程有 ≥ 3 个先后步骤 | 线性条常驻在顶部；讲到「重复」时折成圆环 | 每步 0.6–0.9 秒 + 步间停 0.2 秒；折环 0.8 秒 | 格子高亮 `spring(damping 14, stiffness 180)`；折环沿弧线插值 | 几步同时动（像同时发生）；条和画面上正在变的那一层对不上 |
| 4 | **实物 / 符号并排** 〔观 BE-CPU 8:48〕 | 把真实结构和抽象符号对上 | 第一次引入一个符号（门、波形、眼图） | 左实物、右符号（或上下），同节奏点亮 | 并排停 1.5–2.5 秒，之后可单独用符号 | 符号逐笔画出（stroke-dashoffset） | 符号先出现、实物后补；并排时两边各动各的 |
| 5 | **复制 → 阵列 → 收拢** 〔观 BE-CPU 1:37–2:00、10:48、12:53 drop-in〕 | 从一个到很多、从小到大的层级 | 「一个」变「一群」、或升一级 | 一个 → 复制成阵列（拉远）→ 上一级外壳从上方落下罩住 | 复制 1–1.5 秒；落下 0.5 秒 + 回弹 | 复制按网格依次出现（每个间隔 1–2 帧）；落下 `spring(damping 12)` | 一下子全冒出来（看不出复制）；外壳罩住后看不出里面装了什么 |
| 6 | **视场揭示** 〔原；借 OF 的 mask reveal + 系列的放大镜〕 | 从宏观纸桌进入微观 / 光的世界 | 要看器件「里面」或看光 | 纸桌上目标处张开圆形视场，里面是暗底的内部画面 | 张开 0.5 秒 + 回弹；关闭 0.4 秒 | `<clipPath>` 圆半径用 spring；边缘一圈 3 px 镜框 | 视场里外比例不一致；视场内外同时有大运动 |
| 7 | **同形转接** 〔观 OF 0:13、1:10 match cut〕 | 跨尺度或跨物理形态的「同一个东西」 | 前后两个东西形状相同（圆截面、方波台阶） | 切点前后：形状、大小、屏幕位置一致 | 切点前后各 0.2 秒；后镜回弹 0.3 秒 | 硬切 + 后镜 `spring` 从 1.06 回到 1 | 形状只是「有点像」就硬接（变成误导：两者物理上无关） |
| 8 | **动作提问 → 定格** 〔观 ZD 0–3 秒具体动作、MK 开场〕 | 开头钩子；章节内的小悬念 | 每集开头；揭晓前 | 一个真实动作做到一半定格，大字问题落下 | 动作 1–2 秒 + 定格 0.3 秒 | 定格前 3 帧减速（speed ramp 到 0） | 动作和问题无关；定格太久（> 0.8 秒）像卡住 |

〔原〕通用约束：**每 3–8 秒必须有一次知识推进或视觉推进**（新结构、新读数、新层级）。关键步骤（例如电 → 光的转换）宁可多停，也不为凑节奏切走。

## 3. 5 种硬件可视化模块

| 模块 | 用在哪 | 准确的部分（必须对） | 教学示意的部分（角注「示意」） |
|---|---|---|---|
| **结构爆炸** 〔观 BE、MK 手机 / 封装爆炸〕 | 光模块、机柜、芯片封装 | 部件种类、上下装配顺序、相对位置、接口数量 | 爆开的间距、旋转角度；内部走线简化成几根 |
| **剖视** 〔观 BE-制造 层块、SB 光纤截面〕 | 光纤截面、芯片层、硅光波导 | 层的顺序、材料、折射率高低关系、真实尺寸**用标注给出** | 层厚按对数压缩画（角注「厚度示意」）；材料用约定色 |
| **光路追踪** 〔观 BE-制造 光刻跟光束；SB 折线〕〔原：修正折线问题〕 | 激光 → 透镜 → 光纤 / 波导；光刻 | 光走的器件顺序、方向；单模光纤里光**沿轴**传播（画模场光斑，不画反弹折线）；多模才可以画很平的折线 | 光的颜色（红外用青色）；速度（必须标「慢放 ×10ⁿ」）；光束宽度放大 |
| **信号转换** 〔原〕 | 电 → 光（调制）、光 → 电（探测）、并行 → 串行 | 一一对应关系：电压高低 ↔ 光强亮暗，节拍相同；电是金色、光是青色，在转换器件处换色 | 波形的边沿形状、噪声；调制方式只画最简单的开关（角注「最简单的一种」） |
| **层级缩放** 〔观 BE、MK 尺度链〕〔原：对数标尺〕 | 机柜 → PCB → 模块 → 芯片 → 波导 | 每一级的真实尺寸量级（标尺读数）、上下级的包含关系 | 中间过渡的连续感（实际是不同尺度的场景拼接） |

## 4. Remotion 组件架构草案（未写代码，只定结构）

```
src/
  tokens/            颜色、字号、线宽、缓动和弹簧预设（全系列共用）
    colors.ts        语义色：elec / photon / alert / ok / paper / night / ink / material.*
    motion.ts        EASE.push = bezier(0.7,0,0.3,1)；SPRING.pop = {damping:14, stiffness:180} …
  primitives/        最小单元（SVG）
    Label  Readout  Ring  Arrow  DashLine  LogRuler  SubtitleStrip  CornerNote
  physics/           物理量的图形（SVG，可选 R3F）
    Waveform(bits, edge, noise)   PulseTrain(power(z), sigma(z))   EyeDiagram
    ModeProfile(core_um, mfd_um)  FiberCrossSection(type: 'SMF'|'MMF')   FieldLines
  hardware2d/        纸桌上的 2D 硬件
    Rack  SwitchFaceplate  PCBTrace  OSFPModule  LaserDie  PhotoDiode  Waveguide
  modules/           第 3 节的 5 个模块
    Exploded  Cutaway  LightPath  SignalConvert  ScaleZoom
  grammar/           第 2 节的 8 条语法（转场组件）
    AnchorPush  FollowCarrier  ProcessBar(layout: 'line'|'ring')  TwinView
    CopyArrayEnclose  LensReveal  ShapeMatchCut  FreezeQuestion
  stages/            PaperDesk（纸桌）  NightField（视场）
  media/             BlenderPlate（<OffthreadVideo> + anchors.json 对齐）  VoiceTrack  Sfx  MusicBed
  episodes/<ep>/     storyboard.ts（数据）→ Composition（只拼装，不写画法）
```

**关键接口（示意）**
```ts
type Beat = { id: string; from: number; dur: number;          // 秒
              stage: 'desk' | 'field'; grammar?: GrammarId;
              focus: { x: number; y: number };                  // 视觉焦点（检查用）
              voice?: string; caption?: string; sfx?: SfxCue[] };
type Storyboard = { fps: 30 | 60; size: [1080, 1920]; beats: Beat[] };

interface PulseTrainProps { bits: (0|1)[]; bitPs: number; km: number;
  lossDbPerKm: number; dispPsPerNmKm: number; slowmo: number }   // 物理参数驱动画面
interface LightPathProps { segments: { kind: 'laser'|'lens'|'fiber'|'waveguide'|'pd';
  len_mm: number }[]; mode: 'single'|'multi' }                    // 'single' 时禁止画折线
interface BlenderPlateProps { src: string; anchors: string; anchorKey: string }
```
- **规则**：画面由物理参数算出来（损耗、色散、位宽），不手调「看起来差不多」。
- `focus` 用于自动检查：相邻两个 beat 的焦点跳动 > 屏宽 40% 而又没有转场语法时报警（防止随机快切）。

**必须 Blender 预渲染的资产**（在你的显卡电脑上渲，带透明通道 + anchors.json）

| 资产 | 用途 | 备注 |
|---|---|---|
| AI 服务器机柜（正面 / 背面） | 开场、层级缩放顶层 | 写实，浅景深 |
| 交换机前面板 + 插满的光模块 | 层级缩放、复制阵列 | 端口按真实 OSFP / QSFP 外形 |
| 光模块外壳 + 内部（PCB、DSP、驱动、激光器、透镜、光纤接口） | 结构爆炸、视场揭示 | 硅光版和 EML 版各一套，按集选用 |
| 激光芯片在热沉上（微距） | 光路起点 | 端面出光 |
| 光纤 / 光缆剖面（写实） | 剖视开场 | 125 µm 包层、9 µm 纤芯按比例 |
| GPU 封装（裸晶 + 基板） | 比特起点 | 不仿任何品牌外观 |

其余（波形、模场、眼图、工序条、标尺、截面）全部用 SVG 程序化生成。简单 3D 体块（等距截面）可以用 R3F。

## 5. 75 秒原创分镜：「一个比特穿过光互连系统」（竖屏）〔原〕

场景设定：机柜 A 里一颗 GPU 发一个比特，经交换机和光纤，到机柜 B 的 GPU。沿用系列的「快递五站」：打包出发 → 路上 → 换乘 → 干线 → 签收。
