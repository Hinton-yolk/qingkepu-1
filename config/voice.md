# 配音配置

所有系列统一用这一个声线（`DECISIONS.md` 第 17 条）。不要换声线，也不要为单集临时换。

| 项 | 值 |
|---|---|
| 平台 | Fish Audio（本环境已连接 Fish Audio connector） |
| 声线 | 「科普」 |
| voice id | `83bc284d2a3848c8a37f6d9a9ab11cd8` |
| 模型 | `s2.1-pro` |
| 语速 | 用默认值，不传 speed。实测约 5.3–6.2 字/秒（「如果」约 5.3，光互连 5.85–6.2）。不要再加快 |

## 语气标签
- 正文不加标签。
- 需要放松、惬意的开头时用 `[relaxed]`，同一段里所有句子用同一个标签，保证音高、响度一致。
- **禁用** `[curious]`（声音会发虚、带气声）和 `[excited]`（音高会高出约一个八度）。
- 配完逐句比较音高和响度，有跳变就重配那一句。

## 流程
- **按字节计费**（UTF-8），所以只在脚本经用户确认之后才生成配音。
- 每句单独生成，统一到 -20 LUFS 再进混音；成片总响度 -14 LUFS，音乐压在人声下方约 12 dB。
- 开头两句放慢：先试拆成更短的句子；不行再在句间加停顿。不要整体调慢语速。
- 发布时在抖音 / 小红书勾选「内容由 AI 生成」。
