先遵守仓库 `CLAUDE.md` 的通用规则。本文件只写这个系列特有的东西。

## 来历和定位（用户 2026-11-18 定）
- **取代「白话光互连」**。光互连改了很多版用户都不满意（「要么是画面要么是故事本身」），所以「仿制“为什么”系列的制作流程来做这个硬科普系列，主要内容就是跟 AI 相关，因为是要做成一个系列，所以内容选题建议由浅入深」。

- 光互连的内容不作废：并进**第三季「AI 芯片之间怎么连」**。旧文章 `episodes/guanghulian/articles/` 是第三季的事实来源；「AI 芯片之间寄快递」框架在第三季里继续用。
- **照搬「为什么」的做法，不照搬它的样子**：无配音、六段式、白话版先行、新元素先示意再示意影响、交付顺序、四个角色都照搬；画风用今天这条的深色画风，和「为什么」的浅灰底分开。用户的原则：「不能一个模型硬套在两个不同的系列上」——两个系列做法可以一样，长相要不同。
- 观众：用过 AI、没有计算机背景的普通人。账号主轴是「剑桥材料学博士讲芯片与光」：前两季从人人用过的 AI 讲到芯片，第三季讲到光，是用户自己的专业。
- **系列名待定**。候选：「你每天都在用 AI，但你不知道它在想什么」（仿「为什么」的口号）、「AI 原来如此」、「拆开 AI」。定了之后改本文件标题、片尾卡、封面口号。
- 选题库：`episodes/ai/选题库.md`。要求清单（监督维护）：`episodes/ai/要求清单.md`。每集目录：`episodes/ai/<集号-短名>/`。

## 选题标准
- **第一帧是人人经历过的 AI 瞬间**（AI 逐字回复、修图消除路人、语音助手听懂你、同一个问题两次答案不同……），不是机房、新闻、芯片特写。第二、三季也要先落到一个日常瞬间，再钻进芯片。
- 大字问题里没有专业名词（用「显卡」不用「GPU」；用「一个字一个字往外蹦」不用「自回归」）。
- 一集只讲透一个机制，能演出来。
- **由浅入深，但每集独立成片**：第一次刷到的人也要看得懂。深是靠「符号表」积累出来的（见下），不是靠默认观众看过前几集。系列进度只放片尾卡和画面角落。
- 避开：平台推荐算法、手机监听（`CLAUDE.md`）；不碰美丑这类主观话题；涉及公司只讲技术，不荐股、不评涨跌（显卡、HBM、光模块这几集尤其注意）。

## 结构：六段式（照搬「为什么」，按 AI 题材改了第 3、5 段）
1. **现象**（≤ 约 2.75 秒）：第一帧就是那个 AI 瞬间，正在发生（AI 正在逐字回复、风扇在转）；大字问题从第 0 帧就在；第一句字幕从第 0 帧就在。
2. **错误直觉 + ✕（可选）**：「你是不是以为……？」只用观众真会有的想法（「它先想好整段话再打出来」「它在网上查资料」「有人一条条教它规则」）。想不出就不要这一拍，直接给意外的事实。
3. **钻进去**：一个连续镜头钻进去（推进到屏幕上的下一个字、钻进显卡外壳、推进到芯片）。
4. **只讲一个机制**：先演示，名词作为答案出现（小字）。
5. **原来还差这一步 / 原来还可以这样**：补上让它真正工作的最后一环，或者一个反转（显卡本来是打游戏的）。
6. **回到开头闭环**：回到第一帧的那个瞬间，这次观众看懂了；把标题反过来说一遍（「AI 要的不是天才，而是人多」）。
然后是片尾卡。

## 画面（系列圣经，取自今天这条）
- **底色**：深靛渐变 `#0C0F26 → #141034 → #090B1C`；三团慢慢漂移的柔光（紫 `#5A46FF` 0.26、青绿 `#28C8AA` 0.14、橙 `#FF7850` 0.11）；54 px 点阵每秒下移 16 px；漂浮微尘；暗角。底色本身一直在动，静止时也不死。
- **颜色分工**（不混用）：
  - 黄 `#FFD84A`：字幕关键词、答案、正在被算的题；
  - 绿 `#3DF5B0`（浅 `#B8FFE4`）：GPU、「算」、并行、对勾；
  - 橙 `#FF9A3C`（浅 `#FFC98A`）：CPU、「想」、「类比」标签；
  - 蓝 `#6F86C9`：缓存、「记」；
  - 粉 `#FF5C8A` / 蓝 `#3BA9FF`：参数的正负；
  - 青 `#8FE3FF`：数字、向量；
  - 白 `#F4F6FF`；小字 `#C9CDEB`；次要文字 `#A6ACD3`。
  - **第三季讲光时**，光的颜色要另定，不能和数字青混；按 `CLAUDE.md`「3D 镜头语法」第 11 条，导光约束在芯区、不漏光。到时先问用户。
- **字体**：得意黑（Smiley Sans）做大字问题、大数字、片尾卡；Noto Sans CJK SC 900 做字幕、500 做小字；DejaVu Sans Mono 做数字。
- **大字问题**：顶部居中，得意黑 140 px，两行，行中心 y = 225 / 375，紫色光晕，关键词黄色。开头和结尾各出现一次。
- **字幕**：底部居中，中心 y = 1480，深色圆角条 `rgba(8,9,26,0.72)`，Noto 900 60 px，行高 80，最多 2 行，每行 ≤ 13 字；关键词黄色；类比字幕右侧加橙框「类比」标签。
- **小字注释**（示意 / 估算 / 类比 / 慢放 / 来源）：Noto 500 32 px，`#C9CDEB`，深色底条，放在字幕条正上方，最多 2 行。
- **平台安全区**：所有文字和要看的东西右边缘 ≤ x 940（抖音右侧按钮栏），下边缘 ≤ y 1550。今天这条的审核两次查出数字伸进按钮栏，交片前用亮像素测一遍。
- **数字**：观众要读的数字一屏最多 3 个；作为纹理的数字（数字条、格子里的数）不算，但不能让人以为要读。
- **一直在动**：每个场景都要有环境动态（漂浮、呼吸、扫光），必须过 `tools/motion_check.py`。
- 手法（今天这条用过、可复用）：第 0 帧手机里 AI 逐字回复；推进到「下一个字」的空位里；格子由大缩小、拉远成格子海 + 大数字滚动；甩镜换场（速度线）；外壳变透明推进到芯片；一圈圈通电；两块芯片上下对照按用途上色；放大镜；回到开头的手机，答案字落进空位。

## 示意画法（照搬「为什么」，用户 2026-11-14 定）
1. 新元素第一次出现：点亮它、标名字（小字），其余压暗。
2. 紧接着示意它带来的影响，一次只变一个东西，因果用小箭头接上。
3. 要看的现象放在一条视线上；解释小字贴在被解释的东西旁边。
4. 讲原理的区域占满可用面积。
5. 不变的东西看起来就不变。

## 准确（硬科普，行家会看）
- 每条事实进该集 `FACTS.md` 并附来源；示意、类比、估算、慢放都在**屏幕上**加注（小字或「类比」标签）。
- **速度和尺度对比要自洽**（今天这条的教训）：两段如果都放慢，要放慢同样的倍数，屏幕上写「同样慢放」，并给出真实量级；不能让人以为 CPU 根本跑不动 AI（审核查出初稿把 CPU 画慢了约 10⁸ 倍）。
- **类比不能越界**（今天这条的教训）：「每个像素一个小核」不对（829 万像素对 16384 个核），改成「每个像素都是一道独立的题」。画面暗示的对应关系，也要和片中给出的数字对得上。
- 「一个字」严格说是一个 token：第一次出现时用小字注明。
- 比赛成绩、错误率这类数字写明口径（例：「前 5 错误率」）。
- GPU 版图、SM 排布等是示意时，写「排布示意」。

## 节奏
- 时长 ≤ 60 秒。每 3–8 秒一个新的知识或视觉推进；关键画面停够（≥ 2 秒），但不静止（≤ 0.6 秒，`motion_check` 标准）。
- 字幕停留 ≥ 0.1 秒 × 字数 + 0.5 秒；画面领先字幕 0.5–1 秒。
- 片尾卡约 3 秒（今天这条：57–60 秒）。

## 声音
- **不加配音**，只用字幕（照搬「为什么」；依据见 `DECISIONS.md` 11-07：无配音的「为什么」2 秒跳出率 20–27%，光互连配音版 53.6%）。
- **音乐**：代码合成（`music.py`，numpy），100 BPM（一拍 0.6 秒）。今天这条的编排：开头木琴琶音 + 柔垫 → 讲「慢」时小调断奏低音 + 滴答 → **揭晓前停半拍** → 揭晓段全编制（底鼓、拍手、十六分琶音、主旋律）→ 变薄 → 讲游戏时转调芯片音色 → 结尾钟声收束。
  每集换调性、和声进行和旋律；三段织体不同；整体曲风不大换（`DECISIONS.md` 第 16 条）。
- 音效全部合成，卡在画面动作上（字蹦出、数字落位、计数滚动、通电、算完的「叮」）。
- 母带：两遍 loudnorm 到 -14 LUFS，真峰值 ≤ -1.5 dBTP（`src/build.sh`）。

## 制作流程
- 从今天这条的源码起步：`episodes/dandu/01-ai-xianka/src/`。新一集先整个复制过来，改 `film.js` 里的场景和 CAPS / NOTES、`music.py` 里的段落和音效时间点。
  - `film.js`：`render(t)` 是时间的纯函数；随机只用 `rnd(i)`（种子化）；字幕在 `CAPS`、小字在 `NOTES`。
  - `render.mjs`：`node render.mjs stills <dir> 0,1.5,3.2` 出静帧；`node render.mjs film <out.mp4> 30 3` 出整片（3 路并行，60 秒片约 100 秒）。
  - `build.sh <版本> <输出目录>`：渲画面 + 配乐 + 两遍 loudnorm + 动效检查。
- 输出：1080×1920，30 fps，H.264 CRF 17，AAC 192k。
- 等第一季 01 做完，把它整理成 `templates/ai/`（像 `templates/weishenme/` 那样），以后从模板开新集。
