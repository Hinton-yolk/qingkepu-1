# 「为什么」：你每天都在用，但你不知道它怎么工作

先遵守仓库 `CLAUDE.md` 的通用规则，本文件写这个系列特有的东西。

**轻科普系列**：日常中你经常用、但不知道原理的东西。片子短，以节奏和演示为主，**不加配音，只用字幕**。现在走轻科普路线，**不一定要体现「反直觉」**（错误直觉 + 打叉那一拍可用可不用），**画面风格保持一致**就行（用户 2026-11-09：「不必，这个系列现在走轻科普路线，不一定需要体现所谓的反直觉；只要画面风格保持一致就行」）。
这是账号目前**数据最好**的系列（陀螺仪 2622 播放、微波炉 2060 播放，2 秒跳出率 26.7% / 20.5%）。本季（约 10 集）**保留 EP.01 / EP.02 的画风和结构**（`DECISIONS.md` 第 14 条）。
**选题：日常常用的电子产品和科技**（手机、耳机、充电器、手表、电脑外设、家电……），越常见越好，但**不刻意往「芯片与光」靠**，也**不做泛生活常识**（冰箱门、吸管、马桶这类被评「有点小偏」，用户：「还是尽可能要选择科技相关，电子产品类的」）（2026-11-07）。反差就在内容本身，两种：
- **运作方式不是我们想的那样**（陀螺仪里什么都不转；微波炉先热外面；降噪是往耳朵里加声音）。
- **太习惯它的存在，从没想过它怎么运作**（打电话时屏幕自己黑了）。
用户原话：「越跟生活常见的常用的贴近，越适合这个系列，这个系列的最大反差就在于内容本身：习以为常的事物，可能运作方式不是我们想的那样，或者对于一些习以为常的运作，我们太习惯他们的存在了以至于没有真正思考过他们是怎么运作的」。

## 用户定下的规矩
- **不能一个模型硬套在两个不同的系列上**：这里的结构、画风都只属于本系列，不要拿去套光互连，也不要把光互连的规矩搬过来。
- **白话版先行**：先交白话版文案，用户确认后再做片。用户的原话措辞照用，不要改写。
- 开头不要「今天我们讲……」，结尾不要课本式总结。
- 「文字太多看不过来，只保留对于理解当下画面有意义的文字」。
- 不要编造尺度参照物（「芝麻」被删过）；不要硬让物体说话（「我在扭 / 还没轮到我」被评价为「很尬」）。零件说话只在讲清楚分工时用，例如「陀螺仪告诉手机：我在转。」「加速度计告诉手机：下面在哪。」
- 用户喜欢陀螺仪那条的原因：「节奏丝滑；动感十足，每一帧都有在动；结尾和开头连上了；时长控制」。
- **画人的部分（手、脚）用黄种人肤色**（约 #EBCBA5，阴影 #D6AD84），不要偏粉偏棕（EP.04 触摸屏反馈）。
- **不要用密集重复的小格纹理**（针织格、密点、蜂窝）：「看着可能会让部分人密恐」，也显得丑。衣物、手套用干净的平涂 + 少量缝线 / 罗纹，质感靠形状和光影，不靠满铺花纹（EP.04 触摸屏反馈）。
- **不重复**：同一个状态不反复解释，每一次运动都要推动理解（新的问题、新的变化），不是重放刚讲过的画面。
- **先讲原理，再讲差别**：问完「它在测什么」就先回答它测的是什么（体脂秤：电穿过你有多难走），再讲肌肉和脂肪的区别（EP.05：「那你就应该跟着解释通电到底是为了什么……再来补充肌肉和脂肪的区别」）。
- **对比要一眼看懂**：A / B 并排、一次只亮一边、读数直接标「好走 / 难走」这类字，不让观众先学会读指针（EP.05：「这两部分的对比动画显示的不是很直观」）。
- **动，但不抖**：抖动幅度按屏幕像素算（≤ 1 px），推近的镜头不抖，波纹慢、淡（EP.04：「开篇的画面还是抖动的太多了」）。
- **脚和手要真实**：脚趾不能画成一排圆柱，大脚趾明显、其余由大到小贴在一起（EP.05：「脚指头很假」）。
- 用户对 EP.04 v1 说过「审美疲劳……画面做的很假……没有那个陀螺仪看着流畅」：不要用卡通假人，画面要做得真实、流畅。

## 结构：六段式（侦探式）
1. **现象**：第一帧就是动作本身（手机正在横过来 / 微波炉正在运转），大字问题从第 0 帧就在。不给名词。
2. **错误直觉 + 打叉（可选）**：「你是不是以为……？」橙色铺底，✕（每集最多这一次橙色铺底）。紧接一句翻转。**错误猜测必须是观众真会有的想法**（「它只是一台秤」——「那不然呢」；「亮片只是装饰」——观众「没想过它是装饰」，都被否了）；想不出就不要这一拍，直接给意外的事实。
3. **钻进去**：一个连续镜头钻进物体内部（外面浅色，里面深色沉浸）。
4. **只讲一个机制**：名词作为答案出现（「这块会"偏"的硅，就叫陀螺仪。」）。
5. **原来还差这一步**：补上让它真正工作的最后一环（陀螺仪 + 加速度计；转盘和热点）。
6. **回到开头闭环**：重复开头的动作，这次观众看懂了。可选「小提示」（例：热剩饭中间扒个坑）。
然后是片尾卡。

题目测试：一个没有术语的日常瞬间，能让人「哦，对啊，为什么呢？」。

## 节奏
- 时长：**60 秒以内**。EP.01（44.5 秒）是紧凑版，EP.02（59.75 秒）是完整模板。
- **片头（第 1 段「现象」）试行缩短**：EP.04 之前是 0–4.25 秒，EP.05 起缩到约 2.75 秒（大字问题照样从第 0 帧就在，画面先把动作做完），先看效果和 2 秒跳出率再定。用户：「第一部分的钩子时间有点稍长，建议从这个视频开始片头缩短1-2s左右，先看看效果」（2026-11-09）。
- 每 5–7 秒抛出一个新问题。
- 字幕停留 ≥ 0.1 秒 × 字数 + 0.5 秒；关键画面停 ≥ 2 秒；画面领先字幕 0.5–1 秒。
- 动效：**以观众的观感为主，愿意看就是好视频**；中位运动量 ≥ 5 / 秒不再是硬指标（用户 2026-11-09：「motion median ≥ 5，现在以audience的观感为主，愿意看就是好视频」）。静止不超过 1.5 秒，仍须通过 `tools/motion_check.py`。
- 画面上最多出现 3 个数字。
- 120 BPM：1 拍 = 0.5 秒 = 15 帧；所有提示点落在 0.25 秒的网格上。
- 字幕密度约 5.2 字 / 秒。

## 画面（系列圣经，原文）
- **颜色**：浅灰底 `#ECEBE6` + 墨 `#141414` + 唯一强调色信号橙 `#FF4A1C`；「错误认知」那一拍橙色铺底（每集一次）；微观世界用 SEM 灰阶。深色场景里的浅色字 `#F1F0EC`，深色内部 `#17191C`。
- **字体**：展示字体得意黑（Smiley Sans；封面用 SmileySans-Oblique），界面字体 Noto Sans SC（700 / 400）。
- **字幕在顶部**，不在底部：左对齐 x = 96，基线 y = 330 / 472，得意黑 112 px；最多 2 行、每行约 9 字（一句实在太长时拆成 3 行、96 px，`SERIES.md` 允许）；每行一个橙色关键词。
  入场：逐字模糊入场；答案和揭晓用「砸入」（1.55 → 0.94 → 1.0，0.17 秒）；或擦除入场。0–700 px 有一层底色柔光罩。
- 标注：Noto ≥ 44 px，细引线。y = 1450 以下不放任何东西（让开平台界面）。
- **没有角标、没有边框**（角标是「一语道破」系列的，不要混用）。
- 常用手法：第 0 帧大问题；橙底错误猜测 + ✕ + 一句翻转；扫描线 X 光，零件上的橙色圆环；一个连续镜头钻进去；零件对话气泡；结尾重复开头动作。
- **片尾卡**：物体缩成描边徽章；「你每天都在用，/但你不知道/它[怎么工作]」124 px 打字出现；「EP.0x」150 px 砸入（x 400，y 520），跟着集名；最后一个旋律音上弹出橙色「?」。

## 制作流程（手写 Canvas2D，不是现成的动画 skill）
- `window.seek(t)` 是时间的纯函数；每帧 `ctx.reset()`；随机只用种子化的 mulberry32。
- `timeline.js` 是画面和声音的唯一来源：`T`（提示点时间）、`COPY`（字幕文字）、`HITS`（声音提示）。
- 镜头：相似变换相机 `key(F, anchor, Z, phi)`，对数螺线插值。运动模糊：只在 BLUR 时间窗里做 6 次子采样。
- 渲染：`node render.mjs`（`--stills` / `--sheet` / `--strip` / `--encode` / `--from`），Playwright 逐帧截图。
- 输出：1080×1920，30 fps，libx264 yuv420p CRF 16，AAC 256k。
  小红书全屏版 1080×2340：把每帧顶部 24 行模糊拉伸成 420 px 补在上方。
- 每集一个项目目录：`index.html`、`timeline.js`、`render.mjs`、`music/score.mjs`、`tools/`（master.sh、beatcheck.mjs、motion.py、fonts.py、verify.sh）、`assets/fonts/`、`SPEC.md`、`REVIEW.md`、`FACTS.md`。
- 试过但被否掉的：animate 的变形转场样例（「转场太硬」）；three.js 拆解（每帧 21–34 秒，太慢）。用户：「我比较 prefer 现有版本」。
- **开新一集从模板开始**：`templates/weishenme/`（以 EP.02 为骨架，含系列圣经 `SERIES.md`、封面脚本 `covers/`），步骤和命令见 `templates/weishenme/README.md`。
- 已有各集源码：`episodes/weishenme/01-tuoluoyi/`、`02-weibolu/`、`03-jiangzaoerji/`（降噪耳机）、`04-chupingshoutao/`（触摸屏）、`05-tizhicheng/`（体脂秤）；距离传感器 v1 不做了，存档在 `archive/weishenme/julichuanganqi-v1/`。
  **04 是被否掉的 v1，用户说「先暂时保留，等我指令再开始做」**（见该目录的 `notes.md`），没有指令不要动。
- 选题库：`episodes/weishenme/选题库.md`。

## 声音
- **不加配音**（用户 2026-11-06 确定）：本系列以节奏和演示为主，只用字幕，信息全部靠画面和字幕传达。
- **音乐**：Node 里代码合成的原创配乐，120 BPM，十六分音符。
  - 开头动机 mi-sol-la，揭晓时解决到 mi-sol-DO。每个问题用同一个上行四度两音标记。✕ 之前留 0.5 秒真正的静音。最响的三个点：✕、名词揭晓、结尾闭环时屏幕「咔」一下。
  - EP.01：F–G–Em–Am（IV–V–iii–vi）。EP.02：G 大调 vi–IV–I–V，「叮」（G6）落在 DO 上；微波炉嗡声 98 Hz。
  - **每集要变化**（用户反馈「音乐有点单调」，`DECISIONS.md` 第 16 条）：每集换调性、和声进行、旋律；开头 / 讲解 / 揭晓三段用不同织体；揭晓前停半拍。
    但**整体换曲风被否过**（「不好听，不协调」），所以先在同一套合成音色和速度里做变化，再小心地加减配器。
- 打点放在用 `npx hyperframes beats` 测出的节拍网格上，用 `beatcheck.mjs` 检查。音效全部合成（tick、snap、strike、ding、hum、bloom、打字声），不用噪声嗖嗖声。
- 母带：`master.sh` 两遍 loudnorm 到 -14 LUFS，过采样限幅。

## 封面与文案
- **封面**（`covers/make.mjs`）：顶部小字「你每天都在用，但你不知道它怎么工作」（Noto 400，38 px，60% 墨色）+ 橙色「EP.0x」；两行得意黑标题（抖音 132 px、小红书 128 px，左边距 72），关键词橙色；用片中画面重渲染做主图；圆形放大镜插图（`#17191C` 底、10 px 墨色圈、橙色锚点引线）。
  抖音 1080×1920（重要内容都放在中间 3:4 范围内）；小红书 1080×1440。
- **抖音文案**：一个钩子问题 + 一句反直觉答案 + 话题标签。例：#为什么系列 #陀螺仪 #手机冷知识 #科普 #涨知识 #每天学点新知识
- **小红书**：标题就是问题（另备一个标题）；正文 = 钩子 → 误解 → ①–④ 步骤 → 可选小提示 →「这是「你每天都在用，但你不知道它怎么工作」第 N 集。你还想知道哪个东西是怎么工作的？评论区告诉我。」标签以 #为什么系列 结尾。
- **置顶评论**：「下一集你想看什么？留言点名，点赞最多的先做。」
- 另外按 `CLAUDE.md` 覆盖 3–5 个搜索关键词。

## 范例：EP.01 陀螺仪字幕（v5，44.5 秒；`[ ]` = 橙色）
第 0 帧手机已经在从竖屏转向横屏（0.75 秒转完），1.0 秒屏幕「咔」地切换；第一句字幕从第 0 帧就在，2.0 秒「横过来」加橙色下划线。

- 0「手机怎么知道 / 你把它[横过来]了？」
- 4.25「你是不是以为 / 里面藏了个小[陀螺]？」（橙底，玩具陀螺扫描进来；6.5 秒 ✕）
- 6.75「其实里面 / 什么都[不转]。」
- 8.5「那它到底 / 怎么测[旋转]？」
- 11.0「答案藏在一颗 / 比米粒还小的[芯片]里」（标注：一粒米 · 3 × 2.5 mm）
- 13.0「它自己不转， / 怎么知道你在[转]？」
- 17.25「一小块硅， / 一直在[左右]振动」+「每秒上万次 · 慢放演示」
- 19.25「这时， / 手机[转]一下呢？」
- 21.0「它就会 / 向侧面[“偏”]！」+「这叫科里奥利效应」
- 22.75「为什么一偏， / 就知道转多[快]？」（读数 °/秒）
- 24.5「转得越快， / 偏得越[多]。」
- 26.75「这块会“偏”的硅， / 就叫[陀螺仪]。」+「名叫“陀螺”，却一圈都不转」
- 29.0「但只知道“转了”， / [够吗]？」→ 分屏：陀螺仪告诉手机「我在转」｜加速度计告诉手机「下面在哪」（标注：重力）
- 34.5「手机到底 / 怎么判断[横屏]？」（手机再转一次；两个气泡；38.0 秒屏幕切换）
- 38.5「所以，你一横手机， / 它就[知道]了。」
- 40.75 片尾卡 · EP.01 · 陀螺仪

EP.02 微波炉（59.75 秒）是完整模板：开头整台微波炉在运转、缓慢推近，2.0 秒「叮」，推进碗的剖面，3.0 秒「凉」加下划线；中段 19.25–21.75 秒一镜到底钻进一粒米饭；52.75 秒小提示「热剩饭，中间[扒个坑]，叮完[焖一分钟]，热会自己走到中间。」
